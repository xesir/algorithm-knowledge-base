## 算法原理

OI 里很多算法都拿「值」当**下标**——树状数组、权值线段树、计数数组……但值域往往大得离谱，常见 $10^9$。这种情况下数组还没开就已经爆空间了。

**离散化**就是来解决这个的：把值域压扁。

它的本质是**压缩值域**。当值域很大、而实际用到的数很少时，把所有出现过的值收集起来，**排序去重**后用一个小编号代替原值，值域就从 $O(V)$ 降到 $O(n)$。一般题面是 $n \le 10^5$、$V \le 10^9$ 甚至更大，这个优化的收益非常可观：既不开不下大数组，又**保留元素之间的大小关系**。

举个栗子，原数组：

```text
a = [1, 100, 10000, 100, 1]
```

直接开值域 $10000$ 的数组纯属浪费。离散化之后：

```text
排序去重: [1, 100, 10000]
映射编号: 1->1, 100->2, 10000->3
离散化后: [1, 2, 3, 2, 1]
```

和「不离散化、直接用原值当下标」相比，离散化后代码更省空间，也更容易套用那些需要值域作下标的数据结构。

但要注意代价：离散化会**丢掉原值的绝对信息**（比如「两数之差」「两数之积」没法直接从编号还原），所以它只适合**只需要相对大小关系、不需要绝对权值**的场合，否则得额外维护原值。

## 逐行代码解析

下面三块是几种常用写法，都是片段，不要求拼成完整程序。

### 保序离散化

把原值排序去重，再用 `lower_bound` 查每个值对应的排名。这样离散化后的编号**保留了原值的大小关系**，可以直接比较、二分。

```cpp
sort(b + 1, b + n + 1);
int len = unique(b + 1, b + n + 1) - b - 1;
for (int i = 1; i <= n; i++)
    a[i] = lower_bound(b + 1, b + len + 1, a[i]) - b;
```

- `b` 是原数组的副本，`sort` + `unique` 得到去重后的有序序列，长度记为 `len`。
- `lower_bound` 返回迭代器，减去起点 `b` 得到的就是 $1$ 起的排名。
- 效果：

```text
原值:   1, 100, 10000, 100, 1
编号:   1,  2,    3,   2,  1
```

### 哈希替代

如果只需要判断两个值**是否相等**、不关心大小关系，可以直接用哈希表建立「原值 → 编号」的映射，不必排序，适合值域极大且顺序无关的场景。

```cpp
unordered_map<int, int> mp;
int tot = 0;
for (int i = 1; i <= n; i++) {
    if (!mp.count(a[i])) mp[a[i]] = ++tot;
    a[i] = mp[a[i]];
}
```

- 编号按**首次出现顺序**分配，不保序，但 $O(n)$ 期望时间，不用排序。

### 逆映射还原

离散化后如果还要输出原值，额外存一个 `rev` 数组，记下「编号 → 原值」：

```cpp
for (int i = 1; i <= len; i++) rev[i] = b[i];
```

这样查到编号后直接 `rev[id]` 就还原成原值了。

## 复杂度分析

- 时间复杂度：主体是排序，$O(n \log n)$；`unique` 和逐元素 `lower_bound` 都是 $O(n \log n)$。用哈希表替代时，期望 $O(n)$。
- 空间复杂度：$O(n)$，需要一份原值副本和映射数组，和值域 $V$ 无关。

## 适用场景

- **树状数组 / 线段树的下标**：值域大但数据量小时，必须先离散化才能开数组。
- **权值线段树 / 主席树**：维护值域频次，必须先离散化。
- **逆序对统计**：值域大时离散化后再用树状数组求逆序对。
- **扫描线**：矩形面积并、周长并，端点坐标需要离散化。
- **二维数点**：把坐标压到 $O(n)$ 后再套数据结构。

## 常见陷阱与注意事项

1. **区间离散化要补端点**：维护区间 $[l, r]$ 时，只离散化端点会丢掉两个端点之间的「空隙」，需要额外插入 $l-1$ 或 $r+1$（或改用左闭右开）来保证连续性，否则「一段区间是否被完全覆盖」就判断错了。
2. **编号别弄错下标起点**：数组从 $1$ 开始时，`lower_bound(...) - b` 得到的正好是 $1$ 起的排名；从 $0$ 开始则要相应调整，混用极易差 1。
3. **不保序的编号不能比大小**：哈希映射出来的编号只表示「相等 / 不等」，拿它做大小比较或二分是错的。
4. **离散化后要还原原值**：输出答案如果要求原值，记得用 `rev` 数组映射回去。
5. **重复元素**：`unique` 只去相邻重复，所以**必须先 `sort`**；漏了排序会去重失败。

## 对比与扩展

| 方式 | 是否保序 | 适用场景 |
| :--- | :--- | :--- |
| `sort + unique + lower_bound` | 是 | 需要比较大小、二分 |
| 哈希表映射 | 否 | 只需判断相等 |
| 区间离散化 | 是 | 线段覆盖、区间问题 |
| 二维坐标压缩 | 是 | 平面点集、扫描线 |

扩展方向：

- **区间离散化**：在端点集合里补上相邻端点之间的中间点（或 $l-1$ / $r+1$），保住区间的连续性。
- **坐标压缩**：二维点集分别对 $x$、$y$ 离散化，处理完后每个点坐标都压到 $O(n)$，就能用二维数组或二维数据结构维护，典型场景是扫描线求矩形面积并、二维数点。
- 相关知识点见 `ds-segtree-discretize`（离散化 + 线段树）。

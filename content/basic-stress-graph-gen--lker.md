## 算法原理

一般图的随机生成，核心套路只有一句：**先生成一棵树保证连通，再随机补边到 $m$ 条**。

树的部分和「树与特殊结构」那条完全一样——枚举 $i\in[2,n]$，让 $i$ 连向 $[1,i-1]$。这样图一定连通、边数一定至少是 $n-1$。

补边时要按题目要求逐条加上限制：

| 要求 | 处理方式 |
|---|---|
| 不许自环 | 判 `u==v` 就重抽 |
| 不许重边 | 用 `set<pair<int,int>>` 记已存在的边 |
| 无向边方向 | 统一存成 `{min(u,v),max(u,v)}` |
| 有向边方向 | 直接存 `{u,v}`，不排序 |
| 无环（DAG） | 只允许从小编号连向大编号 |
| 二分图 | 先给树染色，之后只在异色点之间连边 |
| 平面图 | 直接造网格图作为代表 |

## 逐行代码解析

### 连通无向图

先生成一棵树，再在树上随机添加边，以保证图一定连通：

```cpp
for(int i=2;i<=n;i++) 
    cout<<(rd()%(i-1)+1)<<" "<<i<<"\n";
for(int i=n;i<=m;i++)
    cout<<(rd()%n+1)<<" "<<(rd()%n+1)<<"\n";
```

- 第一段是树，用掉 $n-1$ 条边；第二段从第 $n$ 条补到第 $m$ 条，共补 $m-n+1$ 条。
- 补的边**可能是自环、也可能是重边**，多数题不允许，需要换成下面带 `set` 的写法。
- 若 $m$ 小于 $n-1$，这个循环根本不会执行，输出退化成树——要和题目的 $m$ 下界对齐。

### 有向图

```cpp
for(int i=2;i<=n;i++)
{
    int p=1+rnd()%(i-1);
    cout<<p<<" "<<i<<"\n";
}
for(int i=n;i<m;i++)
{
    int u=1+rd()%n;
    int v=1+rd()%n;
    cout<<u<<" "<<v<<"\n";
}
```

- 树的边方向统一为「小 $\to$ 大」，天然无环；补边时方向随机，可能造出环。
- 这里第二段的上界写的是 `i<m`，比无向图那版少跑一次，抄的时候按实际需要的边数调整。
- 注意变量名 `rnd` 与 `rd` 混用了，实际使用时统一成一个。

### 不允许自环和重边的无向图

使用 `set` 判断边是否已经存在即可：

```cpp
for(int i=2;i<=n;i++) 
    cout<<(rd()%(i-1)+1)<<" "<<i<<"\n";
set<pair<int,int>> e;
while(e.size()<m)
{
    int u=1+rd()%n;
    int v=1+rd()%n;
    if(u==v||e.count({min(u,v),max(u,v)})) continue;
    e.insert({min(u,v),max(u,v)});
    cout<<min(u,v)<<" "<<max(u,v)<<"\n";
}
```

- 关键是把边统一存成 `{min,max}`：无向图里 $(u,v)$ 和 $(v,u)$ 是同一条边，不排序就会漏判重。
- `e.size()` 只统计补出来的边，树上那 $n-1$ 条没有放进 `set`，所以循环条件写 `e.size()<m` 时要自己补上偏移。
- 如果 $m$ 接近完全图（$\frac{n(n-1)}{2}$），随机重抽会越来越慢，接近饱和时要改成枚举剩余点对。

### 不允许自环和重边的有向图

基本方法与无向图类似，但需要注意边的方向：

```cpp
set<pair<int,int>> e;
for(int i=2;i<=n;i++)
{
    int p=1+rnd()%(i-1);
    e.insert({p,i});
    cout<<p<<" "<<i<<"\n";
}
while(e.size()<m)
{
    int u=1+rd()%n;
    int v=1+rd()%n;
    if(u==v||e.count({u,v})) continue;
    e.insert({u,v});
    cout<<u<<" "<<v<<"\n";
}
```

- 有向边不排序：$(u,v)$ 与 $(v,u)$ 是两条不同的边，都算合法。
- 这里把树边也放进了 `set`，所以 `while(e.size()<m)` 的语义是对的——总共 $m$ 条边。
- 同上，边数接近 $n(n-1)$ 时重抽会变慢。

### 完全图

```cpp
for(int i=1;i<=n;i++)
    for(int j=i+1;j<=n;j++)
        cout<<i<<" "<<j<<"\n";
```

- 双重循环只取 $j>i$，正好枚举所有无序点对，不重不漏。
- 完全图的边数是 $O(n^2)$，$n$ 稍大输出就会爆掉，注意题目上界。

### DAG

先生成一棵树以保证图连通，再规定只能从编号较小的点指向编号较大的点，从而保证图中无环：

```cpp
set<pair<int,int>> e;
for(int i=2;i<=n;i++)
{
    int p=1+rd()%(i-1);
    e.insert({p,i});
    cout<<p<<" "<<i<<"\n";
}
while(e.size()<m)
{
    int u=1+rd()%(n-1);
    int v=u+1+rd()%(n-u);
    if(e.count({u,v})) continue;
    e.insert({u,v});
    cout<<u<<" "<<v<<"\n";
}
```

- `u` 取 $[1,n-1]$，`v` 取 $[u+1,n]$，所以每条边都从小指向大。既然编号严格递增，就**不可能有环**。
- `rd()%(n-u)` 的取值范围是 $[0,n-u-1]$，加上 $u+1$ 后正好落到 $[u+1,n]$。
- 这个技巧叫做「按拓扑序编号」，比随机删边判环简单得多。

### 二分图

先生成一棵树，并根据树上的连接关系为节点染色，保证相邻节点颜色不同；然后在不同颜色的节点之间随机添加边：

```cpp
for(int i=2;i<=n;i++)
{
    int p=1+rd()%(i-1);
    c[i]=1-c[p];
    e.insert({min(p,i),max(p,i)});
    cout<<p<<" "<<i<<"\n";
}
while(e.size()<m)
{
    int u=1+rd()%n;
    int v=1+rd()%n;
    if(u==v||c[u]==c[v]) continue;
    int a=min(u,v),b=max(u,v);
    if(e.count({a,b})) continue;
    e.insert({a,b});
    cout<<a<<" "<<b<<"\n";
}
```

- 建树时顺便染色：`c[i]=1-c[p]`，保证树边一定连接异色点。
- 补边时 `if(u==v||c[u]==c[v]) continue;` 直接跳过同色点对，于是所有边都在异色之间，图必然是二分图。
- 这个写法同时保证了「连通」「无自环」「无重边」「二分」，是二分图题的万能数据。

### 平面图

这里以生成网格图为例：

```cpp
for(int i=1;i<a;i++)
    for(int j=1;j<=b;j++)
        cout<<id(i,j)<<" "<<id(i,j+1)<<"\n";
for(int i=1;i<=a;i++)
    for(int j=1;j<=b;j++)
        cout<<id(i,j)<<" "<<id(i+1,j)<<"\n";
```

- `id(i,j)` 把二维坐标压成一维编号，通常是 `(i-1)*b+j`。
- 第一段连横向边、第二段连纵向边，画出来就是一张 $a\times b$ 的网格，是平面图最典型的代表。
- 注意两段的边界：横向只该连到 $b-1$，纵向只该连到 $a-1$，否则会连出格子外的点。

## 复杂度分析

建树是 $O(n)$；补边时若用 `set` 判重，每条边是 $O(\log m)$，总计 $O(m\log m)$；完全图和网格图则是按点数直接 $O(n^2)$ 或 $O(ab)$ 输出。空间上 `set` 需要 $O(m)$。

## 适用场景

- 最短路、最小生成树、连通性、拓扑排序、二分图匹配等图论题的随机数据。
- 想卡「重边 / 自环」处理时，专门造带重边、带自环的数据（把上面的判重去掉即可）。
- 想卡「不连通」时，去掉建树那一段，只在随机点对之间连边。

## 常见陷阱

- **$m$ 与 $n-1$ 的关系**：补边循环的起点写成 `i=n` 还是 `i=m`，直接决定总边数对不对。先想清楚「树边已占多少条」再写。
- **无向图忘记 `min/max`**：不排序就会把 $(u,v)$ 和 $(v,u)$ 当成两条边，输出重边。
- **`set` 里没放树边**：`e.size()<m` 的语义就错了，实际边数会偏多。
- **$m$ 接近完全图时重抽变慢**：随机重抽在边快满时会大量空转，$n$ 稍大就可能卡死，需要改成枚举。
- **DAG 的编号规则被破坏**：一旦允许「大编号指向小编号」，环就出现了，拓扑排序题会直接判错。
- **二分图忘了染色**：只靠随机连边是不可能保证二分性的，必须显式染色。
- **平面图边界越界**：横向/纵向循环的上界差一，就会连出不存在的点。

## 对比与扩展

- 与「树与特殊结构」的关系：那一条是这一条的子过程，把建树部分单独抽出来就是树生成器。
- 想造「稀疏随机图」，可以让 $m$ 取 $2n\sim5n$；想造「稠密图」，让 $m$ 取 $n^2/10$ 量级。
- 卡 Tarjan / 网络流时，基环树、菊花、网格、完全图各来一组，比纯随机有效得多。

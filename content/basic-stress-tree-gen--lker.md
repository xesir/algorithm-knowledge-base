## 算法原理

树是随机数据里最常被考的结构，而「随机树」有个非常好用的事实：**枚举 $i\in[2,n]$，让 $i$ 随机连向 $[1,i-1]$ 中的某个点，得到的必然是一棵以 $1$ 为根的树**。

原因有三条：

- $i=2$ 时只能连 $1$，所以图一定连通；
- 每个点只向编号更小的点连边，所以不会产生环；
- 每次恰好加一条边，边数正好是 $n-1$。

由此还能顺手改出几个变体：

| 结构 | 怎么改 |
|---|---|
| 链 | 把「随机连 $[1,i-1]$」改成「只连 $i-1$」 |
| 菊花图 | 把所有点都连到 $1$ |
| 基环树 | 先单独造一个环，再往环上挂树 |
| 森林 | 把 $n$ 个点切成若干段，每段内部按树的方式连 |
| 二叉树 | 随机选父亲，但限制每个点最多两个孩子 |

## 逐行代码解析

### 随机树

给出 $u,v$，表示 $u,v$ 之间有一条边。枚举 $i\in[2,n]$，让每个 $i$ 随机连接到 $[1,i-1]$ 中的一个点：

```cpp
int n=rd()%(MAXN-1+1)+1;
cout<<n<<"\n";
for(int i=2;i<=n;i++)
    cout<<rd()%(i-1-1+1)+1<<" "<<i<<"\n";
```

- `rd()%(i-1-1+1)+1` 化简就是 `rd()%(i-1)+1`，取值范围 $[1,i-1]$；照着公式写不容易错。
- 这样生成的树「偏向于小编号当父亲」，深度通常不大。想造深链、造卡递归的数据，得用下面的「链」或加权策略。
- 如果题目以 $1$ 为根，这里生成的天然就是以 $1$ 为根的有根树，不用再找根。

### 基环树

生成一个环长为 $k$、总点数为 $n$ 的基环树：先建立环，再在环上挂树。

```cpp
for(int i=1;i<k;i++) cout<<i<<" "<<i+1<<"\n";
cout<<k<<" "<<1<<"\n";
for(int i=k+1;i<=n;i++)
    cout<<rd()%(i-1-1+1)+1<<" "<<i<<"\n";
```

- 前两行把 $1\to2\to\cdots\to k\to1$ 连成一个长度 $k$ 的环，正好用掉 $k$ 条边。
- 后面把 $k+1\dots n$ 依次挂到 $[1,i-1]$ 上，因为挂的点编号都大于 $k$，所以不会影响环本身。
- 总边数是 $k+(n-k)=n$，符合基环树「$n$ 点 $n$ 边」的定义。
- 注意 $k$ 至少为 $3$（$k=2$ 会变成两条重边），造数据时要单独卡一下。

### 菊花图

将所有点连接到根节点上：

```cpp
for(int i=2;i<=n;i++)
    cout<<1<<" "<<i<<"\n";
```

- 专门用来卡「单次递归深度大」「从根出发的遍历很慢」这类实现。
- 与链配合使用：链卡深度，菊花卡度数。

### 链

依次连接相邻节点即可：

```cpp
for(int i=2;i<=n;i++)
    cout<<i-1<<" "<<i<<"\n";
```

- 链是最容易把递归 DFS 爆栈的结构，也是深度相关算法（LCA、树剖）的极端数据。
- 想造「长链 + 少量分叉」，可以在链上随机挑几个点再挂叶子。

### 森林

生成多棵树即可：

```cpp
int sum=0;
while(k)
{
    int n=rd()%(k-1+1)+1;
    for(int i=sum+2;i<=sum+n;i++)
    cout<<sum+1+rd()%(i-sum-2+1)<<" "<<i<<"\n"; 
    k-=n;
    sum+=n;
}
```

- `sum` 是已经造过的点数，相当于把全局编号切成若干段，每段内部独立成树。
- 内层 `sum+1+rd()%(i-sum-2+1)` 的含义是「连到本段内编号更小的点」，和随机树的原理完全一样。
- `while(k)` 里 `n` 有可能取到 $0$，如果 $n=0$ 就会死循环，实际使用时建议写成 `rd()%(k)+1`。

### 二叉树

让每个节点随机连接到一个父节点，并限制每个节点的孩子数不超过 $2$：

```cpp
int cnt[N];
for(int i=2;i<=n;i++)
{
    int p;
    do{
        p=1+rd()%(i-1-1+1);
    }while(cnt[p]>=2)
    cnt[p]++;
    cout<<p<<" "<<i<<"\n";
}
```

- `cnt[p]` 记父亲 $p$ 当前已有的孩子数，`do...while` 反复重抽，直到抽到一个还没满两个孩子的父亲。
- 这种「重抽」写法的期望次数很小（树里空位足够多），但最坏情况会退化成一直重抽，数据规模别开太大。
- 注意 `while(cnt[p]>=2)` 后面少了一个分号，实际编译会报错，抄的时候记得补上。

## 复杂度分析

每种结构都是一次 $O(n)$ 的循环，空间上除了二叉树要开一个 `cnt` 数组（$O(n)$）之外都是 $O(1)$。

## 适用场景

- 树形 DP、LCA、树链剖分、树上差分等题的随机数据。
- 想专门卡「递归深度」时用链；想卡「度数」时用菊花图；想卡「环上处理」时用基环树。
- 二叉树模板题（如线段树、堆）可以用二叉树生成器配合验证。

## 常见陷阱

- **随机树深度太小**：默认生成法长出来的树接近「随机递归树」，深度约为 $O(\log n)$，几乎卡不到递归栈。要卡深度必须显式造链。
- **基环树 $k$ 取太小**：$k=2$ 时 $(1,2)$ 与 $(2,1)$ 是两条重边，不是合法的简单环。
- **森林里出现空树**：`n` 取到 $0$ 会死循环，也会破坏「$n$ 个点」的约定。
- **二叉树重抽死锁**：如果 $n$ 很小而限制又很紧（比如每个点最多 1 个孩子），`do...while` 可能永远抽不到，需要兜底。
- **题目要求无标号 / 有标号**：上面生成的都是有标号树；如果题目要的是无标号计数，随机数据没有意义。
- **边权与点权**：不少题还要给边权，记得在每条边后面再输出一个随机权值。

## 对比与扩展

- 与「一般图生成」的关系：树是最小连通结构，先在树上加边就得到连通图；先造森林再加边可以得到不连通图。
- 想造「随机形态更均匀」的树，可以用 Prüfer 序列，但写起来比上面这套麻烦得多，对拍一般用不上。
- 卡常/卡栈时，把链、菊花、二叉树、随机树各造一组，覆盖面就很足了。

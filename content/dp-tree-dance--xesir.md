## 算法原理

树形 DP 是在树上做动态规划：利用树的递归结构，**先算子树，再合并到父节点**，天然适合处理「依赖关系」「覆盖问题」「子树统计」等场景。通用套路可以概括成三点：

- **状态定义**：以节点为状态维度，记录该节点或子树的一些信息。
- **计算顺序**：自底向上，DFS 后序遍历——先算完所有儿子，再合并到父亲。
- **转移**：合并子树的 DP 值，得到当前节点的 DP 值。

基本框架长这样：

```cpp
void dfs(int u, int fa) {
    // 初始化 dp[u]（视题目而定）
    for (int v : G[u]) {
        if (v == fa) continue;
        dfs(v, u);
        // 用 dp[v] 更新 dp[u]
    }
}
```

本例「没有上司的舞会」是树形 DP 的基础例题，本质是**树上的最大权独立集**：一棵树代表公司层级，每个节点有权值（快乐值），约束是「选了某节点就不能选它的直接下属」，目标是选中节点的权值和最大。

注意源程序的建边方式：输入的是 (下属 `l`, 上司 `k`)，代码执行 `bo[k].push_back(l)`，即只保留了「上司 → 下属」这一个方向，所以递归时不需要判父节点。树根就是入度为 0 的那个点，代码用 `v[l]=1` 标记「`l` 有上司」来把它找出来。

## 核心公式 / 状态定义与转移方程

状态定义：

- `dp[u][0]`：不选 $u$ 时，以 $u$ 为根的子树内的最大权值和。
- `dp[u][1]`：选 $u$ 时，以 $u$ 为根的子树内的最大权值和。

转移方程（不选 $u$）：每个儿子 $v$ 可选可不选，取较优值累加。

$$dp[u][0] = \sum_{v \in children(u)} \max(dp[v][0], dp[v][1])$$

转移方程（选 $u$）：儿子都不能选，只能取 `dp[v][0]`。

$$dp[u][1] = val[u] + \sum_{v \in children(u)} dp[v][0]$$

初始化：进入节点时 `dp[x][0]=0`、`dp[x][1]=h[x]`。最终答案 $\max(dp[root][0], dp[root][1])$。

## 逐行代码解析

### 头文件与全局变量

```cpp
#include <bits/stdc++.h>
using namespace std;
vector<int> bo[6010];
int h[6010],f[6010][2],v[6010];
```

- `bo[k]` 存上司 `k` 的所有直接下属（邻接表）；`h[i]` 是快乐值；`f[i][0]`、`f[i][1]` 即上面的两态 `dp`。
- `v[i]` 标记 `i` 是否为某人的下属（即 `i` 有没有上司），用来找唯一的根。

### dp 函数：自底向上合并子树

```cpp
void dp(int x){
    f[x][0]=0;f[x][1]=h[x];
    for(int i=0;i<bo[x].size();i++){
        int y=bo[x][i];
        //cout<<y<<" "<<x<<endl;
        dp(y);//TODO
        f[x][0]+=max(f[y][0],f[y][1]);
        f[x][1]+=f[y][0];
    }
}
```

- 先初始化两个状态：不选 `x` 得 0，选 `x` 先累加自身权值 `h[x]`。
- 遍历每个儿子 `y`，先 `dp(y)` 递归——必须先把儿子的值算好，才能合并到父亲。
- 不选 `x` 时累加 `max(f[y][0], f[y][1])`；选 `x` 时累加 `f[y][0]`（儿子不能同时选）。
- 代码行尾那两处待办注释是源笔记的自我提醒残留，照搬不改；`//cout...` 是调试输出，提交时应删掉。

### main：建树、找根、输出

```cpp
int main(){
    int n;cin>>n;
    for(int i=1;i<=n;i++){
        cin>>h[i];
    }
    for(int i=1;i<n;i++){
        int l,k;cin>>l>>k;
        bo[k].push_back(l);
        v[l]=1;
    }
    int st;
    for(int i=1;i<=n;i++){
            if(!v[i]) {st=i;break;}
        }
    dp(st);
    cout<<max(f[st][0],f[st][1]);
}
```

- 先读 $n$ 个点的权值，再读 $n-1$ 条父子关系；每条关系里 `l` 是下属、`k` 是上司，`bo[k].push_back(l)` 挂边，`v[l]=1` 标记 `l` 有上司。
- `int st;` 声明后**未初始化**，靠下面的循环把它赋成入度为 0 的根；合法输入恰好有一个根，所以一定能赋上值。
- 答案取 `max(f[st][0], f[st][1])`：根可以选也可以不选。

## 复杂度分析

- **时间复杂度**：$O(n)$。DFS 每个节点访问一次，每次合并儿子是 $O(1)$ 的累加，总计 $O(n)$。
- **空间复杂度**：$O(n)$。邻接表加上 `h`、`f`、`v` 三个数组，均为 $O(n)$。

## 适用场景

- 树上的最大权独立集（相邻节点不能同时被选），即本题「没有上司的舞会」。
- 一切「决策只在父子之间传递」的树形问题，如树上最小点覆盖、树上最大匹配（转移思路同源）。
- 更一般地，任何能把「子树」当作整体再向上合并的树形结构问题。

## 常见陷阱与注意事项

1. **必须后序递归**：先 `dp(y)` 再更新 `f[x]`，否则会用到儿子的初值。
2. **建边方向**：源程序只建「上司 → 下属」的单向边，因此递归不判父节点；若改成双向边，必须补 `if (y == fa) continue;`，否则会来回递归。
3. **根可能找不到**：`v[i]` 全为 1 时 `int st;` 不会被赋值，`dp(st)` 就成了未定义行为；本题保证是合法的树，可忽略。
4. **权值可能为负**：`f[x][0]=0`、`f[x][1]=h[x]` 的初始化默认了「不选一定不亏」，若权值有负数要重新审视初值。
5. **递归爆栈**：链状树深度可达 $n$，$n$ 很大时要留意栈空间。
6. **函数名与数组名易混**：源程序用 `dp` 当函数名、`f` 当数组名，`dp(st)` 是调用函数而不是访问数组，别被名字带偏。

## 对比与扩展

- 与「树形 01 背包」相比，本题只有「选 / 不选」两态，转移只需累加子节点值，不必枚举容量分配。
- 若把树退化成链，本题等价于「相邻不能同时选」的最大子段和类问题。
- 若图不是树而是一般图，最大独立集是 NP-hard；$O(n)$ 的树形 DP 完全依赖树的无环性。

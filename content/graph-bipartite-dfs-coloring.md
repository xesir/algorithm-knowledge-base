## 算法原理

二分图（Bipartite Graph）是一种特殊的无向图，其顶点可以划分为两个**互不相交**的集合，使得图中每条边的两个端点分别属于不同的集合。换句话说，同一集合内的顶点之间没有边相连。

### 什么是二分图

设无向图 $G = (V, E)$，若存在顶点集的一个划分 $V = A \cup B$，满足 $A \cap B = \emptyset$，且对任意边 $(u, v) \in E$，都有 $u \in A, v \in B$ 或 $u \in B, v \in A$，则称 $G$ 为二分图。

**核心性质**：一个无向图是二分图，**当且仅当图中不存在长度为奇数的环（奇环）**。

### 染色法思想

染色法是判定二分图最直观的方法：用两种颜色（如颜色 1 和颜色 2）给图中顶点染色，要求相邻顶点颜色不同。如果能成功完成染色，则是二分图；如果在染色过程中发现相邻顶点颜色相同，则存在奇环，不是二分图。

具体步骤：
1. 任选一个起点，染成颜色 1
2. 从该点出发进行 DFS 遍历
3. 对当前节点的每个邻接点：
   - 若未染色：染成与当前节点相反的颜色，继续 DFS
   - 若已染色且颜色与当前节点相同：说明存在奇环，不是二分图
   - 若已染色且颜色不同：无需处理

### 为什么等价于无奇环

- **必要性**：若图中有奇环，则环上顶点交替染色时，绕奇环一圈后首尾颜色相同，产生矛盾
- **充分性**：若图中无奇环，则从任意点出发 BFS/DFS 交替染色不会产生冲突

## 核心状态定义与转移

### 状态定义

| 变量 | 含义 |
|------|------|
| `vis[u]` | 节点 $u$ 的染色状态：$0$ 表示未染色，$1$ 表示颜色 1，$2$ 表示颜色 2 |
| `node[0]` | 颜色为 1 的所有节点（即集合 $A$） |
| `node[1]` | 颜色为 2 的所有节点（即集合 $B$） |
| `ans` | 全局标记，表示当前是否仍为二分图 |

### 染色转移规则

DFS 函数签名：`dfs(idx, k)` —— 将节点 `idx` 染为颜色 `k`

**三种情况的处理**：

$$
\text{dfs}(u, c) =
\begin{cases}
\text{跳过} & \text{ans = false（已发现矛盾）} \\
\text{染色 u 为 c，递归所有邻接点为 } 3-c & \text{vis}[u] = 0 \text{（未染色）} \\
\text{返回（一致）} & \text{vis}[u] = c \text{（颜色相同）} \\
\text{ans = false（矛盾）} & \text{vis}[u] + c = 3 \text{（颜色冲突）}
\end{cases}
$$

其中 $3-c$ 是"取反色"的技巧：颜色 1 的反色是 2，颜色 2 的反色是 1，即 $3-1=2, 3-2=1$。

## 逐行代码解析

### 全局变量定义

```cpp
vector<vector<int>> edges;  // 邻接表
vector<int> vis, node[2];   // 染色数组 / 两个集合的节点列表
bool ans;                   // 是否为二分图的标记
```

- `edges`：邻接表存图，`edges[u]` 存储所有与 $u$ 相连的节点
- `vis`：染色数组，0 表示未访问/未染色，1 和 2 表示两种颜色
- `node[0]`、`node[1]`：分别存储染成颜色 1 和颜色 2 的节点，用于最后输出划分结果
- `ans`：全局布尔标记，一旦发现矛盾立即设为 `false`，后续 DFS 直接返回

### 初始化函数

```cpp
void init(int n)
{
	edges.assign(n + 1, vector<int>());
	vis.assign(n + 1, 0);
	node[0].clear(), node[1].clear();
	ans = true;
}
```

- `edges.assign(n + 1, vector<int>())`：为 n 个节点（编号 1~n）分配邻接表
- `vis.assign(n + 1, 0)`：所有节点初始化为未染色（0）
- `node[0].clear(), node[1].clear()`：清空两个集合
- `ans = true`：初始假设是二分图

### 加边函数

```cpp
void add(int u, int v)
{
	edges[u].emplace_back(v);
	edges[v].emplace_back(u);
}
```

无向图需要双向加边：$u$ 的邻接表加入 $v$，$v$ 的邻接表加入 $u$。

### DFS 染色核心函数

```cpp
void dfs(int idx, int k)
{
	if (!ans) return;                    // 已发现矛盾，直接返回
	if (vis[idx] == 0)                   // 情况1：未染色
	{
		vis[idx] = k;                    // 染成颜色 k
		node[k - 1].emplace_back(idx);   // 加入对应集合
		for (int i : edges[idx])         // 遍历所有邻接点
			dfs(i, 3 - k);               // 邻接点染成相反颜色
	}
	else if (vis[idx] == k) return;      // 情况2：颜色相同，无冲突
	else if (vis[idx] + k == 3)          // 情况3：颜色不同，冲突
	{
		ans = false;                     // 标记为非二分图
		return;
	}
}
```

关键要点：

1. **提前返回**：`if (!ans) return;` 是重要的优化。一旦发现矛盾，所有递归分支都无需继续
2. **染色与记录**：`vis[idx] = k` 标记颜色，同时将节点加入 `node[k-1]` 集合
3. **反色技巧**：`3 - k` 巧妙地实现颜色翻转（1→2, 2→1），比 `if/else` 更简洁
4. **冲突判定**：`vis[idx] + k == 3` 等价于"已染色且颜色不同"，因为 $1+2=3$

### 主函数

```cpp
int main()
{
	ios::sync_with_stdio(false);
	cin.tie(nullptr); cout.tie(nullptr);
	int n, m;
	cin >> n >> m;
	init(n);
	for (int i = 1; i <= m; i++)
	{
		int u, v;
		cin >> u >> v;
		add(u, v);
	}
	dfs(1, 1);          // 从节点1开始，染成颜色1
	if (ans)
	{
		cout << "Yes\n";
		for (int i : node[0]) cout << i << ' ';
		cout << '\n';
		for (int i : node[1]) cout << i << ' ';
		cout << '\n';
	}
	else cout << "No\n";
	return 0;
}
```

注意：代码注释中说明"所有的点都是联通的"，因此只需要从节点 1 启动一次 DFS。如果图可能不连通，则需要遍历所有节点，对每个未染色的连通分量分别调用 DFS。

## 复杂度分析

### 时间复杂度：$O(n+m)$

- 每个节点最多被染色一次，即每个节点最多进入一次 DFS
- 每条边最多被访问两次（无向图双向），即每个邻接关系被检查一次
- 总操作量与顶点数 $n$ 和边数 $m$ 成线性关系

### 空间复杂度：$O(n+m)$

- 邻接表存储：$O(n+m)$
- 染色数组 `vis`：$O(n)$
- 结果数组 `node[0]` 和 `node[1]`：合计 $O(n)$
- DFS 递归栈深度：最坏 $O(n)$（链状图）

## 适用场景

### 适用场景

1. **二分图判定**：判断一个无向图是否为二分图，是许多图论问题的前置步骤
2. **二部划分输出**：不仅判定是否为二分图，还输出具体的顶点划分方案
3. **匹配问题前置**：最大匹配、最小顶点覆盖等问题需要先确认图是二分图
4. **奇偶环检测**：利用"二分图等价于无奇环"的性质，检测图中是否存在奇环

### 不适用场景

1. **有向图**：二分图定义针对无向图，有向图的"二分"需另行定义
2. **需要最大匹配**：本算法只做判定和划分，不求解最大匹配（需用匈牙利算法等）
3. **图不连通且只调用一次 DFS**：需要确保对每个连通分量都进行染色

## 常见陷阱与注意事项

### 1. 图不连通的情况

代码假设图是连通的（注释中明确说明）。如果图可能有多个连通分量，必须遍历所有节点：

```cpp
for (int i = 1; i <= n; i++)
{
    if (vis[i] == 0)
    {
        dfs(i, 1);
        if (!ans) break;
    }
}
```

否则某些连通分量未被染色，可能漏判奇环。

### 2. 起点颜色的选择

从哪个点开始、初始染成什么颜色不影响判定结果。二分图的两个集合是对称的，交换颜色 1 和 2 仍然是合法划分。

### 3. ans 标记的全局传递

`ans` 是全局变量，一旦变为 `false`，所有递归分支应立即返回。代码开头的 `if (!ans) return;` 是必要的剪枝，避免无效搜索。

### 4. 反色技巧的正确性

`3 - k` 只在颜色取值为 1 和 2 时成立。如果颜色用 0 和 1 表示，则反色应为 `1 - k`。

### 5. 节点编号从 1 开始

代码中节点编号从 1 开始（`init` 中分配 `n+1` 个空间，主函数从节点 1 开始 DFS）。如果题目中节点从 0 开始，需要调整数组大小和遍历范围。

### 6. 自环的情况

如果图中存在自环（节点到自身的边），则一定不是二分图。从节点 $u$ 出发遍历到邻接点 $u$（自环）时，`vis[u] == k`，而邻接点本应染成 `3-k`；代码先判断 `vis[idx] == k` 并直接返回，因此**自环不会被检测为冲突**，需要在加边时或 DFS 前单独判断。

这是一个需要注意的边界情况。如果图中可能有自环，需要在加边时或 DFS 前单独判断。

## 对比与扩展

### 与 BFS 染色法对比

| 对比维度 | DFS 染色法 | BFS 染色法 |
|----------|-----------|-----------|
| 遍历方式 | 深度优先，递归或栈实现 | 广度优先，队列实现 |
| 时间复杂度 | $O(n+m)$ | $O(n+m)$ |
| 空间复杂度 | $O(n+m)$，递归栈最坏 $O(n)$ | $O(n+m)$，队列最坏 $O(n)$ |
| 实现难度 | 递归实现简洁直观 | 迭代实现稍长但无栈溢出风险 |
| 栈溢出风险 | 链状图可能栈溢出（n 极大时） | 无栈溢出风险 |
| 适用场景 | 图规模不大、递归深度可控 | 大规模图、避免栈溢出 |

### 扩展：带权二分图

本算法处理的是无权二分图的判定。带权二分图的经典问题包括：
- **二分图最大匹配**：匈牙利算法，时间复杂度 $O(nm)$
- **二分图最大权匹配**：KM 算法，时间复杂度 $O(n^3)$
- **二分图最小顶点覆盖**：Konig 定理，等于最大匹配数
- **二分图最大独立集**：等于顶点数减去最小顶点覆盖

### 扩展：二分图与 2-SAT

2-SAT 问题可以通过构造蕴含图并求强连通分量来解决，而二分图判定和 2-SAT 有着深刻的联系：二分图的染色约束本质上就是一种"二选一"的约束关系，类似 2-SAT 中的变量赋值。

## 附：匈牙利算法（二分图最大匹配）

匈牙利算法（Hungarian Algorithm）由匈牙利数学家 König 和 Egerváry 的理论发展而来，是求解**二分图最大匹配**的经典算法。核心思想基于**增广路定理**：一个匹配是最大匹配，当且仅当图中不存在增广路。

#### 基本概念

**二分图匹配**：在二分图 $G = (A \cup B, E)$ 中，选取一组边 $M \subseteq E$，使得 $M$ 中任意两条边没有公共端点，则 $M$ 称为一个匹配。边数最多的匹配称为**最大匹配**。

**增广路**：设 $M$ 是当前匹配。一条从**未匹配点**出发，交替经过**非匹配边**和**匹配边**，最终到达另一侧的**未匹配点**的路径，称为增广路（Augmenting Path）。

增广路的长度一定是奇数，且首尾都是非匹配边。

#### 增广路定理

**定理**：一个匹配 $M$ 是最大匹配 $\Leftrightarrow$ 图中不存在关于 $M$ 的增广路。

**推论**（增广路算法的正确性基础）：如果能找到一条增广路 $P$，将 $P$ 上的匹配边与非匹配边互换，匹配数增加 1。反复寻找增广路直到不存在，即得到最大匹配。

#### 算法框架

1. 初始匹配为空集
2. 遍历左部每个未匹配点 $u$，尝试从 $u$ 出发寻找增广路
3. DFS 搜索：对 $u$ 的每个邻接点 $v$
   - 若 $v$ 未被匹配：直接匹配 $u \leftrightarrow v$，增广成功
   - 若 $v$ 已匹配给 $w$：递归尝试为 $w$ 寻找新的匹配，若成功则将 $v$ 让给 $u$
4. 若所有左部点都尝试完毕，当前匹配即为最大匹配

#### 时间戳优化

朴素实现中，每次 DFS 前需要清空 `vis` 数组标记右侧节点的访问状态。本代码使用**时间戳优化**：用整数 `t` 标记当前轮次，`vis[i] == t` 表示节点 $i$ 在本轮 DFS 中已访问，无需每次清空数组，将每次增广的初始化代价从 $O(m)$ 降为 $O(1)$。

### 核心公式/状态定义与转移方程

#### 状态定义

| 变量 | 含义 |
|------|------|
| `edges[u]` | 左部点 $u$ 的邻接表，存储所有可到达的右部点 |
| `match[v]` | 右部点 $v$ 当前匹配的左部点编号，0 表示未匹配 |
| `vis[v]` | 右部点 $v$ 的访问时间戳，记录是第几轮 DFS 访问的 |
| `t`（DFS 参数） | 当前轮次标识，等于当前左部点编号 $i$ |

#### 转移方程

对左部点 `idx`，DFS 寻找增广路的递归逻辑：

$$
\text{dfs}(u, t) =
\begin{cases}
\text{true} & \exists\, v \in \text{edges}[u],\; \text{vis}[v] \neq t,\; \text{match}[v] = 0 \\
\text{true} & \exists\, v \in \text{edges}[u],\; \text{vis}[v] \neq t,\; \text{dfs}(\text{match}[v], t) = \text{true} \\
\text{false} & \text{否则}
\end{cases}
$$

成功时更新 `match[v] = u`。

#### 增广路的结构

一条增广路形如：

$$
u_0 \xrightarrow{\text{非匹配}} v_0 \xrightarrow{\text{匹配}} u_1 \xrightarrow{\text{非匹配}} v_1 \xrightarrow{\text{匹配}} \cdots \xrightarrow{\text{非匹配}} v_k
$$

其中 $u_0$ 和 $v_k$ 是未匹配点。取反后匹配数 $+1$。

### 逐行代码解析

#### 全局变量定义

```cpp
vector<vector<int>> edges;  // 左边点的邻接表
vector<int> match;           // 右边节点配对的左边点
vector<int> vis;             // 右边节点访问时间戳
int top;                      // （未使用）
```

- `edges`：只存**左部→右部**的有向边（二分图匹配中边是单向使用的）
- `match`：下标是右部点，值是左部点，`match[v] = u` 表示 $v$ 匹配了 $u$，0 表示未匹配
- `vis`：时间戳数组，`vis[v] = t` 表示 $v$ 在第 $t$ 轮 DFS 中被访问过

#### 初始化函数

```cpp
void init(int n, int m)
{
	edges.assign(n + 1, vector<int>());
	vis.assign(m + 1, false);
	match.assign(m + 1, 0);
	top = 0;
}
```

- `edges.assign(n + 1, ...)`：为 $n$ 个左部点分配邻接表
- `vis.assign(m + 1, false)`：时间戳初始化为 0（所有轮次标识都大于 0，故等价于"未访问"）
- `match.assign(m + 1, 0)`：所有右部点初始未匹配

#### DFS 增广核心函数

```cpp
bool dfs(int idx, int t)
{
	for (int i : edges[idx])
	{
		if (vis[i] == t) continue;    // 本轮已访问，跳过
		vis[i] = t;                    // 标记本轮已访问
		if (!match[i] || dfs(match[i], t))  // 右部点未匹配 或 其匹配者可换边
		{
			match[i] = idx;            // 将右部点 i 匹配给左部点 idx
			return true;               // 增广成功
		}
	}
	return false;                      // 所有邻接点都无法增广
}
```

逐行分析关键行：

1. **`if (vis[i] == t) continue;`**：时间戳判重。若 $i$ 在本轮已被访问，说明从 $i$ 出发的递归增广已经失败过，无需重复尝试。这一步保证了每个右部点在单轮 DFS 中最多被访问一次。

2. **`vis[i] = t;`**：在递归前标记访问，防止递归过程中形成环（同一右部点被多次访问导致死循环）。

3. **`if (!match[i] || dfs(match[i], t))`**：增广的两种成功情况：
   - `!match[i]`：右部点 $i$ 未匹配，直接匹配，增广成功
   - `dfs(match[i], t)`：右部点 $i$ 已匹配给 `match[i]`，递归尝试为 `match[i]` 寻找新的匹配。若成功，则 $i$ 让给当前节点 `idx`

4. **`match[i] = idx;`**：更新匹配关系。注意此时可能已经递归修改了 `match[i]` 原匹配者的匹配关系，所以这里只需设置 $i$ 的新匹配。

#### 主函数

```cpp
int main()
{
	ios::sync_with_stdio(false);
	cin.tie(nullptr); cout.tie(nullptr);
	int n, m, e;
	cin >> n >> m >> e;
	init(n, m);
	for (int i = 1; i <= e; i++)
	{
		int u, v;
		cin >> u >> v;
		edges[u].emplace_back(v);
	}
	int cnt = 0;
	for (int i = 1; i <= n; i++)
	{
		if (dfs(i, i)) ++cnt;
	}
	cout << cnt;
	return 0;
}
```

关键点：

- **输入**：$n$ 个左部点，$m$ 个右部点，$e$ 条边。边只从左到右添加（单向）
- **`dfs(i, i)`**：第 $i$ 轮 DFS 的时间戳就是 $i$ 本身，这样每轮的时间戳天然唯一，无需额外维护计数器
- **`cnt`**：统计成功增广的次数，即最大匹配数

### 复杂度分析

#### 时间复杂度：$O(nm)$

- 外层循环遍历 $n$ 个左部点，每次调用 DFS
- 单次 DFS 最坏情况遍历所有 $m$ 条边（递归深度可达 $n$）
- 总复杂度 $O(n \cdot m)$，其中 $n$ 为左部点数，$m$ 为边数

实际运行中，由于时间戳判重使每个右部点在单轮 DFS 中最多访问一次，单轮 DFS 的实际复杂度更接近 $O(m)$ 而非 $O(nm)$，但最坏上界仍为 $O(nm)$。

#### 空间复杂度：$O(n + m)$

- 邻接表 `edges`：$O(n + m)$（$n$ 个左部点的邻接表，共 $m$ 条边）
- `match` 数组：$O(m)$
- `vis` 数组：$O(m)$
- DFS 递归栈深度：最坏 $O(n)$

### 适用场景

#### 适用场景

1. **二分图最大匹配**：最基本的用途，如任务分配、人员调度
2. **二分图最小点覆盖**：由 König 定理，最小点覆盖数 = 最大匹配数
3. **二分图最大独立集**：最大独立集 = 顶点总数 $-$ 最大匹配数
4. **最小路径覆盖**：将 DAG 拆分为最少路径，需先拆点二分图化再用匈牙利算法
5. **棋盘问题**：将棋盘黑白染色后建二分图，求解最多放置互不攻击的棋子数

#### 不适用场景

1. **一般图最大匹配**：匈牙利算法仅适用于二分图，一般图需用带花树（Blossom Algorithm）
2. **带权最大匹配**：需要最大权匹配时，应使用 KM 算法（Kuhn-Munkres）
3. **超大规模二分图**：$n, m$ 极大（如 $10^6$ 级）时，$O(nm)$ 可能超时，需考虑 Hopcroft-Karp 算法

### 常见陷阱与注意事项

#### 1. 建图方向

二分图匹配中，邻接表**只需从左部到右部单向建边**。如果双向建边，DFS 时可能错误地从右部走回左部，导致逻辑混乱。代码中 `edges[u].emplace_back(v)` 只加了左→右的边。

#### 2. 时间戳的唯一性

代码中 `dfs(i, i)` 直接用左部点编号 $i$ 作为时间戳。这要求左部点编号从 1 开始且互不相同。如果左部点编号有特殊含义（如从 0 开始），需要改为 `dfs(i, i + 1)` 或使用独立的时间戳计数器，确保时间戳不为 0（因为 `vis` 初始值为 0 表示未访问）。

#### 3. match 数组的语义

`match[v]` 存的是右部点 $v$ 匹配的**左部点编号**，不是反过来。如果混淆左右部语义，会导致输出结果错误。

#### 4. 多组数据的初始化

如果有多组测试数据，每次必须调用 `init` 清空 `edges`、`match`、`vis`。忘记初始化是常见的 WA 原因。

#### 5. 自环边和重边

二分图中不应有自环（左部和右部是不同集合，自环无意义）。重边不影响正确性但浪费空间，可以在加边时去重。

#### 6. 左右部点数不对称

代码中 $n$（左部）和 $m$（右部）可以不相等。遍历左部点 $1 \sim n$ 即可，不需要遍历右部点。最大匹配数 $\leq \min(n, m)$。

#### 7. `top` 变量未使用

代码中全局变量 `top` 声明了但未使用，属于冗余代码，可以删除。

### 对比与扩展

#### 与 Hopcroft-Karp 算法对比

| 对比维度 | 匈牙利算法 | Hopcroft-Karp |
|----------|-----------|----------------|
| 核心思想 | 单条增广路逐次增广 | 每轮找一组最短增广路批量增广 |
| 时间复杂度 | $O(nm)$ | $O(m\sqrt{n})$ |
| 实现难度 | 简单，DFS 递归 | 较复杂，需 BFS 分层 + DFS |
| 适用规模 | $n, m \leq 500$ | $n, m \leq 10^5$ |
| 常数因子 | 小 | 稍大（BFS 分层开销） |

#### 与 KM 算法对比

| 对比维度 | 匈牙利算法 | KM 算法 |
|----------|-----------|---------|
| 问题类型 | 无权最大匹配 | 带权最大权匹配 |
| 时间复杂度 | $O(nm)$ | $O(n^3)$ |
| 核心思想 | 增广路 | 顶标 + 相等子图 + 增广 |
| 适用场景 | 无权二分图 | 每条边有权值，求权值和最大的匹配 |

#### 扩展：Konig 定理

二分图中有三个经典等式：

- **最小点覆盖 = 最大匹配数**：选择最少的顶点覆盖所有边
- **最大独立集 = 顶点总数 $-$ 最大匹配数**：选择最多的互不相邻的顶点
- **最小路径覆盖 = 顶点总数 $-$ 最大匹配数**（DAG 上，拆点后）

这些定理使匈牙利算法成为解决二分图各类覆盖、独立集问题的核心工具。

#### 扩展：一般图最大匹配

一般图（非二分图）的最大匹配需要处理**奇环**（花，Blossom）的情况。带花树算法（Edmonds' Blossom Algorithm）通过"缩花"操作将奇环收缩为一个点，时间复杂度 $O(n^3)$，是匈牙利算法在一般图上的推广。

## 算法原理

有向图用 SCC 处理“互相可达”，无向图则要处理“删掉一条边还连不连通”。**边双连通分量（Edge-Biconnected Component，E-DCC）** 是无向图里的极大边双连通子图：分量内任意两点之间，删去任意一条边都不会断开；等价地说，任意两点之间至少有两条**边不相交**的路径。

这个等价性可以用最大流最小割定理证明：若两点之间不存在两条边不相交路径，则它们之间的最小割只有一条边，删掉这条边就断开。竞赛里通常直接把它当作结论使用。

### 无向图 DFS 的边分类

无向图做 DFS 时，边只有两类：

- **树边**：DFS 生成树内部的边；
- **返祖边**：从后代指回祖先的边。

不会出现横叉边：如果一条边从一个子树指向另一个子树，那么无向边会让另一个子树在更早的时候顺着这条边搜过来，两个子树根本不会被分成两棵。正因为没有横叉边，求边双时**不需要像 SCC 那样判断点是否在栈中**。

一条树边 $u\to v$ 是**桥**，当且仅当 $v$ 的子树里没有任何返祖边能跨过这条树边回到 $u$ 或 $u$ 的祖先，也就是

$$
\mathrm{low}[v] > \mathrm{dfn}[u].
$$

把所有桥删掉，剩下的每个连通块就是一个 E-DCC；把每个 E-DCC 缩成一个点，桥就是缩点树上的边，缩点结果一定是**一棵树**。

### 防止走回头路

无向边在邻接表里会被存成两条有向边。DFS 时如果直接从 $v$ 走回 $u$，就会把来时的边当成一条“返祖边”，low 被错误更新，桥就判不出来。

常见写法有两种：

- 记录父节点，禁止走回父节点；
- 记录来时的**边编号**，禁止走回同一条边。

这里必须用第二种。原因是**重边**：如果 $u$ 和 $v$ 之间有两条边，那么从 $u$ 走第一条到 $v$ 后，完全可以从第二条边回到 $u$，这是一条合法的返祖边；如果只记录父节点，就会把这条合法的回去路径也禁掉，导致误判桥。

### 异或配对

建图时把一条无向边拆成两条有向边，编号成对分配：

```
add(u, v):  to[idx] = v; ne[idx] = h[u]; h[u] = idx++;
add(v, u):  to[idx] = u; ne[idx] = h[v]; h[v] = idx++;
```

若第一条边的编号是 $i$，第二条就是 $i\oplus 1$（异或 1 相当于翻转最低位）。DFS 进入 $u$ 时带上来时的边编号 `last`，枚举到边 $i$ 时，只要 `i == (last ^ 1)` 就说明这是来时的反向边，直接跳过。重边有各自的编号，不会被误跳。

### 缩点后的树

求出所有 E-DCC 后，枚举原图的每条边：若两端属于不同分量，就在缩点图上加边。由于每条这样的边都是桥，缩点图没有环，是一棵树。

边双缩点后的常见套路全部是树上问题：

- 求 LCA、树上倍增；
- DFS 序、树上差分；
- 树链剖分、线段树；
- 树的直径、树形 DP。

## 核心公式 / 状态定义与转移方程

边双的 Tarjan 与 SCC 形状相似，只是多了“跳过反向边”，并且不需要栈内标记：

$$
\mathrm{low}[u]=\min\left(\mathrm{dfn}[u],\ \min_{v\in T_u}\mathrm{low}[v],\ \min_{v\in B_u}\mathrm{dfn}[v]\right),
$$

其中 $T_u$ 是树边儿子，$B_u$ 是返祖边指向的已访问点。桥的判定是 $\mathrm{low}[v]>\mathrm{dfn}[u]$；当 $\mathrm{low}[u]=\mathrm{dfn}[u]$ 时，弹栈得到 $u$ 所在的一个 E-DCC。

伪代码：

```
tarjan(u, last_edge):
    dfn[u] = low[u] = ++timer
    stack.push(u)
    for each edge i from u to v:
        if i == (last_edge ^ 1): continue      // 不走反向边
        if dfn[v] == 0:
            tarjan(v, i)
            low[u] = min(low[u], low[v])
        else:
            low[u] = min(low[u], dfn[v])
    if dfn[u] == low[u]:
        repeat:
            y = stack.pop()
            把 y 归入当前 E-DCC
        until y == u
```

缩点树上的两个常用结论：

- 让整张图变成边双，至少需要加的边数是 $\left\lceil \dfrac{\text{叶子数}}{2}\right\rceil$；
- 缩点树上两点距离：$\mathrm{dist}(u,v)=\mathrm{dep}[u]+\mathrm{dep}[v]-2\,\mathrm{dep}[\mathrm{lca}(u,v)]$。

## 逐行代码解析

这一版没有配套的 `.cpp`，下面按模块说明实现要点；片段是结构示意，不是完整可提交程序。

### 模块一：成对建边

`add(u, v)` 只负责把一条有向边接到 `u` 的链表头，`idx` 递增。主函数里对每条无向边连续调用两次 `add`，保证正反边编号相邻、异或为 1。

### 模块二：跳过反向边

`tarjan(u, last)` 的第二个参数是进入 $u$ 的边编号。枚举到 `i == (last ^ 1)` 时跳过，其余边正常处理。根节点传一个不会与任何边配对的哨兵值即可；由于边编号从 0 开始成对分配，传 0 时只会跳过编号 1 的反向边，不会误伤根的真实出边。

### 模块三：low 的更新与弹栈

树边递归后取 `min(low[u], low[v])`；返祖边取 `min(low[u], dfn[v])`。递归结束若 `dfn[u] == low[u]`，从栈顶弹到 $u$，这一段就是一个 E-DCC。无向图没有横叉边，所以不需要 `in_stack` 判断。

### 模块四：孤立点与自环

主函数枚举每个点：若 `h[i] == -1`（没有任何有效边），它自己就是一个 E-DCC；否则若未访问就调用 `tarjan(i, 0)`。自环对连通性没有贡献，读入时直接跳过，避免自环被当成反向边或重复计数。

## 复杂度分析

Tarjan 每个点入栈、出栈各一次，每条边只枚举常数次，时间复杂度 $O(n+m)$；空间为邻接表与若干 $O(n)$ 数组，合计 $O(n+m)$。

缩点后建树也是 $O(n+m)$。若在缩点树上做 LCA/树剖，单次询问 $O(\log n)$，预处理 $O(n\log n)$ 或 $O(n)$。

## 适用场景

- 求无向图的桥、边双连通分量；
- 加最少的边使整张图边双连通（叶子配对）；
- 路径必经边、边双缩点后的树上距离/差分；
- 网络可靠性中“删一条边是否仍连通”的建模。

看到“无向图 + 删边仍连通”“至少两条边不相交路径”“缩点后变成树”，优先考虑边双。

## 常见陷阱与注意事项

- **用父节点防回头**：重边会被误判成桥，必须记录边编号并用异或跳过反向边。
- **把无向图当有向图写**：无向图没有横叉边，多写 `in_stack` 判断不会错，但会掩盖对边分类的理解；求桥时关键在反向边。
- **自环没过滤**：自环对 E-DCC 没有贡献，读入时跳过最省事。
- **图不保证连通**：主函数必须枚举所有未访问点；孤立点要单独算一个分量。
- **桥的判定写反**：树边 $u\to v$ 的桥条件是 `low[v] > dfn[u]`，不是 `>=`；等号表示还能绕回 $u$，不是桥。
- **缩点后不判重边**：重边不影响树的连通性，但会影响度数统计；叶子数按缩点后的树统计，重复边不要重复加度数。
- **叶子数公式的边界**：缩点树只有一个点时叶子数为 0，答案是 0；两个点时叶子数为 2，答案是 1。
- **递归深度**：链状无向图递归深度可达 $n$，注意栈空间。

## 对比与扩展

| 分量 | 图类型 | 删什么仍连通 | 判定 | 缩点结果 |
|---|---|---|---|---|
| SCC | 有向图 | 互相可达 | `low[u] == dfn[u]` + 栈内判断 | DAG |
| E-DCC | 无向图 | 删任意一条边 | 桥：`low[v] > dfn[u]` | 树 |
| v-DCC | 无向图 | 删任意一个点 | 割点：`low[v] >= dfn[u]` | 圆方树 |

经典例题：

- **P8436【模板】边双连通分量**：输出 E-DCC 个数与每个分量的点集，注意重边、自环、图不连通；
- **USACO06JAN Redundant Paths G**：边双缩点成树后，答案是把叶子两两配对所需的最少边数，即 $\lceil \text{叶子数}/2\rceil$；
- **P10953 逃不掉的路**：边双缩点后把询问转成树上两点距离，用 LCA/树剖计算。

边双是“删边”的连通性；下一篇点双处理“删点”，缩点结果会从树升级成圆方树。

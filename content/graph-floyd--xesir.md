## 算法原理

Floyd 解决的是**多源最短路**（求任意两点之间的最短路），**边权可正可负**，但不能有负环。

核心思想是**动态规划**：设 $f[k][i][j]$ 表示"只把编号 $1..k$ 的点当作中间点，从 $i$ 到 $j$ 的最短路长度"，初始为 `INF`。转移就是一句话——要么不经过 $k$，要么经过 $k$ 作为中转：

$$f[k][i][j] = \min\big(f[k-1][i][j],\ f[k-1][i][k] + f[k-1][k][j]\big)$$

**特点**：实现极其简单（就三层循环），能处理负权；顺便还能求路径的传递闭包（比如判断两点是否连通）。虽然复杂度比较高，但它一轮就能求出任意两点最短路，适合稠密图、且需要反复查询最短路信息的问题。

## 核心公式 / 状态定义与转移方程

朴素状态（三维）：

$$f[k][i][j] = \min\big(f[k-1][i][j],\ f[k-1][i][k] + f[k-1][k][j]\big)$$

实际代码中把第一维滚动掉，变成 $f[i][j]$：

$$f[i][j] = \min\big(f[i][j],\ f[i][u] + f[u][j]\big)$$

初始化：$f[i][i] = 0$，其余为 `INF`；然后逐条边 `f[a][b] = min(f[a][b], c)`。最后三层循环 $u, x, y$（中转点 $u$ 必须在最外层）。

## 逐行代码解析

下面把整份模板按模块拆开讲，各块按顺序拼起来就是完整代码。

### 模块一：头文件与全局数组

```cpp
#include <bits/stdc++.h>
using namespace std;
int f[210][210];
const int INF=1e9;
```

- `f[210][210]` 就是邻接矩阵，直接在全局开好；`f[i][j]` 表示 $i$ 到 $j$ 的最短路。
- `INF = 1e9` 作无穷大：因为 Floyd 里会出现 `INF + INF`，用 `1e9` 相加约 $2\times10^9$，还在 `int` 范围内不会溢出。

### 模块二：初始化与读边

```cpp
int main(){
   
    int n,m,k;cin >> n >> m>>k;
    for(int i=1;i<=n;i++){
        for(int j=1;j<=n;j++){
            if(i!=j) f[i][j]=INF;
            else f[i][j]=0;
        }
    }
    for(int i = 1; i <= m; i ++) {
        int a, b; cin >> a >> b;
        int c; cin >> c;
        f[a][b]=min(f[a][b],c);
    }
```

- 读入 $n$ 个点、$m$ 条边，以及后面的 $k$ 次询问。
- 初始化：到自己的距离为 `0`，到别人的距离为 `INF`。
- 读边时用 `f[a][b]=min(f[a][b],c)`，这样**重边**会自动取最小那条。这里是有向边，无向图要再补 `f[b][a]`。

### 模块三：Floyd 三层循环

```cpp
    for (int u = 1; u <= n; u++) {
        for (int x = 1; x <= n; x++) {
            for (int y = 1; y <= n; y++) {
                f[x][y] = min(f[x][y], f[x][u] + f[u][y]);
            }
        }
    }
```

- 三层循环，中转点 `u` 在最外层（这点很关键）。
- `f[x][y] = min(f[x][y], f[x][u] + f[u][y])` 就是那句转移：要么不使用中转点 `u`，要么用 `x → u → y` 这条更短的路。

### 模块四：处理询问

```cpp
    for(int i=1;i<=k;i++){
        int x,y;cin>>x>>y;
        if(f[x][y] == INF) cout << "impossible" << endl;
        else cout << f[x][y] << endl;
    }
}
```

- 读 $k$ 次询问，每次读一对 $(x, y)$，查 `f[x][y]`。
- 若仍为 `INF` 说明两点不连通，输出 `"impossible"`，否则输出距离。

## 复杂度分析

- 时间复杂度：$O(n^3)$，三层循环各 $n$ 次，和边数 $m$ 无关。
- 空间复杂度：$O(n^2)$，就是那个邻接矩阵。

## 适用场景

多源（任意两点）最短路、稠密图、需要反复查询最短路信息、求传递闭包等。因为 $O(n^3)$，一般只在 $n$ 比较小（大约几百以内）时用。

## 常见陷阱与注意事项

1. **循环顺序**：中转点那一维必须在最外层，把 `i`、`j` 写在外层会导致用"本轮的中间结果"去更新，答案错误。
2. **`INF` 相加溢出**：转移里有 `f[x][u] + f[u][y]`，若 `INF` 取太大（如 `INT_MAX`）会溢出成负数；用 `1e9` 就比较稳。
3. **重边要取 min**：本代码用 `min(f[a][b], c)`，如果直接赋值就会丢掉更短的边。
4. **无向图少建边**：只写了 `f[a][b]`，无向图还要补 `f[b][a] = f[a][b]`。
5. **负环**：有负环时 Floyd 结果没有意义；可以通过检查 `f[i][i] < 0` 来发现负环。

## 对比与扩展

和跑 $n$ 次 Dijkstra（$O(nm\log n)$）或 Johnson 比，Floyd 代码最短、还能顺带求传递闭包，但只适合小图；和 SPFA/Dijkstra 比，那些是单源，Floyd 是"一次算全源"。要点是：$n$ 小 + 稠密 + 要反复查，就选 Floyd。

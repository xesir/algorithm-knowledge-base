## 算法原理

~~xkl~~

> 原先的树链剖分主题在线段树位置，然而树剖作为一种图论算法应用很多，不能简单的视为线段树的附庸，故移至此处。

树链剖分（或重链剖分，**HLD**）是一种将树上问题转化为序列问题的技巧。它本身并不负责维护"和""最大值"或"最小值"等具体信息，功能是**把树上的路径或子树表示成若干个连续的序列区间**，以便能够按维护序列的方式维护树上信息。至于这些区间上的信息如何维护，则交给线段树、树状数组或其他合适的数据结构。

### 引入：从序列到树

在线性序列上，区间 $[l,r]$ 是连续的一段，可以很容易地交给线段树或树状数组处理。但在树上，两个节点之间的路径可能弯来弯去。例如要查询节点 $u$ 到节点 $v$ 路径上的点权和，路径上的节点并不对应某个简单的编号区间。一种直接做法是从 $u$ 和 $v$ 不断向上跳到最近公共祖先，但最坏情况下路径长度可能达到 $O(n)$；如果有 $q$ 次询问，复杂度就可能达到 $O(nq)$。

树链剖分的做法是：把树拆成若干条链，给每条链上的节点重新编号，使同一条链上的节点编号连续。这样我们就能把任意一条树上路径拆成若干段链，把每段链转化为一个序列区间，从而用维护序列的方式维护它。显然这种操作的复杂度取决于剖分方式，这里介绍理论复杂度最优、OI 中最常见的剖分算法——重链剖分。

### 重儿子 / 重边 / 重链

首先任选一个节点作为根，之后树就具有了父子关系、深度和子树等概念。

对于每个节点 $u$，在它所有儿子中选择一个子树大小最大的儿子，称为 $u$ 的**重儿子**，剩下的称轻儿子（有多个儿子的子树大小相同，任选一个即可）。连接 $u$ 与重儿子的边称为**重边**，其他连接父子节点的边称为**轻边**；若干条连续的重边构成一条**重链**。特别地，没有重儿子的节点自身可以看成一条只包含自己的重链。

例如：

```text
        1
      / | \
     2  3  4
    / \
   5   6
```

如果节点 $2$ 的子树最大，那么 $1\to2$ 是重边，$1\to3$ 和 $1\to4$ 是轻边；节点 $2,5,6$ 中，若 $5$ 是重儿子，则 $2\to5$ 是重边，而 $2\to6$ 是轻边。得到重链以后，按 DFS 序把它映射到序列上，就得到了重链剖分的序列。

### 为什么轻边不会太多（复杂度证明）

可以证明重链剖分后维护序列信息的复杂度是 $O(n \log n)$，因为剖分后的轻边不会太多，这也是树链剖分能够高效工作的关键。证明如下：

设 $v$ 是 $u$ 的轻儿子。因为 $v$ 不是重儿子，所以一定存在 $u$ 的某个儿子 $w$，满足 $siz[w]\ge siz[v]$。同时，$u$ 的子树至少包含节点 $u$ 自身、子树 $v$ 和子树 $w$，因此可以得到：

$$
siz[u]\ge 1+siz[v]+siz[w]\ge 2siz[v]+1
$$

也就是说，沿着一条轻边向下走时，子树大小至少缩小一半。所以，从任意节点向根移动时，最多经过 $O(\log n)$ 条轻边。由于两点路径可以从两端分别向上跳，因此任意两点之间的路径最多可以被拆成 $O(\log n)$ 条重链上的连续区间——这就是树链剖分的复杂度保证。

> 注：树链剖分的本身复杂度是 $O(n)$ 的，只是维护序列时通常要多一个 $\log$。

## 核心公式 / 状态定义与转移方程

树链剖分通常通过两次 DFS 完成，需要维护以下信息：

| 数组 | 含义 |
|---|---|
| `fah[u]` | 节点 $u$ 的父节点 |
| `dep[u]` | 节点 $u$ 的深度 |
| `siz[u]` | 节点 $u$ 的子树大小 |
| `son[u]` | 节点 $u$ 的重儿子 |
| `top[u]` | 节点 $u$ 所在重链的链顶 |
| `seg[u]` | 节点 $u$ 对应到序列的编号 |
| `rev[u]` | 序列上第 $u$ 个位置对应的树上节点，即 $rev[seg[v]]=v$ |

其中前 $4$ 个信息在第一个 DFS 中计算，后 $3$ 个信息在第二轮 DFS 中计算。

### 两条关键性质

树链剖分编号后，有两个特别实用的性质：

1. **同一条重链上的节点连续**（显而易见）。如果 $u$ 和 $v$ 在同一条重链上，并且 $u$ 是链顶到 $v$ 之间的祖先，那么它们对应的编号区间为 $[seg[u],seg[v]]$。因此链上的一段路径就变成了普通序列上的一段区间。
2. **一棵子树对应连续区间**。由于 DFS 会完整访问完一个节点的子树后才离开，所以节点 $u$ 的子树对应 $[seg[u],\ seg[u]+siz[u]-1]$。这意味着子树操作不需要逐个遍历节点，直接处理一个连续区间即可。

> （第 2 条实际上与树链剖分中的"重边"无关，普通 DFS 序也有此性质。但树链剖分通常同时维护 DFS 序，所以可以统一处理路径和子树问题。）

## 逐行代码解析

下面把模板按模块拆开，各模块按顺序拼接起来就是 `codePath` 指向的 `.cpp`。

### dfs1：求深度、父节点、子树大小、重儿子

```cpp
void dfs1(int x,int f){
	dep[x]=dep[f]+1;
	fah[x]=f;
	siz[x]=1;
	for(int i:G8[x]){
		if(i==f) continue;
		dfs1(i,x);
		siz[x]+=siz[i];
		if(siz[son[x]]<siz[i]) son[x]=i;
	}
}
```

- 进入时 `dep[x]=dep[f]+1` 由父亲深度加一，同时记录父节点 `fah[x]`、把 `siz[x]` 初始化为 1（包含自身）。
- 遍历邻接表 `G8[x]`，`i==f` 是回去的父边，直接跳过。
- 先递归 `dfs1(i,x)` 把儿子处理完，再 `siz[x]+=siz[i]` 累加子树大小，并用 `if(siz[son[x]]<siz[i]) son[x]=i` 边累加边挑出子树最大的儿子（重儿子）。
- `son[x]` 初值为 0、`siz[0]=0`，靠这个哨兵让第一个儿子自然成为重儿子候选。

### dfs2：重链优先编号

```cpp
//该代码中 seg[0] 表示当前节点数，需初始化为 0
void dfs2(int x,int f) {
	top[x]=f;
	seg[x]=++seg[0];
	rev[seg[0]]=x;
	if(son[x]) dfs2(son[x],f);
	for(int i:G8[x]){
	    if(i!=fah[x]&&i!=son[x]) dfs2(i, i);
	}
}
```

- 参数 `f` 传入的是**链顶**：第一次调用 `dfs2(root, root)`，之后重儿子继承同一个链顶。
- `seg[0]` 被当作"当前节点计数"使用（所以必须初始化为 0），`++seg[0]` 给它分配新编号，并同步记录反向映射 `rev[seg[0]]=x`。
- **先递归重儿子**（`if(son[x]) dfs2(son[x],f)`），保证同一条重链上的节点编号连续——这是重链剖分能成立的关键顺序。
- 再遍历轻儿子，每个轻儿子自己开一条新链（`dfs2(i, i)`）；循环里要同时判 `i!=fah[x]`（不回父）和 `i!=son[x]`（重儿子已经走过）。

## 复杂度分析

- **预处理**（两次 DFS）：$O(n)$。
- **树链剖分本身**：$O(n)$；任意两点之间的路径最多被拆成 $O(\log n)$ 条重链上的连续区间，单棵子树对应 $1$ 个区间。
- **维护序列信息**：通常要多一个 $\log$（每段区间交给线段树 / 树状数组），原文给出的整体量级是 $O(n\log n)$。
- **空间**：$O(n)$，即七个长度为 $n$ 的数组加上邻接表。

## 适用场景

1. **把树上路径转成序列区间**：路径求和 / 求最值 / 路径加，接上线段树或树状数组即可维护。
2. **子树整体操作**：利用 $[seg[u],\ seg[u]+siz[u]-1]$ 这一个连续区间，子树加 / 子树求和不必逐个遍历节点。
3. **求 LCA**：两端不断向上跳链顶，最后回到同一条链时深度较小的那个点就是 LCA（重链剖分求 LCA 的副产品）。
4. 当树结构**静态**、且需要**在线**处理路径 / 子树问题时，树链剖分是最实用的选择。

## 常见陷阱与注意事项

1. **dfs2 必须先递归重儿子**：否则同一条重链上的节点在序列中不连续，后续区间操作全错。
2. **`seg[0]` 要清零**：模板把 `seg[0]` 当节点计数器用，多组数据 / 多次调用前必须重置为 0。
3. **dfs2 的两个跳过条件缺一不可**：只判 `i!=fah[x]` 会把重儿子再走一遍；只判 `i!=son[x]` 会沿父边爬回去。
4. **`son[x]` 初值为 0、`siz[0]=0`**：靠这个哨兵让第一个儿子自然成为候选；若 0 在题里是合法节点要额外小心。
5. **链顶与节点深度别混**：跳链时比较的是链顶深度 `dep[top[u]]`，不是 `dep[u]`。
6. **同链收尾别漏**：两端跳到同一条链后，用深度较小者作为区间左端 `[seg[u],seg[v]]`，最后这一段不能忘。
7. **递归爆栈**：链状树会让 dfs1 / dfs2 递归到 $O(n)$ 层，必要时开大栈或改写迭代版。

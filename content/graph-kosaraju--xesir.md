## 算法原理

Kosaraju 是求有向图**强连通分量（SCC）**的入门算法。SCC 是什么、有哪些性质，Tarjan 那一篇已经讲透了，这里一句话带过：**极大 SCC 互不相交，缩点之后原图变成 DAG**。本篇只聊 Kosaraju 的独特之处——它最大的卖点就是：**两次 DFS 就完事，不需要 `dfn` / `low` 那套花哨东西，好懂到可以在纸上复现。**

两次 DFS 的分工是这样的：

- **第一次 DFS**：在**原图**上跑，记录每个点的**完成时间**（也就是它所有邻点都递归处理完、准备返回的那一刻）。跑完后把所有点按完成时间存起来。
- **第二次 DFS**：在**反图**（把每条有向边方向反过来得到的图）上跑，而且顺序是第一次完成时间的**逆序**。

为什么这样就能切出 SCC？把原图缩点后是个 DAG。第一次 DFS 得到的完成时间有个很顺的性质：**顺着出边走，完成时间只会更晚**——也就是说，完成时间的先后天然带了点拓扑序的味道。第二次我们换成反图、又反过来遍历，方向一抵消，搜索就恰好被困在**同一个 SCC 内部**，跑不出圈。

于是结论很清爽：**每一次从某个还没访问的点出发、在反图上能走到的一坨点，刚好就是一个 SCC。**

## 逐行代码解析

这篇不给代码（`noCode`），把两次 DFS 展开成步骤：

```
第一次 DFS（在原图 G 上）：
    对每个未访问点 u: dfs(u)
    dfs(u): 访问完 u 的所有邻点之后，把 u 压入序列 order   // 压入的时刻 = 完成时间
    // order 末尾 = 完成时间最晚的点

第二次 DFS（在反图 G^T 上）：
    从 order 末尾往开头遍历每个点 u
    若 u 还没被染色：从 u 在反图上 DFS，能走到的一坨染成同一个 SCC 编号
```

- 压入 `order` 的时机必须在**递归返回时**，不能在进入点时就压——那样得到的是「发现时间」而不是「完成时间」，算法直接废掉。
- 第二次一定要用**反图**，且顺序是 `order` 的**逆序**，这两个条件缺一不可。
- 每开一个新的染色编号，就说明又抠出了一个 SCC。

## 复杂度分析

- **时间复杂度**：$O(n + m)$。两次 DFS 里，每个点、每条边（原图与反图各一次）都恰好被访问一次，整体线性。
- **空间复杂度**：$O(n + m)$。要同时存**原图和反图**两个邻接表，各 $O(n+m)$，外加 `order`、访问标记等 $O(n)$，仍是线性。

## 适用场景

- **判环 / 求 SCC**：一个 SCC 大小大于 1 就说明图里有环。
- **缩点**：把每个 SCC 缩成一个点后原图变 DAG，接着就能跑拓扑 / DP（最长路、方案计数等）。
- **2-SAT**：判断可行性时也可用 Kosaraju 代替 Tarjan 来求分量。
- **需要直观、可手推的场合**：思路简单，适合作为理解 SCC 的第一个算法。

和 Tarjan 比：两者复杂度同为 $O(n+m)$，但 Kosaraju 要多建一张反图、多跑一遍 DFS，常数和空间都稍大，所以竞赛里通常首选 Tarjan。

## 常见陷阱与注意事项

1. **完成时间的记录时机**：必须在「所有邻点递归处理完」之后才把点压入 `order`；进入点时就压会得到发现时间，整个算法失效。
2. **第二次 DFS 必须在反图上**：在原图上按出栈序逆序 DFS 得到的是错误的划分，务必用反图。
3. **遍历顺序是「完成时间的逆序」**：从 `order` 的末尾往开头遍历，顺序反了就会跨分量错误染色。
4. **不连通图要遍历所有点**：第一次 DFS 的外层循环得覆盖 $1$ 到 $n$，不能只从某一个起点出发。
5. **反图建边方向别搞反**：读入边 $u \to v$ 时，反图应写成「向 `rg[v]` 压入 `u`」，方向反转才对得上。
6. **额外的反图开销**：相比 Tarjan，Kosaraju 多一张反图、多一次 DFS，空间和常数都要更大，题卡得紧时优先考虑 Tarjan。

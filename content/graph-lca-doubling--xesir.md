## 算法原理

LCA 是树上两个节点的公共祖先中，深度最大的那个。它是处理树上路径问题的核心工具。

### 应用场景

- **树上距离**：若每条边带权，则 $\text{dist}(u,v) = \text{depthDist}(u) + \text{depthDist}(v) - 2 \cdot \text{depthDist}(\text{LCA}(u,v))$，其中 $\text{depthDist}(x)$ 表示根到 $x$ 的路径总权值。对于无权树，深度差即可。
- **路径点权和 / 边权和查询**：预处理根到每个节点的前缀和，则 $u \to v$ 路径上的权值和 $= \text{pre}[u] + \text{pre}[v] - 2\cdot\text{pre}[\text{LCA}] + \text{val}[\text{LCA}]$（点权）或 $- 2\cdot\text{pre}[\text{LCA}]$（边权）。
- **树上差分**：对路径进行批量加值，最后通过子树和还原，常常需要 LCA 来标记路径端点。
- **判断祖先关系**：若 $\text{LCA}(u,v) = u$ 则 $u$ 是 $v$ 的祖先。
- **树上最近公共祖先的扩展**：如求树上三点或多点的“汇聚点”（使得到所有点距离和最小的节点），本质上是求这些点两两 LCA 中深度最大的那个。
- **配合动态树或树剖**：在维护子树、链修改等高级数据结构中，LCA 是定位链端点的关键。

## 核心公式 / 状态定义与转移方程

**LCA** 有以下求法，本节先讲最常用的**倍增法**。

倍增法基于二进制拆分思想，预处理出每个节点向上跳 $2^k$ 步所到达的祖先节点。设 $f[u][k]$ 表示节点 $u$ 的第 $2^k$ 级祖先（若不存在则为 $0$ 或根），则递推式为：

$$
f[u][0] = \text{parent}[u], \quad f[u][k] = f[\,f[u][k-1]\,][k-1] \quad (k \ge 1)
$$

预处理通常用 DFS 或 BFS 进行，时间复杂度 $O(n \log n)$，空间复杂度 $O(n \log n)$。

**查询步骤**（假设 $n$ 个节点，则最大深度 $\le 2^L$，其中 $L = \lfloor \log_2 n \rfloor$）：

1. **深度对齐**：设 $\text{dep}[u] \ge \text{dep}[v]$，先将 $u$ 向上跳，使得二者深度相同。枚举 $k$ 从 $L$ 到 $0$，若 $\text{dep}[u] - 2^k \ge \text{dep}[v]$，则 $u = f[u][k]$。
2. **同步上跳**：若此时 $u = v$，则 LCA 就是 $v$（即较浅节点就是祖先）。否则，从 $k = L$ 到 $0$，若 $f[u][k] \ne f[v][k]$，则同时将 $u$ 和 $v$ 上跳到各自的 $2^k$ 级祖先。这样最终 $u$ 和 $v$ 会停在 LCA 的直接子节点上。
3. **返回答案**：最后 $\text{LCA}(u,v) = \text{parent}[u]$（或 $\text{parent}[v]$）。

单次查询时间复杂度 $O(\log n)$，且支持在线查询，无需预知所有询问。其扩展性很强，例如可以在跳跃过程中顺便维护路径上的最小值、最大值、异或和等可合并信息（只需额外维护 $g[u][k]$ 表示从 $u$ 向上跳 $2^k$ 步路径上的统计量）。

## 逐行代码解析

下面把模板代码按模块拆开讲，四块按顺序拼起来就是完整程序。

### 头文件与全局定义

```cpp
#include <bits/stdc++.h>
using namespace std;
#define fi first
#define se second
const int N=5e5+10;
vector<int> G8[N];
int d[N],z[N][30];
```

- `N=5e5+10` 是点数上界；`z` 的第二维开到 30，比实际需要的还宽裕（最大深度不超过 $5\times10^5 < 2^{20}$）。
- `G8` 是邻接表，用来存整棵无向树；`d[x]` 记深度，`z[x][k]` 就是上文的 $f[u][k]$——点 $x$ 向上跳 $2^k$ 步到达的祖先。
- `#define fi first` / `#define se second` 是给 `pair` 用的快捷键，这份片段里暂时没派上用场。

### DFS 预处理（求深度、父亲与倍增表）

```cpp
void dfs(int x,int fa){
	//预处理
	d[x]=d[fa]+1;
	z[x][0]=fa;
	for(int i=1;i<=20;i++){
		//TODO
		z[x][i]=z[z[x][i-1]][i-1];
	}
	for(int i:G8[x]){
		if(i!=fa) dfs(i,x);
	}
}
```

- `d[x]=d[fa]+1`：从父亲推深度。根以 `dfs(s,0)` 调用，`d[0]` 初值为 0，所以根的深度是 1。
- `z[x][0]=fa`：$2^0 = 1$ 级祖先就是直接父亲，对应递推式的第一行。
- `for(int i=1;i<=20;i++)` 与 `z[x][i]=z[z[x][i-1]][i-1]`：逐层填倍增表，正是递推式 $f[x][i] = f[\,f[x][i-1]\,][i-1]$——先跳 $2^{i-1}$ 步，再从落点继续跳 $2^{i-1}$ 步。
- `for(int i:G8[x]) if(i!=fa) dfs(i,x);`：递归所有子节点，跳过父亲防止走回去。
- 代码里以 `//` 开头的行内注释都是笔记保留的，不影响编译。

### LCA 查询函数

```cpp
int lca(int u,int v){
	if(d[u]<d[v]) swap(u,v);
	for(int i=20;i>=0;i--){
		if(d[z[u][i]]>=d[v]) u=z[u][i];
	}
	if(u==v) return v;
	for(int i=20;i>=0;i--){
		if(z[u][i]!=z[v][i]) u=z[u][i],v=z[v][i];
	}
	return z[u][0];
}
```

- `if(d[u]<d[v]) swap(u,v);`：保证 $u$ 是较深的那个，后面统一处理。
- 第一个 `for` 是**深度对齐**：从高位到低位试，只要跳完还不比 $v$ 浅（`d[z[u][i]]>=d[v]`）就跳，最终把 $u$ 拉到与 $v$ 同一深度。
- `if(u==v) return v;`：对齐后若两点重合，说明其中一个是另一个的祖先，直接返回。
- 第二个 `for` 是**同步上跳**：从高位到低位，只要跳完两点仍不相等（`z[u][i]!=z[v][i]`）就一起跳。跳出循环时，$u$ 和 $v$ 恰好停在 LCA 的两个直接子节点上。
- `return z[u][0];`：此时 $u$、$v$ 是 LCA 的两个子节点，再往上走一步（取直接父亲）就是 LCA。

### 主函数

```cpp
signed main(){
	int n,m,s;cin>>n>>m>>s;
    for(int i=1;i<n;i++){
        int u,v;cin>>u>>v;
        G8[u].push_back(v);
        G8[v].push_back(u);
    }
    dfs(s,0);
    for(int i=1;i<=m;i++){
        int u,v;cin>>u>>v;
        cout<<lca(u,v)<<'\n';
    }
	return 0;
}
```

- `signed main()`：很多模板会 `#define int long long` 把全局 `int` 换成长整型，那时 `main` 必须写成 `signed main`；这份片段里没有该宏，写 `signed main` 也完全合法。
- `cin>>n>>m>>s`：读入点数 $n$、询问数 $m$、根节点 $s$。
- `for(int i=1;i<n;i++)`：读 $n-1$ 条无向边，正反两端各 `push_back` 一次。
- `dfs(s,0)`：以 $s$ 为根做预处理，传入的父亲参数用 `0` 表示「没有父亲」。
- 最后的 `for(int i=1;i<=m;i++)`：读 $m$ 组询问，每组输出 `lca(u,v)`。

## 复杂度分析

- **预处理**：DFS 走一遍树是 $O(n)$；对每个点填 21 层倍增表，是 $O(n \log n)$。合计 $O(n \log n)$。
- **单次查询**：深度对齐最多跳 $O(\log n)$ 次，同步上跳也是 $O(\log n)$ 次，合计 $O(\log n)$，且支持在线。
- **空间**：倍增表 `z` 占 $O(n \log n)$，邻接表 `G8` 与深度数组 `d` 各占 $O(n)$，瓶颈在倍增表。

## 适用场景

- **多次、在线查询**：查询一个接一个到来、无法提前收集时，倍增法是首选。
- **树上路径 / 距离问题**：配合深度或前缀和求两点距离、路径权值和。
- **树上差分**：用 LCA 标记路径端点。
- **需要顺带维护路径信息**：跳跃时同步维护最大值、最小值、异或和等可合并量。
- 树结构**静态不变**时最合适；树频繁加边删边则要换别的结构。

## 常见陷阱与注意事项

1. **倍增层数要够**：上界（这里写死 20）必须满足 $2^{\text{上界}} >$ 最大深度，宁多勿少，否则跳不到位，答案就错。
2. **不存在的祖先用 0 兜底**：`d[0]=0`，比较 `d[z[u][i]]>=d[v]` 时不会误跳；但要保证编号从 1 开始，别让 0 号被当成真实节点。
3. **DFS 递归深度**：树退化成链、$n$ 达到 $5\times10^5$ 时递归可能爆栈，必要时改 BFS 或开大栈。
4. **无向边要存两次**：建树时正反各 `push_back` 一次，`dfs` 里用父节点参数跳过回头路，不要另外开 visited。
5. **同步上跳是「不等才跳」**：条件是 `z[u][i]!=z[v][i]` 才跳，目的是停在 LCA 的下一层；写成「相等才跳」就错了。
6. **对齐后直接相等**：`if(u==v) return v;` 不能漏，否则后面会多跳。

## 对比与扩展

源笔记里还列出了 LCA 的其它几种求法，按需选用。

### Tarjan 离线算法

Tarjan 算法利用 DFS 顺序和并查集一次性处理所有询问，总时间复杂度 $O(n + q \cdot \alpha(n))$，接近线性，其中 $q$ 是询问数量，$\alpha$ 是反阿克曼函数。 ~~可以认为反阿克曼函数是常数~~

其核心思想是：

- 对树进行 DFS，在遍历过程中，将已访问过的节点用并查集合并到其当前的祖先节点上。
- 当 DFS 访问到节点 $u$ 时，先递归处理其所有子节点，每处理完一个子树，就把该子树的根节点（即子节点）合并到 $u$ 上（并查集的代表元设为 $u$）。
- 然后，对于所有与 $u$ 相关的询问 $(u, v)$，如果 $v$ 已经被访问过，那么此时 $\text{LCA}(u,v)$ 就是并查集中 $v$ 所在集合的代表元。

该算法需要把所有询问存下来、必须**离线**，不能应对动态增加的询问；但它非常适合询问数量极大（如 $10^6$ 级别）且内存充裕的场景，因为常数很小。

### 欧拉序 + ST 表

DFS 时，如果对每个节点**进入和离开**各标记一次，会得到一个长度 $2n-1$ 的序列，这就是**欧拉序**。不难发现，两个节点 $u,v$ 的 LCA 就是它们在欧拉序里两次出现之间**深度最小**的那个节点。

这样就把 LCA 转化成了 RMQ 问题，直接跑 ST 表即可：预处理 $O(n \log n)$，单次查询 $O(1)$，在线，不支持修改。

> 树链剖分也可以维护 LCA，之后我会在其专栏讲到。

若查询次数较少，或者本身就要访问路径上所有节点，可以使用 $O(n)$ 的暴力跳法，写起来比较简单。

## 算法原理

图论的题目类型多样、考法灵活，**能直接套到板子的概率几乎为 $0$**（~~说你呢 [road](https://www.luogu.com.cn/problem/P14362)~~）。所以比起背板子，更要紧的是掌握**常见的建模思想**——把看起来不像图的问题，翻译成图上的最短路 / 生成树 / 网络流。

这里先讲一个最经典的套路：**分层图**。

### 分层图的经典模型

给定无向带权图 $G=(V,E,w)$、起点 $s$、终点 $t$ 和整数 $k$，求一条 $s \to t$ 的路径，**允许其中至多 $k$ 条边权视为 $0$**，使路径总权最小。

直接枚举哪些边免费显然不现实。换个角度想：真正影响状态的，不就是「已经免了几条」吗？于是建一张 $k$ 层的图：

- 第 $j$ 层代表「已经用了 $j$ 次免费边」时的最短路，从第 $0$ 层出发；
- **每层内部就是原图的复制**，走的都是正常边权；
- 每用一次免费边，就从第 $j$ 层转移到第 $j+1$ 层，实现上就是向下一层的对应节点连一条**边权为 $0$** 的边。

这样一来，「用几次免费」就被编进了「在哪一层」里，问题重新变回一张普通图上的最短路。最后**所有层终点的最小值**就是答案（不必刚好用满 $k$ 次）。

## 逐行代码解析

核心建图代码不长，拆成两块看。

### 模块一：层内复制原图的边

```cpp
for(int i=1;i<=m;i++){
    int u,v,w;cin>>u>>v>>w;
    for(int j=0;j<=k;j++){
        G1[u+j*n].push_back({v+j*n,w});
        G1[v+j*n].push_back({u+j*n,w});
    }
```

- 读入一条原边 $(u,v,w)$，在**每一层**里都建一份副本。
- `u + j*n` 就是「第 $j$ 层的点 $u$」——用一个偏移 `j*n` 把 $k+1$ 层叠成一维编号，避免开二维数组。
- 无向边两个方向都要连，边权保持原来的 $w$。

### 模块二：跨层连「免费边」

```cpp
    for(int j=0;j<k;j++){
        G1[u+j*n].push_back({v+(j+1)*n,0});
        G1[v+j*n].push_back({u+(j+1)*n,0});
    }
}
```

- 这一块是「免费边」：从第 $j$ 层的 $u$ 连到第 $j+1$ 层的 $v$，边权设为 $0$，代表这次过路不要钱。
- 循环上界是 `j < k`（即 $0 \sim k-1$）：免费最多用 $k$ 次，从第 $j$ 层只能跳到第 $j+1$ 层，最高走到第 $k$ 层。
- 同样是双向的——无向图里两个方向都能「享用」这次免费。

## 复杂度分析

- **图规模**：点数变成 $(k+1)n$；原图的每条边在 $k+1$ 层各复制一份，再额外连 $k$ 条免费边，边数是 $O(km)$ 级别。
- **建图**：$O(km)$，就是上面两层循环扫过的点与边。
- **最短路**：要看后面套什么算法，套堆优化 Dijkstra 约为 $O((kn + km)\log(kn))$；总之规模被 $k$ 线性放大。

空间上直接存叠加后的邻接表，是 $O(k(n+m))$。$k$ 大的时候要小心开不下。

## 适用场景

分层图适合处理**最短路 + 「某种次数 / 状态」限制**的题目，例如：

- 至多 $k$ 条边免费或有折扣；
- 至多 $k$ 次操作可以把某条边的权值改小 / 改成另一种权值；
- 带「奇偶性」「剩余次数」「剩余油量」等附加状态的最短路。

判断能不能建模成分层图，就看**那个限制能否用一个可以累加、且范围不大的状态来刻画**——能，就把它放进「层」里，问题立刻回到普通最短路。

## 常见陷阱与注意事项

1. **层偏移 `u + j*n` 别搞混层号和点号**：数组下标要开到 $(k+1)n$，别只按 $n$ 开。
2. **免费边循环边界是 `j < k`**：写成 `j <= k` 会连到并不存在的第 $k+1$ 层，导致越界。
3. **答案要在所有层的终点里取 $\min$**：不能只看第 $k$ 层，因为可能用不满 $k$ 次免费。
4. **图规模是 $(k+1)n$**：堆、距离数组、访问标记都要跟着放大，防止开小或常数爆炸。
5. **无向图别只连单向**：层内边和免费边都要正反各连一次。

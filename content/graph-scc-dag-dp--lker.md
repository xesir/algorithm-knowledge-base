## 算法原理

SCC 本身只是一个划分；真正让它在比赛里好用的一步是 **缩点**：把每个强连通分量压成一个“超级点”，分量内部的点互相可达，走进去就可以全部走完；分量之间的边保留，得到一张 **DAG（有向无环图）**。

为什么缩点后一定是 DAG？如果缩点后的图还有环，那么环上的所有超级点互相可达，它们原本就应该属于同一个 SCC，与“极大性”矛盾。所以缩点图必然无环，可以拓扑排序。

以洛谷 P3387【模板】缩点为例：给定 $n$ 个点、$m$ 条边的有向图，每个点有点权，求一条路径，使路径经过的点权之和最大。路径可以重复经过点，但点权只算一次。缩点后：

- 同一个 SCC 内的点权全部加起来，作为超级点的点权；
- 原图里跨分量的边变成超级点之间的边；
- 在 DAG 上按拓扑序做一遍最大权路径 DP。

这里有一个贪心观察：本题点权非负，所以进入一个 SCC 后把里面所有点都走完一定不亏；因此可以把整个 SCC 的点权合并，不需要在分量内部再做选择。如果点权可能为负，这个观察就不成立，问题会变成另一类“最大权闭合子图/路径”问题，不能直接套这个模板。

### 缩点的三个步骤

1. **Tarjan 求 SCC**：顺便给每个点打上分量编号 `scc[u]`，并累加分量点权。
2. **重建图**：枚举原图的每条边 $(u,v)$，若 `scc[u] != scc[v]`，在缩点图上加边 `scc[u] -> scc[v]`，同时统计入度。
3. **拓扑 DP**：入度为 0 的超级点作为起点，按拓扑序转移，答案是所有超级点 DP 值的最大值。

## 核心公式 / 状态定义与转移方程

设 $c(u)$ 为点 $u$ 所属的 SCC 编号，$W_c$ 为分量 $c$ 的点权之和：

$$
W_c=\sum_{u:\,c(u)=c} a_u.
$$

在缩点图 $G'=(V',E')$ 上定义 $f[c]$ 为“以分量 $c$ 结尾的最大权路径”，则

$$
f[c]=W_c+\max_{\substack{p\to c\\ p\in V'}}\bigl(f[p]\bigr),
$$

没有前驱时 $f[c]=W_c$。按拓扑序递推即可。

写成伪代码：

```
tarjan 求出 scc[u] 与 W[c]
清空缩点图的邻接表
for each original edge (u, v):
    x = scc[u]; y = scc[v]
    if x != y:
        add(x, y); indeg[y] += 1
queue <- all c with indeg[c] == 0
f[c] = W[c] for all c
while queue not empty:
    p = queue.pop()
    for each edge (p, c):
        f[c] = max(f[c], f[p] + W[c])
        indeg[c] -= 1
        if indeg[c] == 0: queue.push(c)
answer = max(f[c])
```

## 逐行代码解析

这一版没有配套的 `.cpp`，下面按模块说明 lker 模板的结构；片段是结构示意，不是完整可提交程序。

### 模块一：Tarjan 与分量点权

在弹栈时同时做三件事：记录点属于哪个分量、把点权累加到 `W[当前分量]`、清空 `in_stack`。分量编号从 1 开始，`W` 数组初始化为 0。弹栈的顺序不影响结果，但每个点必须恰好弹出一次。

### 模块二：重建缩点图

原图的边要先存进 `u[]` 和 `v[]`，因为 Tarjan 之后还要再枚举一次。重建前把 `h` 置为 -1、`ne/to` 清零、`idx` 归零，避免旧边残留。枚举时只保留 `x != y` 的边；自环在缩点后没有意义，必须跳过。

### 模块三：拓扑排序

缩点图的入度用 `indeg`（或复用一个清空后的 `in` 数组）统计。所有入度为 0 的分量先入队，`f` 初始化为自身点权。每次取出队首，枚举出边做转移，入度减到 0 就入队。拓扑序保证转移时前驱已经算完，不需要记忆化搜索。

### 模块四：答案

答案不是 `f[某个固定点]`，而是所有分量 `f` 的最大值。因为最长路径可能在任何地方结束，不能只取拓扑序最后一个点。

## 复杂度分析

Tarjan 是 $O(n+m)$，重建图和拓扑 DP 也都是 $O(n+m)$；总时间复杂度 $O(n+m)$。

空间上邻接表、`dfn/low/scc/W/f/indeg` 都是 $O(n+m)$ 级别。

即使缩点后存在重边，每条边也只会让入度多加一次、转移多做一次，复杂度仍然是线性的；若担心常数，可以在重建时对边去重。

## 适用场景

- 有向图上的“最长路/最大权路径”，且允许重复经过点但只算一次权值；
- 缩点后做 DAG 上的计数、可达性、方案数 DP；
- 需要把“环上的点可以一次走完”显式建模的题目；
- 2-SAT、强连通性判定之后的后续处理。

看到“有向图 + 环 + 路径权值”这类组合，先想缩点；缩点后如果状态只依赖前驱，就按拓扑序 DP。

## 常见陷阱与注意事项

- **忘记保存原边**：Tarjan 会改邻接表的使用状态，重建缩点图前必须保留原图的 `u[]/v[]`。
- **重建前没清空**：`h/ne/to/idx` 不清零会把 Tarjan 的边混进来，缩点图直接错。
- **自环没跳过**：`scc[u] == scc[v]` 的边加进去会形成自环，污染入度和拓扑序。
- **重边导致入度重复**：多条相同的缩点边会让入度数偏大，但每次转移都会减一次，最终仍能全部处理；若要求严格线性或去重，建议先排序去重。
- **拓扑起点漏掉**：只把 1 号点入队会漏掉其它入度为 0 的分量；必须枚举所有分量。
- **答案取错**：最长路径不一定在拓扑序末尾结束，要取全局最大值。
- **负权**：本题点权非负才能“走完整个 SCC”；点权有负时要重新建模，不能直接套。
- **递归深度**：$n$ 较大时 Tarjan 递归可能爆栈，必要时改迭代或开栈。

## 对比与扩展

| 做法 | 适用条件 | 复杂度 | 说明 |
|---|---|---|---|
| SCC 缩点 + 拓扑 DP | 有向图、点权非负、路径可重复经过点 | $O(n+m)$ | 本题模板 |
| 直接记忆化 DFS | 图是 DAG | $O(n+m)$ | 有环时会死循环 |
| Bellman-Ford 类松弛 | 允许负权、无正环 | $O(nm)$ | 不要求 DAG，但慢 |
| 最长路 + 正环检测 | 一般有向图 | 多项式 | 有正环时最长路无界 |

缩点是“把环消掉”的通用手段：SCC 缩点得到 DAG，边双缩点得到树，点双缩点得到圆方树。三种缩点的目标不同，但套路一致——先找分量，再在压缩后的结构上做原本做不动的问题。

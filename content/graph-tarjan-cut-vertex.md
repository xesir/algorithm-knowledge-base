## Tarjan 求割点

## 一、问题定义

**割点（关节点）**：在无向图中，如果删掉某个点（以及它连的所有边）之后，图的连通分量数增加了，这个点就称为割点。

暴力做法是枚举每个点，删掉它后用 BFS/DFS 检查连通性，时间复杂度 $O(n(n+m))$，在大规模数据下会超时。

Tarjan 算法的精髓在于：**只做一次 DFS，就能同时判断所有点是不是割点**，复杂度 $O(n+m)$。

## 二、算法原理：核心思想

删掉点 $u$ 之后图会不会断，关键看 $u$ 的"下方"（DFS 树中 $u$ 的子树）能不能不经过 $u$，绕回到 $u$ 的"上方"（$u$ 的祖先）。

- 如果能绕回去 → $u$ 的子树和其余部分除了 $u$ 还有别的通道，删 $u$ 不断
- 如果绕不回去 → $u$ 是子树通向外界的唯一通道，删 $u$ 后子树被孤立，$u$ 是割点

## 三、基础概念

### 1. DFS 生成树

对图做 DFS，第一次走到某个点所经过的边称为**树边**，所有树边构成一棵生成树。其余边称为**非树边**。

**重要性质**：无向图的 DFS 中，非树边一定是"连向祖先"的**返祖边**，不存在横叉边（连向完全另一棵子树的边）。这个性质是 Tarjan 正确性的基石。

### 2. dfn[u] —— 时间戳

`dfn[u]` 表示 $u$ 是第几个被访问到的点。它有两个作用：
- 作为"访问顺序"的编号，数值越小代表越靠近 DFS 的源头（越像"祖先"）
- 同时充当访问标记（0 = 未访问）

### 3. low[u] —— 能追溯到的最早时间戳

**定义**：$u$ 及其子树中的所有点，通过最多一条返祖边，能够到达的时间戳最小的点的时间戳。

直观理解：`low[u]` 回答的问题是——"$u$ 这一片区域，最远能'回头'摸到多早的祖先？"

- `low[u]` 越小 → 子树有强大的返祖通道，能绕过很多层祖先
- `low[u] >= dfn[u]` → 整个子树被 $u$ 封死了，任何回头路最多回到 $u$ 自己

**low 的维护规则**：

| 情况 | 更新方式 | 代码 |
|------|---------|------|
| 初始化 | `low[u] = dfn[u]`（至少能摸到自己） | `dfn[nd] = low[nd] = ++tim` |
| 走树边进入孩子 to | 孩子的回头能力可以继承给我 | `low[nd] = min(low[nd], low[to])` |
| 遇到返祖边连向已访问的 to | 直接一步跳到 to，能摸到 dfn[to] | `low[nd] = min(low[nd], dfn[to])` |

## 四、两个判定定理

### 定理 1：非根节点 u 是割点

**条件**：存在一个孩子 $v$，满足 $\text{low}[v] \geq \text{dfn}[u]$

**证明思路**：
- 如果 $v$ 的子树中所有返祖边最远只能回到 $u$ 或 $u$ 的后代（$\text{low}[v] \geq \text{dfn}[u]$），那么 $v$ 的子树与"$u$ 的祖先部分"之间，$u$ 是唯一通道。删掉 $u$，$v$ 的子树必然和上面断开。
- 反过来，如果每个孩子的子树都能绕到 $u$ 的严格祖先（$\text{low}[v] < \text{dfn}[u]$），删掉 $u$ 后各子树借返祖边跳到上方再互通，图仍然连通。

### 定理 2：根节点是割点

**条件**：它在 DFS 树中有 $\geq 2$ 个孩子

**为什么根不能用定理 1？** 因为根的时间戳最小（`dfn = 1`），`low[v] >= dfn[root]` 对任何孩子都恒成立，直接套用会得出"根永远是割点"的错误结论。根本身就是最高点，"绕不到根上面"对根没有意义。

**正确角度**：由"无向图 DFS 无横叉边"的性质，根的不同 DFS 子树之间一定没有边相连。所以：
- 孩子数 $\geq 2$ → 子树之间完全隔离 → 删根必断 → 根是割点
- 孩子数 $= 1$ → 整张图都在一棵子树里 → 根不是割点

> 注意：这里的"孩子"指 DFS 树中的孩子，不是图中的度数。比如星形图从叶子开始 DFS，中心节点有多个孩子（判为割点 ✓），叶子只有一个孩子（非割点 ✓）。用度数会误判。

### 初始化函数

```cpp
void init()
{
    tim = 0;
    cnt = 0;
    dfn.assign(n + 1, 0);
    low.assign(n + 1, 0);
    is_cut.assign(n + 1, false);
}
```

重置所有数组和计数器，时间戳从 1 开始（0 表示未访问）。

### Tarjan 主函数

```cpp
void tarjan(int nd, int fa)
{
    int child_cnt = 0;
    dfn[nd] = low[nd] = ++tim;
```

- `nd`：当前节点；`fa`：父节点，根传 -1
- `child_cnt`：记录 DFS 树中的孩子数量
- 打时间戳，low 初始化为自己（"最差也能摸到自己"）

```cpp
    for (int to : edges[nd])
    {
        if (to == fa) continue;
```

枚举所有邻居，**跳过父亲边**。无向边在邻接表里存了两份，从孩子往回枚举时一定会碰到父亲，如果不跳过，就会把"来时的树边"误认成"返祖边"，导致所有点都判不出割点。

```cpp
        if (!dfn[to])                // 情况 1: to 未访问 → 树边
        {
            ++child_cnt;
            tarjan(to, nd);
            low[nd] = min(low[nd], low[to]);
            if (fa != -1 && low[to] >= dfn[nd] && !is_cut[nd])
                is_cut[nd] = true, cnt++;
        }
```

**情况 1：树边**
1. 孩子数 +1
2. 递归处理孩子（先递归，出来时 `low[to]` 才是最终值）
3. 继承孩子的回头能力：`low[nd] = min(low[nd], low[to])`
4. 定理 1 判定非根割点：`low[to] >= dfn[nd]` 且非根
   - `!is_cut[nd]` 去重：多个孩子都满足条件时只计数一次

```cpp
        else                         // 情况 2: to 已访问 → 返祖边
            low[nd] = min(low[nd], dfn[to]);
    }
```

**情况 2：返祖边**
- 用 `dfn[to]` 更新，不是 `low[to]`！
- 语义：返祖边是"我直接一步就能到达 to"，一步可达能摸到的最早值就是 `dfn[to]`
- 割点场景下误用 low[to] 恰好不出错，但割边（桥）会出 bug，养成用 `dfn[to]` 的正确习惯

```cpp
    if (fa == -1 && child_cnt >= 2)
        is_cut[nd] = true, cnt++;
}
```

**定理 2：根的特判**
- 必须等所有邻居枚举完（所有孩子都统计完）才能下结论
- 放在循环外、函数末尾

### 驱动函数

```cpp
void fn()
{
    init();
    for (int i = 1; i <= n; i++)
    {
        if (!dfn[i]) tarjan(i, -1);
    }
}
```

图可能不连通，对每个未访问的点都启动一次 DFS。每个连通块的第一个被访问点自动成为该块的 DFS 根，享受"孩子数 ≥ 2"的正确判定；孤立点孩子数为 0，不会被误判。

### 主函数

```cpp
int main()
{
    ios::sync_with_stdio(false);
    cin.tie(nullptr); cout.tie(nullptr);
    cin >> n >> m;
    edges.assign(n + 1, {});
    for (int i = 1; i <= m; i++)
    {
        int u, v;
        cin >> u >> v;
        edges[u].emplace_back(v);
        edges[v].emplace_back(u);   // 无向图，双向加边
    }
    fn();
    cout << cnt << '\n';
    for (int i = 1; i <= n; i++)
    {
        if (is_cut[i]) cout << i << ' ';
    }
    return 0;
}
```

## 六、手动模拟示例

**图结构**：

```
1 — 2 — 3
    |
    4 — 5
```

边：1-2, 2-3, 2-4, 4-5

从 1 开始 DFS，路径 1→2→3→(回)→2→4→5：

| 步骤 | 动作 | 结果 |
|------|------|------|
| 1 | 进入 1 | `dfn[1]=low[1]=1` |
| 2 | 进入 2 | `dfn[2]=low[2]=2`，1 的 child_cnt=1 |
| 3 | 进入 3 | `dfn[3]=low[3]=3`，2 的 child_cnt=1 |
| 4 | 3 无未访问邻居，回溯 | `low[3]=3` 保持 |
| 5 | 回到 2，用孩子 3 更新 | `low[2]=min(2,3)=2`；`low[3]=3 >= dfn[2]=2` 且 fa=1 非根 → **2 是割点**，cnt=1 |
| 6 | 2 枚举邻居 4（未访问） | 进入 4，child_cnt[2]=2 |
| 7 | 进入 5 | `dfn[5]=low[5]=5` |
| 8 | 回到 4 | `low[4]=min(4,5)=4`；`low[5]=5 >= dfn[4]=4`，fa=2 非根 → **4 是割点**，cnt=2 |
| 9 | 回到 2 | `low[2]=min(2,4)=2`；low[4]>=dfn[2]，但 2 已标记，不重复计数 |
| 10 | 回到 1，枚举完毕 | 1 是根，child_cnt=1 < 2 → 不是割点 |

**结论**：割点为 2 和 4 ✓

## 七、复杂度分析

| 维度 | 复杂度 | 说明 |
|------|--------|------|
| 时间 | $O(n + m)$ | 每个点恰好访问一次，每条无向边在邻接表中各遍历一次 |
| 空间 | $O(n + m)$ | 邻接表 + dfn/low/is_cut 三个数组 |
| 递归深度 | 最坏 $O(n)$ | 链状图会达到最深。本题规模下安全；$n$ 达 $10^5$ 以上需改迭代版或加大栈空间 |

## 八、常见陷阱

1. **返祖边误用 `low[to]`**：应使用 `dfn[to]`。割点场景下恰好不出错，但割边会出 bug，养成正确习惯。
2. **忘记跳过父亲边**：树边被当返祖边，low 全部失效，所有点都判不出割点。
3. **根没有特判**：或误用 `low >= dfn` 判根，导致根永远 / 永不判中。
4. **用图的度数代替 DFS 树的孩子数**：重边、多入口都会使度数失真（见星形图反例）。
5. **忘记处理非连通图**：必须对每个未访问点都启动一次 DFS。
6. **割点判定写在递归之前**：用到未定型的 `low[to]`，判断错误。
7. **忘记去重**：一个点被多个孩子的条件反复触发时多计 cnt。
8. **重边与割点/割边的区别**：割点中"跳过所有 fa 边"没问题；但这个模板不能直接改成割边（桥）——桥必须只跳过"来时的那一条树边"（通常用边编号判断），否则有重边时桥会被漏判。

## 九、适用场景

- **求割点**：找出无向图中所有关节点
- **点双连通分量**：割点是点双连通分量的交界点，求割点是求点双的基础
- **网络可靠性分析**：判断哪些节点故障会导致网络分裂
- **2-SAT 问题**：某些变体需要借助割点分析
- **图的缩点**：点双连通分量缩成"圆方树"，割点是公共点

## 十、与强连通分量 Tarjan 的对比

| 维度 | 强连通分量 Tarjan | 割点 Tarjan |
|------|------------------|------------|
| 图类型 | 有向图 | 无向图 |
| 核心结构 | 栈维护当前 SCC | 无栈，靠 dfn/low 直接判定 |
| 判定条件 | `low[u] == dfn[u]` 弹出栈 | 非根：`low[child] >= dfn[u]`；根：child_cnt >= 2 |
| 父节点处理 | 不需要跳过父边 | 必须跳过父边（`to == fa` continue） |
| 输出 | 每个 SCC 的点集 + 颜色数组 | 割点标记数组 |
| 延伸算法 | 缩点 → DAG → 拓扑 DP | 点双连通分量、圆方树 |

## 附：Tarjan 求桥（割边）

Tarjan 算法由 Robert Tarjan 于 1974 年提出，通过**一次深度优先搜索（DFS）**即可找出无向图中所有的**桥**（割边），时间复杂度为 $O(n+m)$。

#### 什么是桥

**桥（Bridge，又称割边）**：在无向图中，如果删除某条边后，图的连通分量数增加，则称这条边为桥。换句话说，桥是图中的"生命线"——去掉它图就会被拆成两部分。

暴力做法是枚举每条边，删除后用 BFS/DFS 检查连通性，时间复杂度 $O(m(n+m))$，在大规模数据下会超时。Tarjan 算法的精髓在于：只做一次 DFS，就能同时判断所有边是不是桥。

#### 核心思想

判断一条树边 $u \to v$（$u$ 是父节点，$v$ 是子节点）是不是桥，关键看 $v$ 的子树能不能不经过这条边，绕回到 $u$ 或 $u$ 的祖先：

- **能绕回去** → 子树和外界除了这条边还有其他通道，这条边不是桥
- **绕不回去** → 这条边是子树通向外界的唯一通道，删去后子树被孤立，是桥

#### DFS 生成树与返祖边

对无向图做 DFS，第一次走到某个点所经过的边称为**树边**，所有树边构成一棵生成树。其余的边称为**非树边**。

**关键性质**：无向图的 DFS 中，非树边一定是"连向祖先"的**返祖边**，不存在横叉边（连向完全另一棵子树的边）。这个性质是 Tarjan 正确性的基石——因为如果有横叉边，"low 值追溯"的逻辑就不成立了。

#### dfn 与 low 数组

| 数组 | 含义 |
|------|------|
| `dfn[u]` | 节点 $u$ 被首次访问的时间戳（DFS 序），同时充当访问标记（0 = 未访问） |
| `low[u]` | 从 $u$ 及其子树中的所有点出发，通过最多一条返祖边，能到达的时间戳最小的节点的时间戳 |

`low[u]` 回答的问题是："$u$ 这一片区域，最远能'回头'摸到多早的祖先？"

#### 桥的判定条件

对于树边 $u \to v$（$u$ 是父节点，$v$ 是子节点）：

$$
\text{low}[v] > \text{dfn}[u] \quad \Longrightarrow \quad u\text{-}v \text{ 是桥}
$$

含义：$v$ 的子树最多只能追溯到 $v$ 自己或更晚的节点，无法回到 $u$ 或更早的祖先，因此 $u$-$v$ 这条边是子树与外界的唯一连接——桥。

对比割点的判定 `low[v] >= dfn[u]`：割点允许子树追溯到 $u$ 自身（等于号成立），而桥要求**严格大于**——因为如果子树能回到 $u$，说明存在不经过这条树边的路径（通过返祖边），所以这条边不是桥。

### 核心状态定义与转移方程

#### 状态定义

| 变量 | 含义 |
|------|------|
| `dfn[rt]` | 当前节点的时间戳（DFS 序编号） |
| `low[rt]` | 当前节点及其子树能追溯到的最早时间戳 |
| `fa` | DFS 树中的父节点，用于防止走回父边 |
| `tim` | 全局时间戳计数器 |
| `cnt` | tarjan 函数内的局部计数器，用于重边处理（只跳过第一条父边） |
| `is_bridge` | 存储所有桥的边列表 |

#### 转移规则

进入 DFS 时初始化：

$$
\text{dfn}[u] = \text{low}[u] = \text{++tim}
$$

对每条出边 $u \to v$，分三种情况处理：

$$
\text{low}[u] \text{ 的更新} =
\begin{cases}
\text{跳过（仅第一条父边）} & v = \text{fa} \text{ 且本轮未跳过过父边} \\
\min(\text{low}[u], \text{low}[v]) & v \text{ 未访问，递归后回溯更新} \\
\min(\text{low}[u], \text{dfn}[v]) & v \text{ 已访问且未被跳过（返祖边或重边）}
\end{cases}
$$

注意返祖边的情况用的是 `dfn[v]` 而不是 `low[v]`。这是因为 `low` 的定义是"通过最多一条返祖边"能到达的最早节点，如果用 `low[v]` 就相当于走了多条返祖边，会导致误判。

#### 桥的判定

递归回溯后，若满足：

$$
\text{low}[v] > \text{dfn}[u]
$$

则 $u$-$v$ 是桥。

#### 重边处理机制

无向图加边时每条边存两份（$u \to v$ 和 $v \to u$）。如果 $u$ 和 $v$ 之间有**重边**（两条以上的平行边），那么删掉其中一条不影响连通性，因此重边不可能是桥。

代码通过局部计数器 `cnt` 实现正确的重边处理：对当前节点 `rt`，只跳过邻接表中**第一次出现的父边**，后续出现的同方向重边会走到 `else` 分支作为返祖边处理，从而更新 `low` 值，使重边不会被误判为桥。

- `dfn`、`low`：Tarjan 的核心双数组

所有数组初始化为 0，`dfn = 0` 表示未访问。

#### 加边函数

#### Tarjan 核心函数

```cpp
void tarjan(int rt, int fa)
{
	int cnt = 0;                              // 局部计数器：记录是否已跳过父边
	dfn[rt] = low[rt] = ++tim;               // 初始化时间戳和 low 值
	for (int i : edges[rt])                   // 遍历所有邻接点
	{
		if (fa == i && !cnt)                 // 只跳过第一条父边
		{
			++cnt;
			continue;
		}
		if (!dfn[i])                         // 情况1：未访问——树边
		{
			tarjan(i, rt);                   // 递归 DFS
			low[rt] = min(low[i], low[rt]);  // 回溯：用子节点 low 更新父节点
			if (low[i] > dfn[rt])            // 桥的判定条件
				is_bridge.emplace_back(rt, i);
		}
		else                                  // 情况2：已访问——返祖边或重边
			low[rt] = min(dfn[i], low[rt]);  // 用 dfn[i] 更新 low[rt]
	}
}
```

逐行解析关键点：

1. **`int cnt = 0;`**：局部计数器，每次进入 `tarjan` 函数时重置为 0。用于记录当前节点是否已经跳过了一条父边。

2. **`dfn[rt] = low[rt] = ++tim;`**：新节点初始时，low 值等于自己的时间戳——目前只知道能到达自己。注意全局计数器已更名为 `tim`，避免与局部 `cnt` 混淆。

3. **`if (fa == i && !cnt)`**：这是**重边处理的核心**。无向图中每条边在邻接表中出现两次（$u \to v$ 和 $v \to u$），从父节点来的边不能往回走，否则会死循环。但如果有重边（$u$ 和 $v$ 之间多条平行边），只跳过第一条父边，后续重边会走到 `else` 分支作为返祖边处理，从而正确地不判定为桥。

4. **`++cnt;`**：标记已跳过一条父边，后续即使再遇到 `fa` 也不会跳过，而是作为返祖边处理。

5. **`if (!dfn[i])` 树边分支**：
   - 递归进入子节点 `tarjan(i, rt)`
   - 回溯时更新：`low[rt] = min(low[i], low[rt])`——子树能追溯到的最早节点，父节点当然也能追溯到
   - **桥判定**：`if (low[i] > dfn[rt])` —— 子节点的追溯能力到不了父节点或更早，说明父→子这条边是唯一通道，是桥

6. **`else` 返祖边分支**：
   - `low[rt] = min(dfn[i], low[rt])` —— 注意这里用的是 `dfn[i]`（邻居的时间戳）而不是 `low[i]`！因为返祖边只能算"一条"，不能把邻居 $i$ 通过其自身子树追溯到的能力也算上。用 `dfn[i]` 精确表达"通过这条返祖边直接到达节点 $i$"。

#### 主函数

```cpp
int main()
{
	ios::sync_with_stdio(false);
	cin.tie(nullptr); cout.tie(nullptr);
	int n, m;
	cin >> n >> m;
	init(n, m);
	for (int i = 1; i <= m; i++)
	{
		int u, v;
		cin >> u >> v;
		add(u, v);
	}
	for (int i = 1; i <= n; i++)     // 遍历所有连通分量
	{
		if (!dfn[i]) tarjan(i, -1);
	}
	cout << is_bridge.size() << '\n';
	for (pair<int, int> i : is_bridge)
		cout << i.first << ' ' << i.second << '\n';
	return 0;
}
```

注意：代码处理了图不连通的情况——外层循环遍历所有节点，对每个未访问的连通分量启动一次 Tarjan。根节点的父节点设为 `-1`（不存在的节点编号）。

### 复杂度分析

#### 时间复杂度：$O(n+m)$

- 每个节点恰好被访问一次（`dfn` 从 0 变非 0 只发生一次）
- 每条无向边被访问两次（双向各一次），其中一条因父边判定被跳过，实际有效处理一次
- 总操作量与顶点数 $n$ 和边数 $m$ 成线性关系

#### 空间复杂度：$O(n+m)$

- 邻接表：$O(n+m)$
- `dfn`、`low` 数组：各 $O(n)$
- `is_bridge` 结果数组：最坏 $O(m)$（全是桥，即树）
- DFS 递归栈深度：最坏 $O(n)$（链状图）

### 适用场景

#### 适用场景

1. **桥的检测**：找出无向图中所有的桥（割边）
2. **边双连通分量**：将所有桥删除后，每个极大连通子图就是一个边双连通分量。桥是边双连通分量之间的"关节边"
3. **网络可靠性分析**：找出网络中的关键链路，故障后会导致网络分裂
4. **2-边连通性问题**：判断图是否 2-边连通（无桥），或至少需要添加多少条边使图变成 2-边连通

#### 不适用场景

1. **有向图**：桥是无向图的概念，有向图的对应概念需另行定义（如强连通分量）
2. **需要点双连通分量**：点双连通分量基于割点，不是桥
3. **动态图**：边不断增删的图，Tarjan 是静态算法，每次增删边都需要重新运行

### 常见陷阱与注意事项

#### 1. 桥的判定是严格大于

桥的判定条件是 `low[i] > dfn[rt]`（**严格大于**），而割点是 `low[i] >= dfn[u]`（大于等于）。

- **割点**：子树追溯不到 $u$ 之外 → $u$ 是割点。等于号成立说明子树能回到 $u$ 自己，但 $u$ 被删后子树仍然孤立
- **桥**：子树必须连 $u$ 都回不到 → 这条边才是桥。等于号时子树能通过返祖边回到 $u$，说明存在替代路径，这条边不是桥

#### 2. 返祖边更新必须用 dfn[i] 而不是 low[i]

返祖边更新 low 值时，代码写的是 `low[rt] = min(dfn[i], low[rt])`，用的是邻居的 `dfn[i]`，不是邻居的 `low[i]`。

原因：`low` 的定义是"通过**最多一条**返祖边"能到达的最早节点。如果用 `low[i]` 更新，就相当于把 $i$ 通过其子树进一步追溯的结果也算进来了，等于走了多条返祖边，会导致 `low` 值过小，从而把本应是桥的边漏判。

#### 3. 重边处理：只跳第一条父边

无向图中，如果 $u$ 和 $v$ 之间有**重边**（两条以上的平行边），删掉其中一条不影响连通性，因此重边不可能是桥。

**错误做法**：`if (fa == i) continue;` —— 这会跳过所有指向父节点的边，导致重边中的第二条也被跳过，无法作为返祖边更新 `low` 值，从而可能把重边误判为桥。

**正确做法**：用局部计数器 `cnt` 只跳过邻接表中第一条出现的父边（`if (fa == i && !cnt)`），后续重边走到 `else` 分支作为返祖边处理，正确更新 `low` 值，使重边不会被误判为桥。

#### 4. 图不连通的处理

代码外层有 `for (int i = 1; i <= n; i++) if (!dfn[i]) tarjan(i, -1);`，确保每个连通分量都被处理。这一点很重要，否则非连通图的某些分量会被漏掉。

#### 5. 桥的输出顺序

桥以 `(rt, i)` 的顺序存入，即父节点在前、子节点在后。输出的方向与 DFS 树的父子关系一致，与输入的边的方向不一定相同。同一座桥只会被记录一次（从父到子的方向）。

#### 6. 自环边

自环（节点到自己的边）不是桥——删掉自环不影响连通性。在代码中，自环会被 `else` 分支（返祖边）处理，`low[rt] = min(dfn[rt], low[rt])` 没有变化，且不会触发桥的判定（桥的判定只在树边分支）。所以自环被正确忽略。

### 对比与扩展

#### 与割点算法对比

| 对比维度 | Tarjan 求桥 | Tarjan 求割点 |
|----------|-----------|-------------|
| 判定对象 | 边 | 顶点 |
| 判定条件 | `low[v] > dfn[u]`（严格大于） | `low[v] >= dfn[u]`（大于等于），根节点单独判定 |
| 根节点处理 | 无需特殊处理 | 需统计子树个数，子树数 $\geq 2$ 才是割点 |
| 结果存储 | 边对 `(u, v)` | 顶点编号 |
| 时间复杂度 | $O(n+m)$ | $O(n+m)$ |
| 空间复杂度 | $O(n+m)$ | $O(n+m)$ |

#### 边双连通分量

将图中所有的桥都删除后，每个极大的连通子图称为一个**边双连通分量**（Edge-Biconnected Component, E-BCC）。边双连通分量内部没有桥——任意两点之间至少有两条边不相交的路径。

求边双连通分量的方法：
1. 用 Tarjan 找出所有桥
2. 删除所有桥，对剩余图做 DFS/BFS 染色，每个连通块就是一个边双连通分量

#### 点双连通分量

点双连通分量（Vertex-Biconnected Component, V-BCC）是指不存在割点的极大子图。点双连通分量的关系比边双更复杂：一个割点可以属于多个点双连通分量。求点双连通分量需要在 DFS 中维护一个栈，保存经过的边，发现割点时弹栈得到一个点双。

#### 2-边连通性增强

给定一个无向图，问至少添加几条边可以使图变成 2-边连通（没有桥）。解法：
1. 求所有边双连通分量，将每个分量缩成一个点
2. 缩点后的图是一棵树，所有的"边"都是原来的桥
3. 答案 = $\lceil \frac{\text{叶子数}}{2} \rceil$，其中叶子是缩点后度数为 1 的节点

这个结论与"无向图添加最少边使图强连通"（缩点后入度0和出度0的最大值）是类似的对偶问题。

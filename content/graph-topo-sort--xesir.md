## 算法原理

有一堆任务，有些任务必须在另一些任务之前完成。问：能不能把所有任务排成一个线性顺序，使得每个任务的所有前置任务都排在它前面？

这就是**拓扑排序**。

**定义**：对一个**有向无环图**（DAG）的所有顶点进行线性排序，使得对于每条有向边 $u \to v$，$u$ 都排在 $v$ 的前面。

**关键前提**：只有 DAG 才有拓扑排序。如果图里有环，就永远排不出来（环上的任务互相依赖，不存在先后关系）。

**Kahn 算法（BFS 版）** 的步骤：

1. 统计每个点的入度（即有多少条边指向它）。
2. 把所有入度为 0 的点入队（这些点没有任何前置依赖，可以最先做）。
3. 每次从队列里取出一个点 $u$，把它加入拓扑序列；然后遍历 $u$ 的所有出边 $u \to v$，把 $v$ 的入度减 1。如果 $v$ 的入度变成 0，就把 $v$ 入队。
4. 重复直到队列为空。如果最后拓扑序列的长度小于总点数，说明图里有环，无法拓扑排序。

## 核心公式 / 状态定义与转移方程

入度约束（对每条边 $u \to v$）：

$$d^-(v) \leftarrow d^-(v) - 1$$

当某个点入度降为 $0$ 时即可入队：

$$v \in Q \iff d^-(v) = 0$$

最终判定：

$$\text{拓扑序列长度} = n \;\Rightarrow\; \text{是 DAG};\quad < n \;\Rightarrow\; \text{有环}$$

## 逐行代码解析

下面把整份模板按模块拆开讲，各块按顺序拼起来就是完整代码。

### 模块一：头文件与全局变量

```cpp
#include <bits/stdc++.h>
using namespace std;
const int N=1e9;
bool v[N];
vector<vector<int>> s(N);
int h[N];
vector<int> pai;
queue<int> q;
int n,m;
```

- `s` 是邻接表，`s[x]` 存 `x` 的所有后继；`h` 记录每个点的入度。
- `pai` 用来存拓扑序列，`q` 是 Kahn 算法的 BFS 队列。
- `bool v[N]` 这份代码里其实没用上；另外 `N` 开成了 `1e9`，见下面"常见陷阱"。

### 模块二：读边并统计入度

```cpp
int main() {
    cin>>n>>m;
    for (int i=1;i<=m;i++) {
        int x,y;
        cin>>x>>y;
        s[x].push_back(y); 
        h[y]++;
    }
```

- 读 $n$ 个点、$m$ 条有向边。
- 对每条边 $x \to y$：把它加进 `s[x]`，同时给 `y` 的入度 `h[y]` 加 1。

### 模块三：入队初始点 + Kahn 主循环

```cpp
    for(int i=1;i<=n;i++){
        if(h[i]==0){
            q.push(i);
            pai.push_back(i);             
        }
    }
    while (q.size()) {
        int t=q.front();
        q.pop();                 
        for(int j:s[t]){            
            h[j]--;
            if(h[j]==0){q.push(j);pai.push_back(j);}            
        } 
    }
```

- 先扫一遍所有点，把入度为 0 的点入队、并同时放进 `pai`。
- 主循环里取出队首 `t`，遍历它的所有后继 `j`，把 `h[j]` 减 1；一旦某个 `j` 的入度减到 0，就入队并追加到 `pai`。

### 模块四：输出拓扑序 / 判环

```cpp
    if(pai.size()==n){
        for(auto i:pai){
            cout<<i<<" ";
        }
    }else{
        cout<<-1;
    }
    return 0;
}
```

- 如果 `pai` 里恰好有 $n$ 个点，说明所有点都被排进去了，输出这个拓扑序。
- 否则说明有环排不出来，输出 `-1`。

## 复杂度分析

- 时间复杂度：$O(n+m)$，每个点、每条边都只被处理常数次。
- 空间复杂度：$O(n+m)$，邻接表加上入度、序列、队列几个数组。

## 适用场景

- **判断图是否有环**：能拓扑排序就是 DAG，否则有环。
- **DP 顺序**：树上或 DAG 上的 DP（最长路、方案数等）需要按拓扑序计算。
- **任务调度**：确定任务的先后执行顺序。
- **依赖解析**：比如包管理工具处理软件包依赖。

拓扑排序本身不算"难题"，但它经常作为其他算法的前置步骤出现。比如树形 DP 里的"先算子树再合并"，本质上就是一种树上的拓扑序——很能体现图论的万金油性质。

## 常见陷阱与注意事项

1. **数组上限写成了 `1e9`**：`const int N=1e9; bool v[N]; int h[N];` 这么写数组根本开不出来（`h` 要 4 GB），`vector<vector<int>> s(N)` 也会构造 $10^9$ 个空 vector。实战要按数据范围把 `N` 改小（比如 $10^5$）。
2. **`bool v[N]` 没用上**：这份模板里它是个"僵尸数组"，真正参与判环的是 `pai.size()` 和总数 $n$ 的比较。
3. **只对 DAG 有效**：有环时输出 `-1` 或者序列长度不足，别把它当成"万能排序"。
4. **入度数组与邻接表要同步清空**：多组数据时 `h`、`s`、`q`、`pai` 每组都要重置。
5. **入队时机**：初始入度为 0 的点要一次性入队；后续只有在入度**刚减到 0** 时才入队，重复入队会出错。

## 对比与扩展

Kahn（BFS 版）思路直观、天然能判环，是最常用的写法；另一种是 **DFS 版**——对每个点做 DFS，在递归返回时把当前点压栈，最后栈的逆序就是拓扑序，同时也能检测环（DFS 中遇到还在递归栈里的点即有环）。两者复杂度相同，Kahn 更好写、也更容易做"字典序最小拓扑序"之类的变形。

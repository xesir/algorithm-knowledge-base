## 算法原理

分块的核心思想是**把序列（或值域、操作序列、树）切成大小约为 $\sqrt n$ 的块**，块内暴力、块间整体处理。它的复杂度通常比线段树多一个 $\sqrt n$，但实现简单、常数小，而且能处理线段树很难维护的信息（区间众数、区间不同数个数、区间 $\le k$ 的个数等）。

本页是「数据结构」大类下的二级总述，按「对什么分块」把相关知识点分成七组：

- **序列分块**：区间加 / 区间求和、区间 $\le k$ 的个数、区间开根等（`ds-block-decomposition`）。
- **莫队**：把询问按块排序，用指针在相邻询问之间移动（普通莫队、带修莫队、回滚莫队，`ds-mo-team`、`ds-mo-team-modify`）。
- **值域分块**：对值域而非下标分块，用于第 $k$ 小、mex、值出现次数统计（`ds-block-value-domain`）。
- **时间分块（操作分块）**：把修改/询问按时间切块，块内暴力重做、块间复用（`ds-block-time`）。
- **树分块**：在树上按深度或关键点分块，处理树上路径统计（`ds-block-tree`）。
- **二维分块**：矩阵与二维数点类问题（`ds-block-2d`）。
- **块状链表与 Sqrt Tree**：把块做成链表以支持插入删除（`ds-fast-block-list`、`ds-index-tree-block-list`），以及在块上建静态 RMQ 结构（`ds-sqrt-tree`）。

## 核心公式 / 状态定义与转移方程

- 块长通常取 $B=\lfloor\sqrt n\rfloor$ 或 $\sqrt{n\log n}$；块数 $n/B$。
- 单次修改/查询：整块 $O(n/B)$ 个 + 零散 $O(B)$ 个元素，取 $B=\sqrt n$ 得 $O(\sqrt n)$。
- 莫队：块长取 $n/\sqrt m$ 时总复杂度约 $O(n\sqrt m)$；带修莫队块长取 $n^{2/3}$，复杂度约 $O(n^{5/3})$。
- 值域分块：值域 $V$ 上的查询为 $O(\sqrt V)$。
- Sqrt Tree：$O(n\log\log n)$ 预处理，$O(1)$ 区间查询。

## 逐行代码解析

本页是总述页，不附实现。各分块类型的模板、块长取法与逐行注释在对应子条目中；分块的核心代码骨架是「预处理每个元素所属块 + 每块的聚合信息 + 修改/查询时分别处理整块与零散块」三段。

## 复杂度分析

- 序列分块：单次修改/查询 $O(\sqrt n)$；$q$ 次操作 $O(q\sqrt n)$。
- 莫队：$O((n+q)\sqrt n)$（普通）、$O(n^{5/3})$（带修）。
- 值域分块：$O(\sqrt V)$ 单次，$O(n\sqrt V)$ 总量级。
- 树分块：单次路径查询 $O(\sqrt n)$ 级别，视具体形态而定。
- 二维分块：单次 $O(\sqrt n)$ 或 $O(n^{2/3})$，取决于块长设计。

## 适用场景

- 需要维护区间信息，但线段树难以合并（众数、不同数个数、$\le k$ 计数）。
- 询问可离线、且相邻询问的答案可以 $O(1)$ 移动指针维护 → 莫队。
- 值域大而询问少 → 值域分块。
- 修改与询问混合、且修改难以快速作用到结构上 → 时间分块（操作分块）。
- 树上路径统计、且不想写树链剖分 → 树分块。
- 需要支持在序列中间插入删除 → 块状链表。
- 不适合：能直接用线段树/树状数组 $O(\log n)$ 解决的问题，分块的 $\sqrt n$ 常数反而更慢。

## 常见陷阱与注意事项

- 块长不是 $\sqrt n$ 一定最优：带修莫队、二维分块、树上分块的块长要按操作类型重新推。
- 零散块边界写成 `l` 到 `min(r, bel[l]*B)`，容易把整块也暴力一遍。
- 懒标记与块内实际值不同步：整块加标记后，块内元素值没有更新。
- 莫队指针移动顺序写错，导致区间为空时答案非法。
- 带修莫队忘记把时间维一起排序。
- 值域分块的下标映射（离散化）与原始值混淆。

## 对比与扩展

分块与线段树、树状数组是互补关系：能用可合并信息就用线段树，信息不可合并时退回分块。莫队可以看成「分块 + 双指针」，树分块与树链剖分解决同一类问题但实现代价不同；二维分块常与莫队二次离线结合。学习顺序建议：序列分块 → 莫队 → 值域分块/时间分块 → 树分块/二维分块 → Sqrt Tree 与块状链表。

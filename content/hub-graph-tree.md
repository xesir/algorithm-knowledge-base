## 算法原理

树上问题专指**在无向树（或有向树形结构）上**做路径与子树相关的查询与修改。它不包括用线段树维护区间这类与树无关的内容，成员只有图论大类下的树算法：

- **树的表示与性质**：树的定义、度数、深度、子树、直径与重心（`graph-tree-basic`、`graph-centroid`）。
- **最近公共祖先**：倍增（`graph-lca-doubling`）、重链剖分（`graph-lca-hld`）、Tarjan 离线（`graph-lca-tarjan`）。
- **树上路径操作**：重链剖分 + 线段树（`graph-hld-segtree`）、虚树（`graph-virtual-tree`）。
- **特殊树形**：基环树（`graph-cyclic-tree`）。

## 核心公式 / 状态定义与转移方程

- 深度与祖先：`dep[v] = dep[fa[v]] + 1`；倍增表 `up[k][v] = up[k-1][ up[k-1][v] ]`。
- LCA：先把两点抬到同深度，再从高到低同时上跳。
- 重链剖分：`siz[v] = 1 + Σ siz[son]`，重儿子取 `siz` 最大者；`dfn` 保证一条重链连续。
- 路径查询：把路径拆成 $O(\log n)$ 段重链区间，交给线段树。
- 虚树：只保留关键点与它们的 LCA，按 `dfn` 排序后用栈建树。

## 逐行代码解析

本页是总述页，不附实现。倍增 LCA、树链剖分、虚树、基环树的完整模板与逐行注释在各子条目中；它们共用的前置是「一次 DFS 求 `dep` / `fa` / `siz` / `dfn`」。

## 复杂度分析

- 倍增 LCA：预处理 $O(n\log n)$，单次查询 $O(\log n)$。
- 树链剖分：预处理 $O(n)$，单次路径操作 $O(\log^2 n)$。
- Tarjan 离线 LCA：$O(n+q)$。
- 虚树：单次建树 $O(k\log k)$，$k$ 为关键点数。
- 重心：$O(n)$。

## 适用场景

- 需要求两点 LCA、两点距离、路径上的最值/和。
- 需要对路径或子树做整体修改与查询（树链剖分）。
- 多次询问只涉及少量关键点（虚树）。
- 树上恰好有一个环（基环树），需要拆环后分别处理。
- 不适合：图不是树（有多个环）时不能直接套 LCA / 树链剖分。

## 常见陷阱与注意事项

- 倍增上界开小（要开 $\lfloor\log_2 n\rfloor+1$）。
- 树链剖分后把 `dfn` 与原始编号混用。
- 递归 DFS 在深链上爆栈。
- 虚树建树时忘记把 LCA 也加入关键点。
- 基环树找环写错，或多棵基环树森林没有分别处理。

## 对比与扩展

树上问题与数据结构结合最紧的是「树链剖分 + 线段树」；与 DP 结合是树形 DP；与分块结合是树分块。学习顺序建议：树的遍历与性质 → 倍增 LCA → 树链剖分 → 虚树 → 基环树。

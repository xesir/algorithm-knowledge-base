## 3. 现在怎么加知识点 / 加题目（2026-10-29 版）

### 3.0 输入长什么样

world-needs-sunday会丢**一个文件夹**，按内容判断角色（文件名不固定）：

```
任意文件夹/
├── 题目.md / 题目.txt   ← 只有题目才有
├── 代码.cpp             ← world-needs-sunday本人写的实现（可能没有）
└── 思路.md / 思路.txt   ← world-needs-sunday的思路总结
```

代码**逐字符搬运、不改实现**；题面**忠实转述，不补数据范围/样例**；讲解可润色扩充。

### 3.1 加知识点

1. **先 scaffold**：
   ```bash
   node tools/new-kp.js --id dp-interval-stone --title "区间DP·石子合并" \
        --category 动态规划 --subcategory 区间DP --level A
   ```
2. 写 `content/<id>.md`：
   - frontmatter 必填：`id` `title` `category` `subcategory`
   - 常用可选：`tags` `timeComplexity` `spaceComplexity` `level` `verified` `codePath` `noCode` `source`
   - 正文七章：**算法原理 / 核心公式或状态定义 / 逐行代码解析 / 适用场景 / 复杂度分析 / 常见陷阱 / 对比与扩展**
3. 代码放对应分类目录，`codePath` 用**反斜杠相对路径**；纯讲解类写 `noCode: true`，不写 `codePath`。
4. **多作者版本**：`content/<id>--<作者key>.md`；新作者须在 `build.js` 的 `AUTHOR_KEYS` 登记
   （当前：`fenfeng`→`Fohen`、`xesir`→`Xesir`、`lker`→`lker`、`stripe-python`→`stripe-python`），
   主版本 `content/<id>.md` 的作者固定是 `world-needs-sunday`。
5. **外部内容合并**：非本站作者的内容用 `--<作者key>` 命名 + `legacy: true` + `source`，正文首行标注授权来源；只收知识点/题目/技巧。
6. 图谱登记：`knowledgePoints[id] = { prerequisites: [...], related: [...] }`；新子分类要在 `subcategories` 里加描述。
7. 门禁：`node tools/lint.js` → `node build.js`。

### 3.2 加题目

1. scaffold：
   ```bash
   node tools/new-problem.js --id prob-luogu-p1050 --title "P1050 循环" \
        --oj 洛谷 --problemId P1050 --difficulty 普及+/提高− --category 数学
   ```
   （`--difficulty` 只能填九档之一；查不到写 `暂未评定`）
2. 写 `problems/<id>.md`，frontmatter 至少：`id` `title` `oj` `problemId` `difficulty` `cfRating` `category` `tags` `codePath` `level` `verified` `source`
   + **`knowledgePoints: []`**（本轮新增，用于星图连边，填知识点 id 数组）。
3. 正文小节必须齐全：`题目描述` → `输入格式` → `输出格式` → `数据范围` → `思路` → `代码解析` → `复杂度`。
4. 代码放 `题目专辑/<大类>/<题名>/代码.cpp`；作者版 `代码--<作者key>.cpp` + `problems/<id>--<作者key>.md`。
5. **若该题同时被写成知识点**：知识点侧只留纯知识 + 模板题链接，题解放这里（第 8 条要求）。
6. 门禁：`node tools/lint.js` → `node build.js`。

### 3.3 加星图关系

- 知识点侧：`knowledge_graph.json` 的 `prerequisites` / `related`（`related` 必须双向）。
- 题目侧：题目 frontmatter 的 `knowledgePoints`（构建后题目节点自动连向这些知识点）。
- 前端行为：星图右上角「星图显示题目」默认**关闭**，开启后才出现灰色飞镖；中心为题目且关闭开关时会自动退出星图并回到题目页。

### 3.4 修改已有内容

- 最小改动；正文代码块要跟 `.cpp` 同步（lint 会比对，真漂移 0 才算过）。
- 只是「代码改了正文没改」时，只同步正文代码块，别重写整篇。

```bash
node tools/lint.js            # 内容门禁（error 必须 0）
node tools/lint.js --quiet    # 只看汇总
node build.js                 # 生成三个产物
```

  `& "C:\Program Files\Adobe\Adobe Creative Cloud Experience\libs\node.exe" tools/lint.js`
- **本机无 `g++` / `gcc` / `clang`**：C++ 无法本地编译验证，只能依赖 lint W028（正文代码 ↔ `.cpp` 同步）与用户原稿。

- PowerShell **不支持 heredoc**：多行提交信息先写临时文件，再 `git commit -F <file>`。
- 本仓库 **git 未配置 user.name/user.email**：提交时用环境变量临时指定，不要改全局 config：

## 3. 现在怎么加知识点（本轮实测流程）

1. 读源 `.md`：确认 frontmatter 的 `id` / `category` / `subcategory` / `codePath` 已齐全。
2. 建代码目录并原样搬运 `代码.txt` → `codePath` 指向的 `Untitled1.cpp`（`Copy-Item`，不改字符）。
3. `.md` 复制为 `content/<id>.md`；若章节标题被粘连/缺失，只拆标题、不动正文。
4. 图谱：`subcategories` / `subSubcategories` 缺就补描述；`knowledgePoints[id]` 写 `prerequisites`，`related` 必须双向。
5. 门禁：`node tools/lint.js`（error 0）→ `node build.js`。
6. 同步 `AGENTS.md` / `PROJECT_FRAMEWORK.md` / `docs/让AI了解本站-提示词.md` 的规模数字（README 只追加，不改正文）。

## 4. 常用命令与环境备忘

- `node` 不在 PATH，用绝对路径：
  `& "C:\Program Files\Adobe\Adobe Creative Cloud Experience\libs\node.exe" tools/lint.js`
- 本机无可用 `g++`，C++ 无法本地编译验证；依赖 lint W028（正文代码 ↔ `.cpp` 同步）与用户原稿。
- PowerShell 执行策略 Restricted：每次报 profile 加载失败，**可忽略**。
- git 未配置 user.name/email：提交时用 `$env:GIT_AUTHOR_NAME=...` / `$env:GIT_COMMITTER_*` 临时指定，不改全局 config。

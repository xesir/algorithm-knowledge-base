1. 读源 `.md`：确认 frontmatter 的 `id` / `category` / `subcategory` / `codePath` 已齐全。
2. 建代码目录并原样搬运 `代码.txt` → `codePath` 指向的 `Untitled1.cpp`（`Copy-Item`，不改字符）。

4. 图谱：`subcategories` / `subSubcategories` 缺就补描述；`knowledgePoints[id]` 写 `prerequisites`，`related` 必须双向。
5. 门禁：`node tools/lint.js`（error 0）→ `node build.js`。

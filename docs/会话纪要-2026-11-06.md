## 3. 现在怎么做

### 3.1 加知识点 / 加题目 / 改内容

仍按 `AGENTS.md` 与 `.trae/skills/*` 执行，**本轮未改变内容流程**：

```powershell
& "<node>" tools/lint.js --quiet
& "<node>" build.js
```

### 3.2 提交一条投稿（前台）

1. `login.html` 登录（作者账号或任意已激活账号）。
2. 「提交工单」→ 类型选「投稿」。
3. 填：栏目名称（必填）、作者（默认自己）、所属大类（必填）、标签（可选/可自定义）、关系（可多条）、是否题目 + 难度（可选）、内容（网页输入或上传文本文件）。
4. 提交后生成 `tickets(type='submission', payload=jsonb)`，状态 `pending`。

### 3.3 审批并自动入库（后台）

1. `admin.html` → 「工单审批」，确认该行「效果」列显示 **通过后自动入库**。
2. 点「通过并入库」→ `tickets.status='approved'`。
3. 触发器自动写入 `columns`：
   - `column_key = 'sub-' + 工单 id`，`status='published'`，`source_ticket_id` 记录来源；
   - `owner_id = payload.author_id`（缺省为提交者）；
   - 标签写入 `columns.tags` 并 upsert 到 `tags` 表；
   - 多条关系写入 `columns.relations`，首条同步到 `relation_type/relation_target`。
4. 校验：

```sql
select column_key, owner_id, category, tags, relations, status, source_ticket_id
from public.columns where source_ticket_id = <工单 id>;
```

### 3.4 专栏管理

- 管理员在 `admin.html` →「专栏管理」可直接新建（insert）。
- 普通用户新建专栏 = 提交投稿工单，审批通过后自动入库；可在「我的投稿」撤回 `pending` 投稿。
- 修改自己已发布专栏内容不需工单，直接在专栏管理里编辑。

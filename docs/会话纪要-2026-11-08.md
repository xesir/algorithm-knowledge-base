## 4. 现在怎么用

- **作者登录**：邮箱、QQ、洛谷、CF、昵称任意一个 + 登录密码。
- **看自己/他人专栏**：作者用登录密码解锁自己名下专栏（默认密码）；管理员登录后无需密码，直接看任意专栏。
- **改专栏**：登录 → 修改工单 → 选专栏 → 密码（自己的默认密码；无密码专栏免输）→ 点「显示 Markdown 源码」后再编辑/下载/上传 → 提交待审批。
- **管理员改专栏**：`admin.html` 专栏管理，选中后点「显示 Markdown 源码」再编辑，保存立即写库。

## 5. 待办 / 已知问题

- 密码门仍是**前端展示层**控制：正文存在于公开的 `data.js` 与匿名可读的 `published_columns`，无法阻止直接读取静态文件；真正保密需改为「验证后由 RPC 下发正文」。
- 登录解锁后记录在本标签页 `sessionStorage`，刷新免重输，关标签失效。
- `resolve_login_email` 无频率限制，理论上可被在线撞库；如需加强可在网关或 Auth 层限流。
- `supabase/` 目录约 5.46 MB 已随仓库公开，用户尚未要求移出。

## 6. 踩过的坑

| 现象 | 原因 | 处理 |
|---|---|---|
| 专栏密码「完全没有生效」 | `column_locks` 7 条默认行 `password_hash` 全为 `null` | phase12 把作者登录密码的 bcrypt hash 复制进默认行 |
| 用 QQ/昵称登录失败 | Supabase Auth 只认邮箱，注册邮箱是按首个标识生成的 | phase13 RPC 先用密码校验标识，再返回真实登录邮箱 |
| 正文在密码门前闪现 | 密码状态异步返回前先渲染正文 | 增加 `lockStatusReady` 与「正在检查访问权限…」占位 |
| `node` 不在 PATH | 本机未安装到系统路径 | 使用 `C:\Users\admin\AppData\Roaming\secoresdk\360se6\Application\components\Node\node.exe`（v22.14.0） |
| PowerShell 内联 Python 转义失败 | `$`、引号被 PowerShell 解析 | 改为写 `.py` 到 `临时文件/数据/`，用 `python -B` 执行，用完删除 |

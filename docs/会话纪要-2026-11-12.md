## 1. 本轮完成的功能

### 1.1 元数据便捷修改（phase21 → phase22）

- **入口**：详情页 Meta 栏「👤 作者」右侧的「✏️ 便捷修改」按钮；知识点与题目都有。
- **范围**：只改非正文，正文不动。
- **管理员**：调用 `admin_update_column_meta(jsonb)`，校验 `profiles.role='admin'` 与 `expected_updated_at`（乐观锁），直接写 `columns` 并刷新页面；同时插入一条 `status='approved'` 的审计工单，供贡献计分。
- **普通用户**：调用 `submit_column_meta_edit(...)`（phase22 起 12 参），生成 `type='edit'`、`status='pending'` 工单；payload 带 `meta_only=true`、正文快照、`base_updated_at`、新旧字段值。
- **审批**：`publish_submission_ticket` 先把正文快照写回（内容不变），再由 `trg_z_apply_meta_fields` 写回评分 / OJ / 题号 / 复杂度并置 `meta_override=true`。
- **关系预填**：DB `relations` 为空且 `relations_override=false` 时，回退静态 `prerequisites / related / parent`（题目为 `knowledgePoints`）。

### 1.2 phase22 扩展字段

`columns` 新增：

| 字段 | 含义 |
|---|---|
| `cf_rating` | CF 难度评分（题目） |
| `oj` | 来源 OJ（题目） |
| `problem_id` | 题号（题目） |
| `time_complexity` | 时间复杂度（知识点 / 题目） |
| `space_complexity` | 空间复杂度（知识点 / 题目） |
| `meta_override` | 是否被人工覆盖；为 true 时前端以数据库为准 |

`published_columns` 同步暴露上述字段；前端增量同步按 `meta_override` 决定是否覆盖静态值。

### 2.2 CF 评分预填成 `NaN`

- **现象**：`build.js` 对缺失评分的题目导出 `cfRating: 'NaN'`，便捷修改弹窗原样预填 `NaN`，保存时被「CF 评分只能填数字」拦截。
- **修复**：弹窗预填统一清洗，`NaN / undefined / null / - / — / 未知` 一律显示为空；缺失信息可以直接留空保存（空值写入数据库为 `NULL`）。
- **位置**：`index.html` 的 `openMetaEdit()` 内 `cleanMetaText()`。
- **提交**：`2d3117c`，并随 `data.js` 重建一起发布。

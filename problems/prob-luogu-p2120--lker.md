## 题目描述

原文未附题面，以下题意根据作者思路整理。

有 $n$ 个工厂排成一列，第 $i$ 个工厂的坐标为 $x_i$、商品数量为 $p_i$，在工厂 $i$ 处建仓库的花费为 $c_i$。建若干仓库，每个工厂的商品运往它右侧最近的仓库（本题的转移式对应「$(j,i]$ 的商品都运到 $i$」这种切分）。设 $f_i$ 表示前 $i$ 个工厂中建仓库、并把前 $i$ 个工厂的商品都处理好的最小代价，则

$$f_i=\min_{j<i}\left(f_j+c_i+\sum_{k=j+1}^{i}p_k(x_i-x_k)\right)$$

原文只给了这个转移式，没有交代 $n$、$x_i$、$p_i$、$c_i$ 的取值范围。

## 解题思路

### 一、状态与转移

$f_i$ 表示前 $i$ 个工厂里建仓库的最小代价，枚举上一个仓库的位置 $j$（在 $i$ 建新仓库，$(j,i]$ 的商品全部运到 $i$）：

$$f_i=\min_j\left(f_j+c_i+\sum_{k=j+1}^{i}p_k(x_i-x_k)\right)$$

瓶颈是那个求和：每枚举一个 $j$ 都要重算一遍。

### 二、把求和拆开

约定两个前缀和：

$$s_i=\sum_{k=1}^{i}p_k,\qquad l_i=\sum_{k=1}^{i}p_kx_k$$

于是

$$\sum_{k=j+1}^{i}p_k(x_i-x_k)=x_i(s_i-s_j)-(l_i-l_j)$$

### 三、回代，化成直线

把拆开的结果塞回转移式，与 $i$ 无关的项提出来：

$$f_i=c_i-l_i+s_ix_i+\min_j\left(-s_jx_i+(l_j+f_j)\right)$$

括号里又成了直线：斜率 $-s_j$、截距 $l_j+f_j$，自变量是 $x_i$。

### 四、最小值 + 斜率递减

商品数量 $p_k$ 非负，所以 $s_j$ 随 $j$ 单调不减，斜率 $-s_j$ **单调递减**；求的是最小值，对应的就是下包络。用单调队列维护凸壳即可，判据与 P3195 同一套。

### 五、后缀全为 0 的坑

原文强调：如果某一段**后缀里商品数量都是 $0$**，那么这一段没必要非把东西全部运到 $n$ 处（在那里建仓库纯属浪费），正确答案要在这段后缀里取最小的 $f_i$。这一步不做，hack 数据过不去。

实现要点（根据原文整理）：

- **两个前缀和都要维护**：$s_i=\sum p_k$ 与 $l_i=\sum p_kx_k$，后者要用 64 位承接，它同时充当直线截距的一部分。
- **判据要开 `__int128`**：原文明确提醒过，斜率与截距的乘积在 64 位边缘，比较时转 `__int128`。
- **队列里存下标 $j$**：斜率 $-s_j$、截距 $l_j+f_j$ 都能由 $j$ 直接算，不必单独存直线。
- **队头过期要弹**：单调队列要求查询的自变量单调递增，本题的查询量是坐标 $x_i$；队头会随时间过期，查询前先从队头弹。
- **答案取后缀最小值**：算完所有 $f_i$ 之后，从末尾往前找连续的 $p_i=0$ 位置，在这一段里取 $f_i$ 的最小值；不要直接输出 $f_n$。

## 复杂度分析

- **时间复杂度**：单调队列里每个决策点入队一次、出队一次，每次转移均摊 $O(1)$，总复杂度 $O(n)$。后缀取最小值是 $O(n)$ 的一次扫描，不改变量级。
- **空间复杂度**：$f$、$s$、$l$、$x$、$p$ 与单调队列都是 $O(n)$，合计 $O(n)$。

## 常见陷阱与注意事项

1. **后缀商品数为 0 要单独处理**：末尾几个工厂没有商品时，不必强制在 $n$ 建仓库，要在「后缀全 0」的那一段里取最小的 $f_i$，否则会被 hack 掉。
2. **必须开 `__int128`**：斜率判据中的乘法会超出 64 位，溢出后凸壳直接被弹错。
3. **最小值对应斜率递减**：本题是 min + 斜率递减（下包络），如果写成上包络，答案会偏大。
4. **求和拆分方向别错**：$x_i(s_i-s_j)-(l_i-l_j)$ 里两个前缀和一个是「数量」、一个是「数量乘坐标」，混用会让截距整体错位。
5. **$c_i$ 与 $l_i$ 的位置**：$c_i-l_i+s_ix_i$ 是与 $j$ 无关的常数，必须提到 min 外面，写进括号里会让每个候选都多加一次 $c_i$。
6. **队头过期**：忘了弹队头，$f_i$ 会用到已经不优的决策点。

## 对比与扩展

- **与 P3195 / P3628 的关系**：三题都是单调队列维护凸壳，区别只在「求 min 还是 max」和「斜率递增还是递减」。P2120 与 P3195 同属 min + 斜率递减（下包络），判据方向一致，只是 P2120 多了一步拆求和、多了一个后缀取最小值的收尾。
- **与 P3515 的对比**：P3515 的代价带根号，拆不成直线，只能分治优化到 $O(n\log n)$；本题能拆成 $s_j$ 与 $x_i$ 的乘积，才能压到 $O(n)$。
- **扩展**：本题的「拆求和 → 前缀和 → 化成直线」是很常见的预处理，凡是转移里带 $\sum p_k(x_i-x_k)$ 这种「距离乘权值」的形式，都可以先拆成 $x_i\sum p_k-\sum p_kx_k$，再考虑斜率优化。

## 解题思路

### 一、顺序可以任意重排

原文的第一句话是「由于题目没有要求选到的一定是一个连续段，所以我们可以任意改变顺序来做这个事情」。这句话是整个做法的入口：既然购买方案只关心哪些地分在一组，不关心它们在输入里的先后，那就可以先把土地按某个维度排好序，再去研究分组。

### 二、长宽都更小的地可以白嫖

原文的第二个观察：如果一块地的长和宽都比另一块地小，那么它就可以被「白嫖」——把它和那块更大的地放进同一组，这一组的价格由更大的那块地的长和宽决定，多带上它不会让价格变高。所以这类地被支配的地不需要单独付费，真正需要关心的只是那些在长、宽两个维度上都不被其他地支配的土地。

### 三、贪心筛出真正有贡献的地

原文的贪心是：先按土地的宽度降序排序，再把不符合长度升序的删去。理由写在括号里：宽度也降序的地，长度更小的那块会被长度更大的那块白嫖掉。

具体走一遍：

1. 按宽度从大到小排序。
2. 从左往右扫，维护已经保留的土地里最大的长度。
3. 如果当前土地的长度不大于这个最大长度，那么它的宽度不超过前面某块地、长度也不超过那块地，两个维度都被支配，删掉。
4. 否则保留它，并更新最大长度。

扫完之后，剩下的候选集合有两个单调性：宽度严格递减，长度严格递增。这一点是后面 DP 能做斜率优化的前提。

### 四、候选集合上的 DP

设 $f_i$ 表示考虑候选集合前 $i$ 块地的答案。枚举最后一批买的是哪一段：如果最后一批买的是第 $j+1$ 到第 $i$ 块，那么这一批里宽度最大的是最靠前的第 $j+1$ 块，长度最大的是最靠后的第 $i$ 块，价格为 $w_{j+1}l_i$。于是

$$f_i=\min_{j<i}\left(f_j+w_{j+1}l_i\right)$$

原文写的就是这个式子，直接枚举 $j$ 是 $O(n^2)$ 的。

### 五、斜率优化

把转移式按决策点 $j$ 整理：

$$f_i=\min_{j<i}\left(w_{j+1}\cdot l_i+f_j\right)$$

对于每个决策点 $j$，把它看成一条以 $l_i$ 为自变量的直线：斜率是 $w_{j+1}$，截距是 $f_j$。候选集合宽度递减，所以斜率随 $j$ 单调递减；长度递增，所以查询横坐标 $l_i$ 随 $i$ 单调递增。求最小值、斜率递减、查询点右移，这正是单调队列维护下包络的标准形状：

- 队头存当前最优决策，查询前把已经变劣的队头弹掉；
- 队尾用交点判据弹掉不可能再取到最小值的直线；
- 每个决策点至多入队、出队一次。

于是 DP 部分做到 $O(n)$，加上排序的 $O(n\log n)$，总复杂度是 $O(n\log n)$。

### 六、为什么删掉的地可以完全不管

被删掉的地一定被某块保留下来的地支配：宽度不超过它、长度也不超过它。把被删的地塞进支配它的那块地所在的那一组，组内最大长和最大宽都不会变大，价格也就不变。所以最优方案里不需要为这些地单独付钱，删掉它们不会漏掉最优解。

实现要点（根据原文整理）：

- **排序方向**：先按宽度降序；宽度相同时按长度升序，这样同宽的地里只有最长的那块可能留下。
- **删除被支配**：扫一遍并维护当前最大长度，只保留长度严格变大的地。长度没有变大的地，宽度不超过前面某块地，两个维度都被支配。
- **下标对齐**：筛完的数组从 $1$ 开始编号，$f_0=0$，转移时 $j$ 取 $0$ 到 $i-1$，价格项是 $w_{j+1}l_i$，不是 $w_jl_i$。
- **斜率优化**：决策点 $j$ 对应的直线斜率为 $w_{j+1}$、截距为 $f_j$，查询横坐标是 $l_i$；队尾按交点判据弹点，队头弹过期元素。
- **交点判据**：用乘法交叉比较，建议用 `__int128` 承接乘积，避免中间结果溢出。

## 复杂度分析

- **时间复杂度**：排序 $O(n\log n)$；单调队列 DP 中每条直线至多入队一次、出队一次，均摊 $O(1)$，DP 部分 $O(n)$。合计 $O(n\log n)$。
- **空间复杂度**：土地数组、$f$ 数组、单调队列各 $O(n)$，合计 $O(n)$。

## 常见陷阱与注意事项

1. **排序方向别搞反**：原文是「宽度降序 + 长度升序」。把长度也写成降序，删支配的逻辑就反了，保留下来的集合也不再满足宽度递减、长度递增的单调性。
2. **「不符合长度升序的删去」要理解成保留严格递增**：长度没有变大的地就是被支配的地，不能保留。
3. **同宽的地要先按长度排好**：同宽时宽度一样大，只有最长的那块可能产生贡献；不先处理长度，可能把同宽里较短的那块误留下来。
4. **转移项的下标是 $w_{j+1}$**：第 $j+1$ 到第 $i$ 块组成的这一批，最大宽度来自最靠前的第 $j+1$ 块，写成 $w_j$ 就错位了。
5. **求 min、斜率递减时维护的是下包络**：弹点判据的方向要和求 max 的版本区分开，照抄反方向会把最优直线弹掉。
6. **交点判据注意溢出**：斜率差与截距差相乘再相减，数值可能超出普通 32 位整数，比较前要换更宽的类型。

## 对比与扩展

- **同篇的 P3195、P3628、P2120**：都是把转移拆成 $kx+b$ 后用单调队列维护凸壳。本题的不同点在于 DP 之前要先贪心筛掉被支配的地，把「最大长 × 最大宽」这种二维信息压成一维的单调结构，之后才是标准的斜率优化。
- **和 P4097 的关系**：P4097 是李超线段树的模板，插入直线、查询单点最值。本题的直线斜率和查询横坐标都单调，用单调队列就够，属于李超线段树能做的子集。
- **和 P5785 的关系**：P5785 的斜率不单调，单调队列失效，只能换李超线段树。这三道题正好串成一条线——先贪心造出单调性，再用单调队列；单调性缺失时，用李超树兜底。

## 题目描述

原文未附题面，以下题意根据作者思路整理。

有 $n$ 件玩具排成一列，第 $i$ 件的长度为 $c_i$，记前缀和 $s_i=\sum_{k\le i}c_k$，另有一个常数 $l$。要把这个序列划分成若干连续段，段 $(j,i]$ 的代价是

$$\left(i-j-1+s_i-s_j-l\right)^2$$

其中 $i-j-1$ 是在数这一段里玩具之间的空隙数量。设 $f_i$ 表示前 $i$ 件玩具划分完的最小总代价，则

$$f_i=\min_{j<i}\left(f_j+\left(i-j-1+s_i-s_j-l\right)^2\right)$$

原文只写了这个转移式，没有交代 $n$、$l$、$c_i$ 的取值范围。

## 解题思路

斜率优化的入门题，整套推导值得背下来。

### 一、状态与转移

$f_i$ 表示前 $i$ 个玩具的最少代价，枚举上一段的切分点 $j$：

$$f_i=\min_j\left(f_j+(i-j-1+s_i-s_j-l)^2\right)$$

直接枚举 $j$ 是 $O(n^2)$ 的，瓶颈在于平方项里 $i$ 和 $j$ 缠在一起。

### 二、合并同类项，凑成一个平方

把只和 $i$ 有关的、只和 $j$ 有关的分别归拢：

$$f_i=\min_j\left(f_j+\left(i+s_i-(j+s_j+l+1)\right)^2\right)$$

于是令

$$x_i=i+s_i,\qquad y_j=j+s_j+l+1$$

$x_i$ 只依赖当前状态，$y_j$ 只依赖决策点——这正是能斜率优化的形状。

### 三、展开成直线

把平方拆开：

$$f_i=\min_j\left(f_j+x_i^2-2x_iy_j+y_j^2\right)=x_i^2+\min_j\left(-2y_jx_i+(y_j^2+f_j)\right)$$

括号里的东西，对每个决策点 $j$ 来说都是一条以 $x_i$ 为自变量的直线：斜率 $-2y_j$，截距 $y_j^2+f_j$。斜率与截距**都只和 $j$ 有关**，所以每个决策点对应的直线是固定的，$f_i$ 的取值只取决于这堆直线在 $x_i$ 处的最小值。

### 四、上凸壳 / 下包络

$x_i$ 随 $i$ 单调递增，$y_j$ 随 $j$ 单调递增，所以斜率 $-2y_j$ **单调递减**。把这些直线按插入顺序画在平面上，最优取值点构成一个**上凸壳**（换个说法就是这组直线的**下包络线**）。维护一条包络线只需要一个单调队列：队列里存的是可能成为最优决策的那些下标。

### 五、弹点判据

按插入顺序把队列末尾两条直线记为 $l_1,l_2$，待插入的是 $l_3$。若

$$l_3 \text{ 与 } l_1 \text{ 的交点横坐标} \le l_1 \text{ 与 } l_2 \text{ 的交点横坐标}$$

说明 $l_2$ 在任何位置都取不到最小值，直接从队尾弹掉。判据分别联立两条直线的斜截式就能得到；实现时把它整理成叉积形式，可以完全避开浮点。

### 六、查询与过期元素

队头就是当前的最优直线，$f_i$ 用它算。随着 $x_i$ 右移，队头会「过期」（第二条在 $x_i$ 处已经不比它差），所以每次查询前要从队头把过期元素弹掉。

### 七、小结

原文的总结是：只要满足 $x_i$ **单调**、斜率按插入顺序**单调**（从左往右插直线），就可以用单调队列维护凸壳。这是「能把转移拆成直线形式」的斜率优化通用套路。

实现要点（根据原文整理）：

- **$i=0$ 也要插入一条初始直线**：$f_0=0$、$s_0=0$，对应的 $y_0=l+1$、截距 $y_0^2+f_0$，它是第一个能转移给 $f_1$ 的决策点。漏掉它，$j=0$ 这一种划分方式就永远取不到。
- **注意弹出过期元素**：查询前先从队头弹，别只在队尾做凸壳维护；队头过期不弹，答案会用到已经不优的直线。
- **队列存下标而不是直线**：斜率和截距都能由下标 $j$ 直接算出来，存 $j$ 省事也不容易写错。
- **转移式里的平方项**要用 64 位整数承接，别只给 $f$ 开大类型。

## 复杂度分析

- **时间复杂度**：每个决策点对应的直线最多入队一次、出队一次（队尾弹一次、队头过期弹一次），每次转移的均摊代价是 $O(1)$，总共 $O(n)$。
- **空间复杂度**：$f$ 数组、前缀和数组、单调队列各 $O(n)$，合计 $O(n)$。

## 常见陷阱与注意事项

1. **判据必须开 `__int128`**：原文点名了这个坑，叉积的两个乘积都在 `long long` 边缘，溢出后判据时真时假，凸壳会被弹错。
2. **$i=0$ 要插入初始直线**：这是最容易被忽略的一步，少了它 $f_1$ 就无从转移。
3. **记得弹过期元素**：只在队尾维护凸壳、忘了队头过期，等价于让已经变劣的直线继续参与比较。
4. **上凸壳 / 下包络别搞反**：本题求 min、斜率递减，对应下包络；把判据方向照抄成求 max 的版本，答案会变成求最大代价。
5. **等价变形要仔细**：$j+s_j+l+1$ 里的 $+1$ 来自空隙计数 $i-j-1$，少这个 $+1$、或者把 $l$ 的符号弄反，整个式子都会偏。
6. **x 与 y 别混用**：$x_i$ 只由当前状态 $i$ 算，$y_j$ 只由决策点 $j$ 算，混着算出来的截距是错的。

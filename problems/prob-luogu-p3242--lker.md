## 解题思路

考虑对一条路径 $A$，刻画「路径 $B$ 能被 $A$ 包含」的条件。

- **情况一**：$B$ 的两个端点为 $u,v$，钦定 $u$ 的深度更浅，且 $\text{lca}(u,v)=u$。$A$ 的两个端点为 $x,y$，钦定 $x$ 更浅。此时 $x$ 可以在「除了 $u$ 到 $v$ 路径上那个儿子的子树之外」的全部位置，$y$ 可以在 $v$ 的子树中的任意位置。
- **情况二**：否则，两个点可能分别位于 $u$ 的子树和 $v$ 的子树中。

于是考虑**离线做树上二维数点**。把每条原路径拆成两个点挂到树上，维护有哪些询问路径端点符合条件，最后取并集就得到了路径。用两个 `vector` 分别维护每个点上挂的左端点和右端点；用两个 01 串分别维护「对每个询问端点，左 / 右端点是否合法」。

这两种情况都是钦定出来的，最后统计答案时把对称情况也考虑一下即可。

我们称「打了奇数次标记」为合法，利用异或实现抵消非法标记。具体挂标记的方式：

- **情况一**：左端点给根打一个标记，给 $u$ 的那个儿子打一个标记；右端点给 $v$ 打一个标记。
- **情况二**：左端点给 $u$ 打一个标记，右端点给 $v$ 打一个标记。

用树剖维护求 `lca`，dfs 入栈时打上标记，出栈弹出时清除标记，最后把两个 01 串取交。因为最开始已经对所有区间按权值排好序，所以直接找第 $k$ 个 1 对应的路径权值即可。这个复杂度有点爆炸，上一个 `bitset` 维护一下就能通过本题。

## 逐行代码解析

代码由三段组成，按顺序拼起来就是完整的 `.cpp`：先看递归打标记，再看挂标记，最后看统计答案。

### 递归：入栈打标记、出栈清标记

```cpp
void dfs(int u,int f)
{
    for(int id:vl[u]) cur_l[id]=cur_l[id]^1;
    for(int id:vr[u]) cur_r[id]=cur_r[id]^1;
    if(is_query_node[u])
    {
        fl[u]=cur_l;
        fr[u]=cur_r;
    }
    for(int i=h[u];~i;i=ne[i])
    {
        int j=to[i];
        if(j==f) continue;
        dfs(j,u);
    }
    for(int id:vl[u]) cur_l[id]=cur_l[id]^1;
    for(int id:vr[u]) cur_r[id]=cur_r[id]^1;
}
```

- `cur_l`、`cur_r` 是两个 01 串（`bitset`），表示「当前递归栈上，哪些路径的标记是奇数次」。
- 进点时把挂在这个点上的左 / 右标记全部异或一次；出点时再异或一次，等于撤销——这样 `cur` 始终对应「从根到当前点这条路」上的标记状态。
- `is_query_node[u]` 为真时把当前状态快照存进 `fl[u]`、`fr[u]`，供后面统计答案用。
- 异或天然处理了「同一条路径的两个端点都在子树内、标记要抵消」的情况。

### 挂标记：按两种情况分类

```cpp
    for(int i=1;i<=p;i++)
    {
        int u=path[i].a,v=path[i].b;
        int lca=get_lca(u,v);
        if(dep[u]>dep[v]) swap(u,v);
        if(u==lca)
        {
            int t=get_son(u,v);
            vl[1].push_back(i);
            vl[t].push_back(i);
            vr[v].push_back(i);
        }else{
            vl[u].push_back(i);
            vr[v].push_back(i);
        }
    }
    for(int i=1;i<=q;i++)
    {
        cin>>qes[i].a>>qes[i].b>>qes[i].k;
        is_query_node[qes[i].a]=1;
        is_query_node[qes[i].b]=1;
    }  
```

- 先 `swap` 保证 $u$ 是较浅的那个，再判 `u==lca`。
- 情况一：`vl[1]` 与 `vl[t]` 各打一个标记，等价于「$t$ 子树之外的全部位置」——根上打一次、$t$ 上再打一次，异或后正好抵消掉 $t$ 子树。`vr[v]` 单独给 $v$ 打右端点标记。
- 情况二：`vl[u]`、`vr[v]` 各打一个，表示「一个端点在 $u$ 子树、一个端点在 $v$ 子树」。
- 读入询问时把两个端点标记成「查询结点」，这样 dfs 时只在端点处快照。

### 统计答案：取交后找第 k 个 1

```cpp
    for(int i=1;i<=q;i++)
    {
        int u=qes[i].a,v=qes[i].b;
        bitset<N> val=(fl[u]&fr[v])|(fr[u]&fl[v]);
        int pos=val._Find_first();
        for(int j=1;j<qes[i].k;j++)
            pos=val._Find_next(pos);
        cout<<path[pos].c<<"\n";
    }
```

- `(fl[u]&fr[v])|(fr[u]&fl[v])`：把「$u$ 当左端点、$v$ 当右端点」和「$u$ 当右端点、$v$ 当左端点」两种对称情况取并，得到所有被包含的路径。
- `val` 的第 $i$ 位为 1 表示第 $i$ 条路径满足条件；因为路径已按权值排序，所以按位找第 $k$ 个 1 就得到答案。
- `_Find_first()` / `_Find_next()` 是 `bitset` 的位扫描接口，避免逐位枚举。
- `path[pos].c` 就是第 $k$ 小路径的权值。

## 复杂度分析

原文没有给复杂度。按做法估：每次 `bitset` 取交是 $O(N/64)$（$N$ 是路径条数），每个询问还要扫 $k$ 位；dfs 是 $O(n)$，`lca` 用树剖是 $O(\log n)$。总复杂度与「询问数 × 路径条数 / 64」同阶，具体取决于实现取值方式，所以这里不写死。

## 常见陷阱与注意事项

- **端点的左右角色**：两种情况都是钦定了「谁当左端点、谁当右端点」，统计答案时一定要把对称的 `(u,v)` 与 `(v,u)` 都算上，否则会漏一半。
- **情况一的子树抵消**：根上打一次、$t$ 上再打一次，靠异或抵消；如果只打 $t$ 会漏掉根那一侧。
- **出栈必须撤销标记**：少了出栈的异或，`cur` 会带着别的分支的状态，答案全错。
- **查询点才快照**：`is_query_node` 漏标会导致 `fl`/`fr` 全是空 `bitset`。
- **`bitset` 大小**：`N` 要开够路径条数，开小了会截断。
- **排序后才能按位找第 $k$**：如果路径没按权值排序，第 $k$ 个 1 就不是第 $k$ 小。

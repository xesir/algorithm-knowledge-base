## 题目描述

原文未附题面，以下题意根据作者思路整理。

给定长度为 $n$ 的序列 $h$，对每个位置 $i$ 求最小的非负整数 $p$，使得对任意 $j$ 都满足

$$h_j \le h_i + p - \sqrt{|i-j|}$$

把 $p$ 孤立出来，得到 $p \ge h_j + \sqrt{|i-j|} - h_i$。因为 $h_i$ 对每个答案而言是常数，而 $p$ 是正整数，于是

$$f_i = \max_j \left\lceil h_j + \sqrt{|i-j|} \right\rceil,\qquad ans_i = f_i - h_i$$

也就是说：每个位置要吸收掉「别的山峰高度减去距离开根号」带来的最大值。

## 解题思路

### 一、先记住四边形不等式的四种情形

约定 $w(a,d)+w(b,c) \ge w(a,c)+w(b,d)$（$a<b<c<d$）为**标准方向**，$w(a,d)+w(b,c) \le w(a,c)+w(b,d)$ 为**反常方向**。两两组合得到四种情况：

- 标准方向 + 求 min：opt 随 $i$ 增大单调不减；
- 标准方向 + 求 max：opt 随 $i$ 增大单调不增；
- 反常方向 + 求 min：opt 随 $i$ 增大单调不增；
- 反常方向 + 求 max：opt 随 $i$ 增大单调不减。

这张表是整道题的开关：**根据决策点的单调方向修改分治区间，根据求 min 还是 max 修改比较方向**，两件事都做对，分治优化才成立。

### 二、把约束拆开

原约束是 $h_j \le h_i + p - \sqrt{|i-j|}$。先把 $p$ 孤立：

$$p \ge h_j + \sqrt{|i-j|} - h_i$$

$h_i$ 对第 $i$ 个答案来说是常数，不会影响「哪个 $j$ 最优」；又因为 $p$ 是正整数，取上整即可：

$$f_i = \max_j \left\lceil h_j + \sqrt{|i-j|} \right\rceil,\qquad ans_i = f_i - h_i$$

### 三、拆绝对值：正着做一遍，翻过来再做一遍

绝对值把 $j$ 分成 $j \le i$ 和 $j \ge i$ 两半。$j \le i$ 时 $\sqrt{|i-j|}=\sqrt{i-j}$，正着扫一遍就够了；$j \ge i$ 那半边把序列**翻转**之后，就又变成了「$j \le i$」的形状。所以只需正着做一次、翻转序列反着做一次，两遍取 max 就得到完整的 $f_i$。

### 四、确定它属于四种情形里的哪一种

打表验证 $\sqrt{i-j}$ 满足**反常方向**的四边形不等式。本题要求最大值，对照第一小节的表：**反常方向 + 求 max → opt 随 $i$ 增大单调不减**。

此外 $f$ 的每个状态只依赖已经算出来的东西，与同一层里尚未确定的状态无关，允许**离线**处理——这正是分治优化能吃下的前提。

### 五、分治优化怎么落地

对状态区间 $[l,r]$ 取中点 $mid$，在给定的决策备选区间 $[optl,optr]$ 里暴力枚举，算出最优决策点 $k$ 与 $f_{mid}$；由于 opt 单调不减，$mid$ 左边的状态最优决策不会超过 $k$，右边的不会小于 $k$，于是把决策区间切成 $[optl,k]$ 与 $[k,optr]$，分别递归左右两半。

单次算一个 $f_{mid}$ 的代价是 $O(optr-optl+1)$ 的枚举，靠分治把总枚举量压下来。

### 六、答案合并

正着那一遍得到 $j \le i$ 的最优值，翻转那一步得到 $j \ge i$ 的最优值，两次取 max 才是完整的 $f_i$，最后统一减去 $h_i$。

实现要点（根据原文整理）：

- **分治函数要带两个区间**：状态区间 $[l,r]$ 与决策备选区间 $[optl,optr]$。算出 $mid$ 的最优决策 $k$ 后，左半状态继承 $[optl,k]$、右半状态继承 $[k,optr]$（opt 单调不减时就是往这个方向收）。
- **求 max 要改比较方向**：判据写成了求 min 的「更小就更新」，答案会一路偏小；这里应当是「更大才更新」。
- **绝对值必须做两遍**：只做正着的一遍，等于默认所有 $j$ 都在 $i$ 左边，右侧山峰的贡献全部丢失。
- **先比较、后取整**：代价里有 $\sqrt{\cdot}$，两个候选值的差可能小于 $1$，先取整会把两个候选压成同一个值，最优决策点随之跑偏。要在实数域把最大值挑出来，最后一步才向上取整。
- **存储**：只需要两套长度为 $n$ 的答案数组（正反两遍各一套，或原地取 max），分治过程本身不占额外空间。

## 复杂度分析

- **时间复杂度**：分治优化每一层里，状态被不断二分，枚举总量与该层状态数同阶，为 $O(n)$；递归深度是 $O(\log n)$，所以单遍是 $O(n\log n)$。正着、翻转各做一遍，常数翻倍，量级仍是 $O(n\log n)$。
- **空间复杂度**：答案数组 $O(n)$，递归栈 $O(\log n)$，合计 $O(n)$。

## 常见陷阱与注意事项

1. **四种情形记混**：标准 / 反常方向与 min / max 交叉出四种 opt 单调方向，本题是「反常 + max」，如果照着「标准 + min」那套模板抄，区间和比较方向会同时错。
2. **分治区间要按 opt 单调方向修改**：方向写反时，某个状态的最优决策点可能被切到另一半里再也搜不到，表现为答案系统性偏大或偏小，而且很难靠猜数据看出来。
3. **求 max 要改比较方向**：比较符号不改，等价于在求最小值。
4. **绝对值只做一遍**：正着扫一遍只覆盖了 $j \le i$，必须翻转序列再做一遍。
5. **向上取整的位置**：$\lceil\cdot\rceil$ 要放在所有比较结束之后。中间过程用实数（原文在同类题里提到过精度问题，用 `long double` 更稳），最后再取整。
6. **离线的前提**：分治优化要求同一层的状态互不依赖，本题满足；但如果转移是「同一层内 $i$ 依赖 $i-1$」这类，就不能直接套。

## 对比与扩展

- **与斜率优化（P3195 / P3628 / P2120）的分工**：那三题能把转移拆成 $kx+b$ 的直线，斜率单调时用单调队列维护凸壳，可以做到 $O(n)$；本题代价里带 $\sqrt{|i-j|}$，拆不出直线，只能靠决策单调性加**分治**做到 $O(n\log n)$。能不能拆成直线，是选择哪套优化的第一判据。
- **与单调队列维护决策区间（同篇的 P1912 诗人小 G）对比**：两者都吃决策单调性，区别在于 P1912 用队列维护「每段区间归属哪个决策点」、在线二分更新；本题用分治离线算。分治版写起来短，但要求代价函数能快速求值。
- **扩展**：只要验证出代价函数满足某方向的四边形不等式，就可以先用暴力 DP 打表确认 opt 单调，再套这张四种情形的表，分治优化的骨架几乎不用改。

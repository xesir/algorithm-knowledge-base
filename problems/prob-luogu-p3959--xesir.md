## 题目描述

你有一张 $n$ 个点的无向图，边有长度。

你可以**任意**选择一个起点（入口），然后**依次**开发道路：每次只能开发一条连接**已开发区域**和**未开发点**的道路，代价为 `边权 × 当前已开发层数`。

这里的「层数」定义为从入口点到这条道路起点的路径上经过的点数（包含入口和起点）。说白了，如果某个点是从入口开始数第 $k$ 层，那么连接它和它父节点的边就乘以 $k$。目标是开发所有点，最小化总代价。

> 原笔记关键词：状压 DP、分层扩展、子集枚举。前置知识是**子集 DP**（状压 DP 的一种）。

### 输入格式

原笔记没有单独写输入格式，以下按所附代码的读入逻辑整理：

- 第一行两个整数 $n, m$；
- 接下来 $m$ 行，每行三个整数 $u, v, w$，表示一条连接 $u$ 与 $v$、边权为 $w$ 的无向边。

### 输出格式

一行一个整数，表示开发所有点的最小总代价。

### 数据范围

原笔记给出：$n \le 12$，$m \le 1000$，边权 $\le 5 \times 10^5$。

## 样例

### 样例 1

**输入：**
```
4 5
1 2 1
1 3 3
1 4 1
2 3 4
3 4 1
```
**输出：**
```
4
```

**解释：** 选入口 $1$。第 $0$ 层为 $\{1\}$；第 $1$ 层可加入 $\{2\}$、$\{4\}$ 或 $\{2,4\}$，其中同时加入 $2$ 与 $4$ 的代价为 $1 \times 1 + 1 \times 1 = 2$（$2$ 和 $4$ 都连到 $1$，深度为 $1$）；第 $2$ 层加入 $\{3\}$，此时 $3$ 可以连到 $1$（代价 $3 \times 2 = 6$）、连到 $4$（代价 $1 \times 2 = 2$）或连到 $2$（代价 $4 \times 2 = 8$），取最优连到 $4$，总代价 $= 2 + 2 = 4$，正好是样例输出。

> 说明：原笔记是用文字给出这组数据的（「$n=4$，边：1-2(1),1-3(3),1-4(1),2-3(4),3-4(1)」），这里按代码的读入格式排成输入文本；输出 $4$ 是原笔记里明确写出的样例输出。

## 解题思路

### 一眼丁真

$n$ 只有 $12$，可以枚举所有点集，我一眼就看出这道题 ~~不是人~~ 是**状压 DP**。
~~你要想的话爆搜也不是不可以。~~

### 把「修路」看成「长树」

我们把最终建成的道路看成以入口为根的一棵**树**。每个节点都有一个「深度」，即从根到它的路径长度（边数）。那么代价就是：对每条边 $(u,v)$（$u$ 是父节点，$v$ 是子节点），贡献为 `边权 × dep[v]`。

### 关键性质：按深度分层

**深度相同的点之间不存在边**（除非它们有父子关系，但父子深度差 $1$）。所以整个开发过程可以按**深度**分层：第 $0$ 层是根，第 $1$ 层是根的子节点，第 $2$ 层是第 $1$ 层的子节点……

这样 DP 的时候，就可以**一层一层**地扩展点集，而不是去枚举树的形态。这条性质是整道题的钥匙：题面只说「每次连已开发区和未开发点」，并没有说「同层无边」，但它能推出来——边只连接父子，父子深度必差 $1$。

### DP 状态设计

设 `dp[i][S]` 表示**已经开发了前 i 层**（即深度为 $0 \sim i$ 的所有点），**已包含的点集为 S** 时的最小总代价。

显然 $S$ 必须包含根节点，且大小至少为 $i+1$（因为每一层至少有一个点）。

转移时，考虑第 $i$ 层（即新加入的一层）加入哪些点。假设上一层（第 $i-1$ 层）已经覆盖的点集为 $T$，现在要扩展到 $S$（$T \subset S$），那么新增的点集就是 $S \setminus T$，这些点全部深度为 $i$，它们必须与 $T$ 中的至少一个点相连（才能接上去）。

对于每个新增点 $v$，它连到 $T$ 的最小边权记为 `minEdge(T, v)`，那么这一层总的新增代价就是：

$$
i \times \sum_{v \in S\setminus T} \min_{u\in T} w(u,v)
$$

为什么可以直接相加？因为每个新增点独立选择父节点，互不干扰。不同新增点可以选择 $T$ 中不同的点作为父节点，这不会影响代价（它们都乘同一个 $i$）。

于是转移方程出炉：

$$
dp[i][S] = \min_{T \subset S} \big( dp[i-1][T] + i \times cost(T, S) \big)
$$

其中 `cost(T, S)` 就是上面那个和式。

### 预处理 cost[T][S]

由于 $n$ 很小，可以直接 $O(3^n \cdot n^2)$ 预处理，代码是这样做的：

- 枚举目标集合 `i`（即 $S$）；
- 枚举它的子集 `j`（即 $T$）；
- 对每个新增点 `t ∈ i ^ j`，计算 `tmp = min(G1[l][t])` 其中 `l ∈ j`，如果找不到则置 `inf`；
- 累加所有 `tmp` 得到 `cot[j][i]`。

注意：`cot[j][i]` 表示**从集合 j 扩展到集合 i 的边权和**（不乘深度）。

### 初始化与答案

枚举每一个点作为根（入口），即初始状态 `dp[0][1<<(u-1)] = 0`，然后对每个根独立跑 DP，最后取所有 `dp[i][(1<<n)-1]` 的最小值，就是答案 `cnt`。

为什么可以枚举根？因为入口可以任意选，而且不同根会导致不同的树结构，代价也不同。

边界：当 $n=1$ 时，不用开任何路，代价为 $0$。

### 为什么这样转移是对的

- **能覆盖最优解**：任取一棵最优树，按深度分层后，第 $i$ 层每个点的真实父节点一定在第 $i-1$ 层、属于集合 $T$，所以 $\min_{u\in T}w(u,v) \le w(\text{真实父节点},v)$，DP 算出的代价不会超过最优树。
- **每条 DP 路径都合法**：DP 每步都是「把新点连到上一层某个点」，按深度依次连边，自然构成一棵以入口为根的树，代价就是 DP 记录的值，不会凭空算小。
- 两边一夹，DP 的最小值恰好是最优总代价。

### 一些你可能踩的坑

1. **重边**：输入可能有重复边，取最短的就好。
2. **不连通**：如果某个新增点无法连接到 $T$，则这个转移不合法，`cot` 设为 `inf`。
3. **深度计算**：注意 $i$ 从 $1$ 开始还是从 $0$ 开始？代码中第一层（深度 $1$）对应 $i=1$，所以转移时乘的是 $i$，而根层深度为 $0$ 没有代价。
4. **枚举子集小技巧**：`for (int j = i; j; j = (j-1)&i)` 可以枚举 $i$ 的所有非空子集。代码里跳过了 `j == i` 的情况，因为新增点不能为空（必须扩展）。

### 总结

这道题巧妙地将树形结构**分层**，然后用状压 DP 逐层扩展，核心是 `cost` 的预处理和转移中深度因子的处理。

### 模块一：头文件、宏与全局数组

```cpp
#include<bits/stdc++.h>

using namespace std;

```

- `#define int long long` 把代码里所有 `int` 换成 `long long`，于是 `memset(0x3f)` 得到的 `inf` 是 $0x3f3f3f3f3f3f3f3f$，远大于真实答案（边权 × 深度 × 边数），不会误判成可达。
- `G1[u][v]` 存两点间最小边权（重边取 min）；`cot[j][i]` 存「从集合 $j$ 扩展一层到集合 $i$」的边权和（不乘深度）；`dp[i][S]` 存前 $i$ 层覆盖点集 $S$ 的最小代价。
- $M = 2^{12}$，正好把 $n \le 12$ 的点集压成不超过 $M$ 的下标；`N=15` 是层数维。

- `n == 1` 特判直接输出 $0$：一个点不需要开路，注意它在读边**之前**就返回了。
- 读边时正反两个方向都做 `min`，处理**重边**。

### 模块三：预处理 cot[j][i]

```cpp
	for(int i=1;i<(1<<n);i++){
		for(int j=i;j;j=(j-1)&i){
            if(j==i) continue;
			for(int t=1;t<=n;t++){
				int tmp=inf;
				if(!(((i^j)>>(t-1))&1)) continue;
				for(int l=1;l<=n;l++){
					if((j>>(l-1))&1) tmp=min(tmp,G1[l][t]);
				}
                if(tmp>=inf){
					cot[j][i]=inf;break;
				}else cot[j][i]+=tmp;
			}
		}
	}
```

- 外层 `i` 是目标集合 $S$，内层 `for(int j=i;j;j=(j-1)&i)` 枚举 $i$ 的所有非空子集 $j$（即 $T$），`j==i` 被跳过——新层不能为空。
- `i^j` 就是 $S \setminus T$；`(((i^j)>>(t-1))&1)` 判断点 $t$ 是否属于新层，不属于就跳过。
- 对新点 $t$，`tmp = min_{l∈j} G1[l][t]` 求它连到 $j$ 的最小边权。找不到（`tmp >= inf`）就说明这组扩展不合法，整组置 `inf` 并 `break`；否则累加进 `cot[j][i]`。
- 每个 $(j,i)$ 组合只会被访问一次，`cot` 又是全局零初始化，所以累加不会串。

### 模块四：枚举根、逐层 DP 与统计答案

```cpp
	for(int u=1;u<=n;u++){
		memset(dp,0x3f,sizeof dp);
		dp[0][1<<(u-1)]=0;
		for(int i=1;i<n;i++){
			for(int j=1;j<(1<<n);j++){
				for(int k=j;k;k=(k-1)&j){
                    if(j==k) continue;
					if(cot[k][j]!=inf) dp[i][j]=min(dp[i][j],dp[i-1][k]+i*cot[k][j]);
				}
			}
			cnt=min(cnt,dp[i][(1<<n)-1]);
		}
	}
```

- 外层 `u` 枚举入口；每个入口重开一次 `dp`，`dp[0][1<<(u-1)] = 0` 表示第 $0$ 层只有根、代价为 $0$。
- `i` 从 $1$ 到 $n-1$：第 $i$ 层最多到 $n-1$ 层。
- 对每个状态 $j$ 枚举其非空子集 $k$（跳过 `k==j`），若 `cot[k][j]` 合法，就按 `dp[i][j] = dp[i-1][k] + i*cot[k][j]` 转移。
- 每跑完一层，用覆盖全集 `(1<<n)-1` 的状态更新答案 `cnt`。

## 复杂度分析

### 时间复杂度：$O(3^n \cdot n^2)$

- **预处理 `cot`**：枚举所有「集合 + 子集」对共 $3^n$ 组，每组内部枚举新点 $t$（$O(n)$），再对 $t$ 扫一遍 $j$ 中的点求最小边权（$O(n)$），故为 $O(3^n \cdot n^2)$。当 $n=12$ 时 $3^{12} = 531441$，乘 $n^2 = 144$ 约 $7.6 \times 10^7$，C++ 里能跑（代码里还有若干剪枝）。
- **DP 转移**：对每个根（$n$ 个）× 深度（$n$ 层）× 状态与子集（合计 $3^n$ 组），为 $O(n^2 \cdot 3^n)$，与预处理同阶。
- 合起来仍是 $O(3^n \cdot n^2)$。

### 空间复杂度：$O(4^n)$

- `cot[M][M]` 是空间大头：$M = 2^n$，所以是 $4^n$ 项；又因为 `#define int long long` 每项 $8$ 字节，$n=12$ 时约 $16.7 \times 10^6$ 项、约 128 MB，需要留意内存限制。
- `dp[N][M]` 是 $O(n \cdot 2^n)$，`G1[N][N]` 是 $O(n^2)$，相对可忽略。

## 常见陷阱与注意事项

1. **重边**：同一对点可能有多条边，必须取最小边权（`G1[u][v]=min(...)` 正反都写）。漏掉会算大甚至算错。
2. **不连通 / 无法扩展**：某个新点 $v$ 与集合 $T$ 全都不相邻时，这组转移不合法，`cot[j][i]` 要置 `inf`，并且转移时用 `cot[k][j] != inf` 跳过，否则会把哨兵当真实代价加进去。
3. **深度因子的起点**：深度 $i$ 从 $1$ 开始乘，根层深度 $0$ 不计代价；写成从 $0$ 乘会把根层也算钱。
4. **子集枚举的边界**：`for (int j = i; j; j = (j-1)&i)` 枚举的是**非空**子集（$j=0$ 退出），且必须 `continue` 掉 `j==i`；DP 里的 `for (int k = j; ...)` 同理要跳过 `k==j`。
5. **根必须枚举**：入口任选，不同根对应不同树形和代价，只跑一个根会错。
6. **$n=1$ 特判**：单点无需修路，输出 $0$。注意代码里这个特判在读边之前就 `return` 了。
7. **内存**：`cot` 是 $4^n$ 项、每项 8 字节（因为 `#define int long long`），$n=12$ 时约 128 MB；卡内存的话可以把 `cot` 单独声明成 `int` 或改成按需计算。
8. **INF 的取法**：`memset(..., 0x3f, ...)` 配合 `#define int long long` 得到的是 long long 级别的无穷大，判断不可达就用 `tmp >= inf`，别拿 `0x3f3f3f3f` 这种 int 值去比。
9. **`dp[i-1][k]` 可能是 `inf`**：代码只检查了 `cot[k][j] != inf`，没检查 `dp[i-1][k]`。此时 `inf + i*cot` 仍是一个极大的数，不会溢出（`inf ≈ 4.56e18`，`int64` 上限约 `9.22e18`），但它会被当成一个「合法但很差」的值留在表里；最终答案取 min，正常连通图上不受影响，但如果你改了 INF 或边权范围，要小心溢出。

## 对比与扩展

| 方法 | 时间 | 空间 | 说明 |
|---|---|---|---|
| 分层状压 DP（本题） | $O(3^n n^2)$ | $O(4^n)$ | 利用「按层扩展 + 子集枚举」，$n \le 12$ 可过 |

### 扩展

- 「**按深度分层 + 子集枚举**」是状压 DP 里很常见的一类套路，凡是有「层数 / 步数惩罚」的连通、覆盖问题都可以往这个框架上套：核心是把「选父节点」拆成「每一层独立求和」。
- 把「点到集合的最小边权」提前预处理，是这类题的标准优化：否则每次转移都要再花 $O(n^2)$ 重算父节点。
- 子集枚举写法 `for (sub = S; sub; sub = (sub - 1) & S)` 是所有「枚举集合所有子集」场景的基础，务必背熟。
- 变体：若深度因子从 $0$ 开始计、或每层允许空，只需改转移里的系数与 `j==k` 的跳过条件，框架不变。

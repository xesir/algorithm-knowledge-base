## 解题思路

和「[Ynoi Easy Round 2016] 这是我自己的发明」一样，这道题的换根操作是**假的**。

我们钦定以 $1$ 为根，随后发现：不管以哪个点为根，路径都是一样的。所以

- 路径赋值操作不需要针对根的情况做讨论；
- 换根操作不需要真的换根，只需要开一个变量记录当前根即可；
- 子树最小值查询才需要分类讨论。

设当前根为 $root$，要查询以 $u$ 为根的子树最小值，分三种情况：

1. **根就是子树的根**（$root=u$）：最小值就是全局最小值；
2. **根在子树外**：最小值就是以 $1$ 为根时 $u$ 的子树最小值；
3. **根在子树内**：$u$ 的子树变成了「整棵树去掉 $u$ 的某个儿子的子树」，其中这个儿子是「子树内包含 $root$ 的那个」。于是答案是「去掉这一棵子树后剩余部分」的最小值。

这部分直接套一个树剖做即可。注意：查询的时候有可能求补集，而补集恰好落在全集的末尾，导致查询区间出现空区间，这里在 `query` 函数里面特判一下就可。

还需要实现一个函数：给定 $u,v$，求 $u$ 的儿子中，子树内包含 $v$ 的是哪一个。做法是让 $v$ 一直跳重链，直到二者在同一条重链上。每次跳之前检查一下重链链顶的父亲是不是 $u$——如果是，答案就是这条重链的链顶；否则继续往上跳。循环结束时二者在同一条重链上，答案就是 dfs 序上 $u$ 的编号加 $1$ 的位置。

## 逐行代码解析

核心是那个找儿子的函数，拆成两段。

### 沿重链上跳

```cpp
int fnd(int u,int v)
{
    while(top[u]!=top[v])
    {
        if(fa[top[v]]==u) return top[v];
        v=fa[top[v]];
    }
```

- `while(top[u]!=top[v])`：只要 $u,v$ 还不在同一条重链上，就让 $v$ 往上跳。
- `if(fa[top[v]]==u) return top[v];`：跳之前先看这条重链的链顶是不是直接挂在 $u$ 下面。如果是，这条链的链顶就是「$u$ 的儿子中，子树包含 $v$ 的那一个」。
- `v=fa[top[v]]`：整条重链一起跳过去，这是树剖保证复杂度的关键——每次至少跳过一条链。

### 同链时取 dfs 序的下一位

```cpp
    return pos[dfn[u]+1];
}
```

- 走到这里说明 $u,v$ 已经在同一条重链上，且 $u$ 是 $v$ 的祖先。
- 同一条重链上，dfs 序是连续的，所以 $u$ 的儿子就是 dfs 序紧挨着 $u$ 的下一个点，`pos` 是 dfs 序到原编号的映射。
- 这一步成立的前提是 $u$ 有儿子且 $v$ 在其子树内，调用方要先保证。

## 复杂度分析

原文没有给复杂度。按树剖的标准分析：预处理 $O(n)$，路径赋值 $O(\log^2 n)$，单次子树查询 $O(\log n)$（情况 3 要拆成两段区间），找儿子函数因为只跳重链，也是 $O(\log n)$。

## 常见陷阱与注意事项

- **补集查询出现空区间**：情况 3 里「去掉某棵子树」可能落到 dfs 序的末尾，形成空区间，`query` 里必须特判，否则会取到错误的初值。
- **换根别真换**：真的把整棵树重构一遍，复杂度直接爆炸；记录一个变量即可。
- **判断「根在子树内」**：要用 dfs 序的区间包含关系，而不是只比较深度。
- **根恰好等于查询点**：这是情况 1，直接返回全局最小值，不要走情况 3 的拆分。
- **路径赋值与根无关**：这条性质依赖「路径」本身与根的选择无关，别把它推广到子树操作上。

## 对比与扩展

- 「换根是假的」这个套路在换根类题目里非常常见：路径不变、子树要分类讨论，记住这个结论能省掉很多推导。
- 与「这是我自己的发明」那题对照：两者都把换根操作降级成「记录一个变量」。
- 如果题目要求的是子树加而非子树查，同样按这三种情况拆区间即可，只是线段树换成带懒标记的区间加。

## 题目描述

原文未附题面，以下题意根据作者思路整理。

有 $n$ 根柱子排成一列，第 $i$ 根的高度为 $h_i$，拆掉第 $i$ 根柱子需要花费 $w_i$。记 $w$ 的前缀和为 $s_i=\sum_{k=1}^{i}w_k$。

在两根柱子之间可以架一座桥，从 $j$ 架到 $i$ 的代价是 $(h_i-h_j)^2$；桥架好之后，夹在 $j$ 与 $i$ 中间的那些柱子必须全部拆掉。

设 $f_i$ 表示「把第 $1$ 到第 $i$ 根柱子处理到首尾连通、并且最后一座桥的右端点是 $i$」的最小代价，原文给出的转移式是

$$f_i=\min_{j<i}\left(f_j+(h_i-h_j)^2+s_{i-1}-s_j\right)$$

其中 $s_{i-1}-s_j=\sum_{k=j+1}^{i-1}w_k$，正好是拆掉 $j$ 与 $i$ 之间那些柱子的代价。

原文只写了这个转移式，没有交代 $n$、$h_i$、$w_i$ 的取值范围。

## 解题思路

### 一、经典 DP

设 $f_i$ 表示处理到第 $i$ 根柱子、并且以 $i$ 作为最后一座桥右端点的最小代价，枚举上一座桥的右端点 $j$：

$$f_i=\min_{j<i}\left(f_j+(h_i-h_j)^2+s_{i-1}-s_j\right)$$

原文的说法是「容易得到经典 DP」。这个式子直接枚举 $j$ 是 $O(n^2)$ 的，瓶颈在平方项把 $i$ 和 $j$ 缠在了一起。

### 二、拆式子，化成直线

把平方展开：

$$(h_i-h_j)^2=h_i^2-2h_jh_i+h_j^2$$

回代之后，把只和 $i$ 有关的项提到 $\min$ 外面：

$$f_i=h_i^2+s_{i-1}+\min_{j<i}\left(-2h_j\,h_i+h_j^2-s_j+f_j\right)$$

括号里对每个决策点 $j$ 都是一条以 $h_i$ 为自变量的直线：

- 斜率 $k_j=-2h_j$；
- 截距 $b_j=h_j^2-s_j+f_j$。

斜率和截距都只和 $j$ 有关，所以每个 $j$ 对应的直线是固定的。$f_i$ 只取决于这堆直线在 $h_i$ 处的最小值——这正是斜率优化的标准形状。

### 三、斜率不单调，单调队列失效

原文的说法是「由于斜率不递增考虑李超树做」：斜率 $-2h_j$ 随着 $j$ 的推进并不保证单调，而单调队列维护包络线的前提恰恰是「按插入顺序，斜率单调」。一旦斜率乱序，队尾弹点的判据就不再成立，凸壳会被弹坏。

于是换成李超线段树：它不要求直线按斜率有序，支持「动态插入一条直线」和「查询某个横坐标处所有直线的最小值」，正好对上本题的需求。

### 四、李超线段树的定义域下界取 0

原文特意强调「李超树开的范围下界是 $0$」。柱子高度从 $0$ 开始计数，横坐标的取值区间必须覆盖到 $h_i=0$ 这种情况；下界开成 $1$，高度为 $0$ 的柱子就没有对应的查询区间，答案会算错。

每次算完 $f_i$ 之后，把 $j=i$ 对应的直线 $k_i=-2h_i$、$b_i=h_i^2-s_i+f_i$ 插进李超树，供后面的状态使用。

实现要点（根据原文整理）：

- **李超树的下界取 $0$**：定义域从 $0$ 开到高度的上界，别默认从 $1$ 开始。
- **插入的是直线 $k_j=-2h_j$、$b_j=h_j^2-s_j+f_j$**：每次算完 $f_i$ 立刻插入 $j=i$ 这一条，插入顺序按 $i$ 递增即可，李超树不关心斜率。
- **转移时先查后改**：$f_i=h_i^2+s_{i-1}+\operatorname{query}(h_i)$，查完之后再插入自己的直线，避免自己转移给自己。
- **$j=0$ 的初始直线要插**：$f_0=0$、$s_0=0$，对应的斜率为 $-2h_0$、截距为 $h_0^2$，少了它 $f_1$ 就没有决策点可用。
- **前缀和用 $s_{i-1}$ 而不是 $s_i$**：拆掉的是 $j$ 与 $i$ 之间的柱子，第 $i$ 根自己不用拆。
- **数值范围**：$h_j^2$ 与 $f$ 都放在 64 位整型里；李超树比较交点位置时是斜率差乘截距差，建议用 `__int128` 承接，避免溢出把判据翻错。
- **查询沿路径取最小**：单点查询 $h_i$ 时，把根到叶子路径上每个节点维护的直线在该点的取值都取一遍 min。

## 复杂度分析

- **时间复杂度**：一共 $n$ 次插入和 $n$ 次查询，李超树的每次操作都是树高 $O(\log V)$（$V$ 是高度定义域的大小），整体记作 $O(n\log n)$。
- **空间复杂度**：$f$、$h$、$w$、$s$ 四个数组各 $O(n)$；李超树的数组长度取决于定义域的范围，按 $n$ 级别开即可，整体记作 $O(n)$。

## 常见陷阱与注意事项

1. **斜率不单调就别用单调队列**：本题的斜率 $-2h_j$ 不保证有序，单调队列的弹点判据依赖插入顺序的单调性，硬套会把真正的最优直线弹掉。
2. **李超树下界必须取 $0$**：横坐标的下界决定了叶子覆盖的范围，下界抬高会让低处的查询点落在定义域外。
3. **$s_{i-1}$ 与 $s_j$ 的配对**：转移式里是 $s_{i-1}-s_j$，写成 $s_i-s_j$ 就把第 $i$ 根柱子自己的拆除代价也算进去了。
4. **截距里的符号**：截距是 $h_j^2-s_j+f_j$，$s_j$ 前面是减号；符号写反后直线整体上移或下移，答案会稳定偏大或偏小。
5. **忘记插入当前点的直线**：$f_i$ 算完不插入，后面所有用到 $j=i$ 的转移都会集体缺失。
6. **交点比较的溢出**：斜率差与截距差的乘法在 64 位边缘，转 `__int128` 再比。
7. **$j=0$ 的边界**：前缀和 $s_0=0$、$f_0=0$，初始直线对应「从第一根柱子开始架桥」这一种方案。

## 对比与扩展

| 手段 | 适用条件 | 本题情况 |
|---|---|---|
| 单调队列维护凸壳 | 查询横坐标单调、插入直线斜率单调 | 斜率不单调，不适用 |
| 李超线段树 | 只要转移能写成直线形式，插入与查询顺序都不受限制 | 本题采用 |
| CDQ 分治 + 凸包 | 斜率与横坐标都不单调，但可以离线按顺序分治 | 也能做，见 P4027 |

- **与同组的 P3195 / P3628 / P2120 对照**：那三题都能写成「斜率 + 截距只依赖 $j$」的直线形式，区别只在「求 min 还是 max」「斜率递增还是递减」，因为它们满足斜率单调，$O(n)$ 的单调队列就够了。本题的式子形状完全一样，唯独斜率不单调，代价就从 $O(n)$ 抬到 $O(n\log n)$。
- **与 P5785 任务安排对照**：那题的斜率也不单调，同样改用李超线段树；区别是 P5785 的直线只需要在 $i$ 之后有效，而本题是全局插入、全局查询，不需要考虑线段的区间限制。
- **再往前一步**：当连「按 $i$ 递增插入」这个顺序约束都要被剥掉时，就该用 CDQ 分治把偏序限制拿掉，再在里面套李超树或者凸包（P4027 的思路）。

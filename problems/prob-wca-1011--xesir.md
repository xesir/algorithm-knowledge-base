> 一道神秘的远古 ICPC 题，把树、状压、子集 DP、容斥原理揉在一起，思路清奇。
> **关键词**：树上前缀异或、高维前缀和、容斥原理、组合数

## 题目描述

有一棵 $n$ 个节点的树，有 $m$ 条“指定道路”（编号 $1 \sim m$），还有 $k$ 条“路线”，每条路线是树上的一条简单路径（用两个端点表示）。

对于每条路线，它能“覆盖”它经过的所有指定道路。

现在要找一个最小的整数 $i$（$1 \le i \le m$），使得：**在所有路线中，存在一种方案选出 $i$ 条路线，使得它们覆盖的指定道路集合大小恰好为 $m$（即覆盖了所有指定道路）**。

输出最小的 $i$ 和方案数（对 $998244353$ 取模）。如果不存在这样的 $i$，输出 `-1`。

### 输入格式

原文没有单独给出输入格式，下面按所附代码的读入顺序整理：

- 第一行三个整数 $n,m,k$；
- 接下来 $n-1$ 行，每行两个整数 $u,v$，表示一条树边，边按输入顺序编号为 $1 \sim n-1$；
- 接下来 $m$ 行，每行一个整数 $x$，表示第 $x$ 条读入的树边是一条指定道路；
- 接下来 $k$ 行，每行两个整数 $u,v$，表示一条路线的两个端点。

### 输出格式

若存在解，输出一行两个整数：最小的 $i$ 与对应方案数（对 $998244353$ 取模），中间用空格分隔；否则输出 `-1`。

- $m \le 22$
- $k \le 3 \times 10^5$

## 解题思路

### 一、题目在问什么

一句话：树上有 $m$ 条被指定的边、$k$ 条路径，一条路径“覆盖”它经过的指定边；求最小的 $i$，使得存在 $i$ 条路径，它们覆盖的指定边并集恰好是全部 $m$ 条，并统计这种选择的方案数。

数据范围已经把做法写在脸上了：$n,k$ 都有 $3\times 10^5$ 量级，而 $m \le 22$。凡是“$m$ 很小、$n$ 很大”的组合题，基本都要对那 $m$ 个对象做状压。

### 二、思路从哪来：$m \le 22$ 几乎是在明示状压

~~遇事不决状压DP~~

$2^{22} \approx 4.2\times 10^6$，这个数刚好卡在“能开数组、能枚举、但不能再乘 $m$ 太多次”的位置。于是把每条指定道路看成一个二进制位：第 $i$ 条指定道路对应第 $i-1$ 位。

对每条路线 $u \to v$，用一个 $m$ 位二进制数表示“它经过了哪些指定道路”。整个问题瞬间变成：

> 给定 $k$ 个 $m$ 位二进制数，求最小的 $i$，使得存在 $i$ 个数的按位或等于全集 $(1<<m)-1$，并输出方案数。

于是整个问题被拆成了三个独立的步骤：**路线转掩码 → 子集和 → 容斥计数**。

### 三、关键性质一：路径掩码 $=$ 两端点根路径掩码的异或

题面只说了“路线是简单路径、覆盖经过的指定道路”，并没有告诉你路径掩码怎么快速求。朴素做法是对每条路线沿着树走一遍、逐条检查经过哪些指定边，单次 $O(\text{路径长度}\times m)$，$k$ 条路线直接 TLE。

这里要用的隐藏性质是：

> 任取根（比如 $1$），记 `fh[x]` 为“根到 $x$ 的路径上经过的指定道路集合”（$m$ 位掩码），则
> $$\text{path\_mask}(u,v) = \text{fh}[u] \oplus \text{fh}[v]$$

**为什么是异或？** 设 $l=\mathrm{LCA}(u,v)$。根到 $u$ 的路径 = 根到 $l$ 的路径 ∪ $l$ 到 $u$ 的路径，根到 $v$ 同理。两段“根到 $l$”完全重合，异或后互相抵消；剩下的 $l \to u$ 与 $l \to v$ 没有公共边，恰好拼成 $u \to v$ 的完整路径。

注意这里统计的对象是**边**，而“指定道路”本身也是边，所以根到自己的路径为空、`fh[1]=0`，边界天然成立。

`fh[x]` 的预处理只要一次 DFS：先 `fh[x] = fh[fa]`，再看边 $(x,fa)$ 是不是第 $i$ 条指定道路，是就把第 $i$ 位置 $1$。

### 四、关键性质二：把“恰好覆盖”换成“从子集池里选”

求出 $k$ 个掩码后，先做最基础的计数：`dp[mask]` 表示掩码恰好等于 `mask` 的路线条数。

接着要回答的问题是：对每个掩码 $S$，有多少条路线的掩码是 $S$ 的**子集**？这正是**子集和**，用高维前缀和（SOS DP）来做：

```text
for i in [0, m):
    for sta:
        if sta 含第 i 位: dp[sta] += dp[sta ^ (1<<i)]
```

做完之后 `dp[S]` 就是“掩码是 $S$ 的子集的路线总数”。

**为什么这样做对**：这相当于对每一位独立地做一个“前缀和”。处理完第 $i$ 位后，所有状态都已经是“第 $0..i$ 位上可以比自己小、其余位必须相等”的累加结果，$m$ 位全部处理完就是完整的子集和。更新时读的 `dp[sta^(1<<i)]` 在第 $i$ 位上为 $0$、本轮不会被写，所以内层循环升序降序都无所谓。

### 五、关键性质三：容斥把“至少/子集”翻成“恰好”

固定 $i$，现在要算“选 $i$ 条路线、掩码按位或恰好等于全集 $U$”的方案数。直接枚举组合是 $\binom{k}{i}$ 级，完全不可行，只能反着来。

设 $f(S)=\binom{dp[S]}{i}$，含义是“从掩码 $\subseteq S$ 的路线池里选 $i$ 条”。这些路线覆盖的并集一定 $\subseteq S$，但不一定等于 $S$。也就是说 $f(S)$ 统计的是“至少覆盖 $\subseteq S$”，要用它反推“恰好覆盖 $U$”，就得做布尔格上的 Möbius 反演（容斥）：

$$\text{ans} = \sum_{S \subseteq U} (-1)^{m - |S|} \binom{dp[S]}{i}$$

**简易证明**：固定某一种“实际覆盖集合为 $T$”的选择，它在原式中被计入的次数为

$$\sum_{S \supseteq T} (-1)^{m-|S|} = \sum_{j=0}^{m-t}\binom{m-t}{j}(-1)^{m-(t+j)} = (-1)^{m-t}(1-1)^{m-t}$$

其中 $t=|T|$。当 $t<m$ 时该和为 $0$，当 $t=m$（即 $T=U$）时为 $1$。所以这个式子恰好只留下“覆盖全集”的方案，其余全部抵消。

代码用奇偶性判断符号：`(ct & 1) == (m & 1)` 表示 $m-ct$ 为偶数，对应系数 $(-1)^{m-ct}=+1$；否则为 $-1$。

### 六、为什么 $i$ 只需要枚举到 $m$

从 $i=1$ 往上枚举，找到第一个 `ans != 0` 的 $i$ 就是答案；如果 $i=1..m$ 全部为 $0$，输出 `-1`。

$i$ 只需枚举到 $m$ 的理由：要覆盖 $m$ 条不同的指定道路，最优选择里每条路线至少贡献一条“此前没被覆盖过”的新道路（否则这条路线可以删掉，$i$ 还能更小），所以最小覆盖路线数不会超过 $m$。答案若存在，必然在 $1 \sim m$ 之间。

### 七、总结

## 逐行代码解析

### 头文件、宏与全局数组

```cpp
#include<bits/stdc++.h>
#define endl '\n'
#define fi first
#define se second
#define lowbit(x) (x&(-x))
#define int long long
using namespace std;
typedef pair<int,int> PII;
typedef long long ll;
const int N=3e5+10,M=23,mod=998244353;
int n,m,k;
vector<int> G8[N];
PII a[N];
int fh[N],mac[N];
int dp[(1<<M)];
int jcr[4*N],nyj[4*N];
```

- `#define int long long` 把所有 `int` 提升为 64 位，因此主函数必须写 `signed main()`（`signed` 等价于 `int`，不会被宏再次展开成 `long long main`）。
- `M=23` 给 $m\le 22$ 留了余量，`dp[1<<M]` 是子集和用的数组，大小 $2^{23}$。
- `fh[x]` 存根到 $x$ 的前缀掩码，`mac[i]` 存第 $i$ 条路线的掩码；`a[1..k]` 存路线，`a[k+1..k+m]` 存指定道路的端点对。
- `jcr/nyj` 是阶乘与阶乘逆元，`4*N` 的上界对应后面 `jiecycl(2*(n+k))`。

### 快速幂与组合数预处理

```cpp
int ksm(int x,int y,int p){//快速幂
    int res=1;
    if(y==0) return 1;
    if(y&1) res=x*ksm(x,y-1,p)%p;
    else res=ksm(x,y/2,p),res=res*res%p;
    return res;
}
void jiecycl(int n){
    jcr[0]=1;
    for(int i=1;i<=n;i++){
        jcr[i]=jcr[i-1]*i%mod;
    }
    nyj[n]=ksm(jcr[n],mod-2,mod);
    for(int i=n-1;i>=0;i--){
        nyj[i]=nyj[i+1]*(i+1)%mod;
    }
}
int cabz(int n,int k){//组合数
    if(k<0||k>n) return 0;
    return jcr[n]*nyj[k]%mod*nyj[n-k]%mod;
}
```

- `ksm` 是递归快速幂，`jiecycl` 先递推阶乘，再用费马小定理求 `nyj[n] = jcr[n]^(mod-2)`，最后倒推所有阶乘逆元。
- `cabz(n,k)` 用阶乘公式算 $\binom{n}{k}$，并对 `k<0` 或 `k>n` 的非法情况直接返回 $0$，这样容斥枚举时不用额外判空。
- 容斥里要算 $\binom{dp[sta]}{i}$，其中 `dp[sta] \le k`，所以阶乘预处理到不小于 $k$ 即可；代码用 `2*(n+k)` 留足余量。

### DFS 求根路径掩码

```cpp
void dfs(int x,int fa){
    fh[x]=fh[fa];
    for(int i=1;i<=m;i++){
        if(a[k+i]==(PII){x,fa}||a[k+i]==(PII){fa,x}) fh[x]|=1<<(i-1);
    }
    for(auto i:G8[x]){
        if(i==fa) continue;
        dfs(i,x);
    }
}
```

- 先继承父亲的掩码 `fh[x]=fh[fa]`，再枚举 $m$ 条指定道路，检查边 $(x,fa)$ 是否是其中一条。
- 判定里 `(PII){x,fa}` 与 `(PII){fa,x}` 两个方向都写，是因为树边是无向的、存的时候方向不确定。
- 每个节点都完整枚举一遍 $m$，所以这一段是 $O(n\cdot m)$，不是 $O(n)$。

- 树边按输入顺序存进 `sb010[i]`，同时建无向邻接表。
- 指定道路的输入是“树边编号 $x$”，所以 `a[k+i]=sb010[x]` 把它还原成端点对，供 DFS 比较。
- `a[1..k]` 存路线、`a[k+1..k+m]` 存指定道路，与 DFS 里的下标约定严格对应。

### main（二）：路线转掩码与 SOS 子集和

```cpp
    dfs(1,0);
    for(int i=1;i<=k;i++){
        mac[i]=fh[a[i].fi]^fh[a[i].se];
        dp[mac[i]]++;
    }
    for(int i=0;i<m;i++){
        for(int sta=(1<<m)-1;sta>=0;sta--){
            if(sta&(1<<i)) dp[sta]+=dp[sta^(1<<i)];
        }
    }
```

- `mac[i]=fh[u]^fh[v]`：用树上前缀异或一次求出第 $i$ 条路线的掩码，顺手 `dp[mac[i]]++` 统计“掩码恰好等于它的路线数”。
- 两重循环做 SOS DP：外层枚举位、内层枚举状态，把“去掉这一位”的子集累加进来。结束后 `dp[S]` 是“掩码为 $S$ 子集的路线数”。
- 内层从 `(1<<m)-1` 递减，读源 `sta^(1<<i)` 的第 $i$ 位为 $0$，不会在本轮被修改。

### main（三）：容斥统计答案与快读快写

```cpp
    for(int i=1;i<=m;i++){
        int ans=0;
        for(int sta=0;sta<=(1<<m)-1;sta++){
            int ct=__builtin_popcount(sta);
            if((ct&1)==(m&1)) ans=(ans%mod+cabz(dp[sta],i)%mod+mod)%mod;
            else ans=(ans%mod-cabz(dp[sta],i)%mod+mod)%mod;
        }
        ans%=mod;
        if(ans!=0){
            cout<<i<<" "<<ans;
            exit(0);
        }
    }
    cout<<-1;
    return 0;
}
```

- 外层枚举 $i$，内层枚举所有子集 `sta`，按容斥系数 $\pm\binom{dp[sta]}{i}$ 累加；`(ct&1)==(m&1)` 决定加还是减。

- 文件末尾的 `read/write` 是手写快读快写，但 `main` 里用的是 `cin/cout`，这两个函数实际没被调用，属冗余代码。

## 复杂度分析

- **DFS 求掩码**：每个节点都枚举 $m$ 条指定道路，$O(n\cdot m)$；$k$ 条路线各做一次异或，$O(k)$。
- **SOS 子集和**：外层 $m$ 位、内层 $2^m$ 个状态，$O(m\cdot 2^m)$。
- **容斥枚举答案**：外层 $i$ 共 $m$ 次、内层 $2^m$ 个状态，$O(m\cdot 2^m)$。
- **总计**：$O(n\cdot m + m\cdot 2^m)$。代入上限，$n\cdot m \approx 6.6\times 10^6$，$m\cdot 2^m \approx 9.2\times 10^7$，总量约 $10^8$，注意常数。

原文在复杂度一节写“每个节点只遍历一次，标记指定道路时 $O(1)$，总 $O(n+k+m)$”，但代码 `dfs` 里对每个节点都有一个 $m$ 次循环，实际是 $O(n\cdot m)$（原文那句后面自己也打了个问号）。

空间上，`dp[1<<23]` 在 `#define int long long` 下每个元素 8 字节，约 67 MB；`jcr/nyj` 各 $1.2\times 10^6$ 个 `long long`，合计约 19 MB；再加上邻接表、`a/sb010/fh/mac` 等数组，整体在 100 MB 量级，需留意题目内存限制。

## 常见陷阱与注意事项

1. **`#define int long long` 必须配 `signed main()`**：写 `int main()` 会被宏替换成 `long long main()`，是未定义行为。

2. **路径掩码用异或而不是按位或**：`fh[u]^fh[v]` 正是要抵消根到 LCA 的公共段，换成按位或会把公共段上的指定道路重复统计。

3. **容斥符号别写反**：`(ct&1)==(m&1)` 对应 $(-1)^{m-ct}=+1$；奇偶判断颠倒会让所有项符号翻转。

4. **SOS DP 的读源方向**：更新 `dp[sta] += dp[sta^(1<<i)]` 时，读源必须不含第 $i$ 位，才能保证它本轮没被改过。

5. **组合数减法要补 `+mod`**：`ans` 累减时统一 `(...%mod - ...%mod + mod) % mod`，否则负数取模出错。

6. **指定道路按“边编号”读入**：`a[k+i]=sb010[x]` 说明输入给的是树边编号 $x$；若题面改成给端点，必须先建“端点对到边”的映射再转换。

7. **$i$ 只需枚举到 $m$**：最小覆盖至多要 $m$ 条路线，$i=m$ 仍为 $0$ 就可以直接判无解。

8. **内存常数偏大**：`dp` 约 67 MB，阶乘逆元约 19 MB；必要时把 `dp` 单独声明为 32 位 `int`，能省一半。

9. **DFS 递归深度**：`dfs` 的递归深度最大为 $n$，链状数据（$n=3\times10^5$）可能爆栈；代码没有手工开栈或改迭代，本地测链数据时要留意。

## 对比与扩展

- **对比朴素做法**：枚举“选 $i$ 条路线”是 $\binom{k}{i}$ 级，完全不可行；本题把覆盖关系压成 $m$ 位掩码，再用 SOS DP 与容斥把计数降到 $O(m\cdot 2^m)$。

- **SOS DP（高维前缀和）**：求“子集和 / 超集和”的标准工具，复杂度 $O(m\cdot 2^m)$；把加法换成 $\max/\min$ 就能扩展到“子集内最值”等变体。

- **布尔格上的容斥 / Möbius 反演**：$f(S)=\binom{dp[S]}{i}$ 是“覆盖 $\subseteq S$”的计数，反演后得到“恰好覆盖 $S$”，与“至少 / 恰好”类计数题同源。

- **树上前缀异或**：不限于“指定道路”，任何可沿边累加、异或的边权（边权异或和、边权乘积）都能用 `fh[u]^fh[v]` 在 $O(1)$ 内求路径值；配合 LCA 与离线询问可以扩展到更一般的树路径统计。
